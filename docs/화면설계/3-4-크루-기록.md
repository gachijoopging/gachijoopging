# 3-4 크루 기록

**목적** 기간별 크루 전체 활동 성과와 크루원 순위를 보고, 크루장은 기간을 골라 CSV로 내보낸다.
**원본** `../legacy/android-res/layout/fragment_group_record.xml` · **변경** 내 기록/전체 기록 탭과 지도·개인 기여 상자를 없애고, 크루 전체 통계·추이·순위·CSV 내보내기로 바꿨다.
**진입** 3-1 모이깅의 "크루 기록" · 2-1 홈의 최근 7일 카드 · 3-2 크루 정보의 "크루 기록" · **이탈** 5-4 타인 프로필 · 시스템 공유 시트(CSV) · 뒤로 가기 → 진입 화면

## 배치

옛 XML의 순서(헤더 → 탭 → 지도 → 지표 행 → 카테고리 칩 → 크루원 목록 → 공유 버튼)를 따른다. 지도 자리에는 기간 선택과 일별 막대, 내/전체 탭 자리에는 1주·1개월·전체 기간 칩을 둔다. 크루원 목록은 순위 카드가 된다.

```
┌──────────────────────────────────────┐
│ ① ‹  크루 기록                        │
├──────────────────────────────────────┤
│ ② [최근 7일] [1개월] [전체]           │
│ ③ ▂▅▇▄▆▃▅  9월 1일 ~ 9월 7일          │
├──────────────────────────────────────┤
│ ④  1,430개   128.0km   26시간40분  62회 │
│      개수       거리       시간     활동 │
├──────────────────────────────────────┤
│ ⑤ [담배꽁초 620] [플라스틱 310] ...    │
│ ⑥ 크루원 순위                         │
│    1  (◉) 관열  412개 · 30.1km        │
│    2  (◉) 상혁  380개 · 28.8km        │
│ ⑦ [ CSV 내보내기 ]                    │ ← 크루장만
└──────────────────────────────────────┘
```

## 상태

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | ①은 보이고 ②~⑦ 자리에 `Loading` "크루 기록을 불러오고 있어요" | ① 뒤로 |
| 새로고침 | 당겨서 새로고침. 이전 ③~⑦ 값을 남기고 상단 스피너 | 기간 칩·순위 행·뒤로 |
| 빈 | 선택 기간에 `totals.activities` 0. ③은 0 막대, ④는 모두 0, ⑤·⑥은 숨기고 `EmptyState` "이 기간에는 활동 기록이 없어요" | 기간 칩·뒤로 |
| 오류 | `GET /crew/stats` 4xx·5xx면 ③~⑦ 자리에 `ErrorState` "크루 기록을 불러오지 못했어요" / [다시 시도] | 다시 시도 → 같은 range 재조회 |
| 오프라인 | 이전 값이 있으면 그대로, ② 아래 `Banner` "인터넷 연결을 확인해 주세요.". 값이 없으면 오류 상태 | 기간 칩·뒤로 |

| 부분 실패 | **해당 없음.** 기간 통계 하나의 응답으로 지표·막대·순위를 함께 받는다 | — |
| 크루원 | ⑦ CSV 내보내기가 숨겨진다 | 기간 칩·순위 행 |
| 크루장 | ⑦ CSV 내보내기가 보인다 | 전부 |

CSV 기간 선택 시트: 제목 "기록 내보내기" · 시작일/종료일 입력 · 설명 "활동 한 회가 한 행으로 내려받아져요." · [취소] / [CSV 내보내기]. 시작일이 종료일보다 늦으면 "시작일은 종료일보다 앞서야 해요.". `GET /crew/export` 200의 `text/csv; charset=utf-8` 파일을 시스템 공유 시트로 보낸다. 실패하면 "CSV를 만들지 못했어요. 다시 시도해 주세요." `Snackbar`.

## 인터랙션

- 스크롤: ③~⑦이 길면 세로 스크롤, ①·②는 고정
- 당겨서 새로고침: 있음. 현재 `range`로 `GET /crew/stats` 재조회
- 길게 누르기: 없음
- 시트: 크루장만 ⑦에서 CSV 기간 선택 시트
- 뒤로 가기: 진입 화면으로 팝한다. 시트가 떠 있으면 먼저 닫는다
- 키보드: CSV 시트의 날짜 입력에서만 날짜 키보드 또는 OS 날짜 선택기를 쓴다
- 기간 전환: ②의 칩을 누르면 선택 상태가 즉시 바뀌고 ③~⑥만 `Loading`으로 갱신한다
- 순위 행 탭: 내 행은 5-5, 다른 크루원은 5-4로 푸시
- 전환: 5-4·5-5는 푸시. CSV는 앱 밖 시스템 공유 시트

## 접근성

- ②: 선택된 기간을 "최근 7일, 선택됨"처럼 읽는다
- ③: 막대 하나씩이 아니라 요약 "최근 7일, 총 1,430개"를 읽는다
- ④: "1,430개, 128킬로미터, 26시간 40분, 활동 62회"를 하나로 읽는다
- ⑤: 각 칩은 "담배꽁초 620개"처럼 읽는다
- ⑥: "1위, 관열, 412개, 30.1킬로미터, 프로필 보기"로 읽는다
- ⑦: "CSV 내보내기, 크루장만 가능". 모든 버튼은 44dp 이상이다

## 옛 화면과의 차이

- 옛 내 기록/전체 기록 탭은 제거했다. 크루 하나의 기간 통계를 모두에게 같은 모양으로 보여 준다
- 옛 지도·GPS 약함 칩·내 기여 상자·피드 공유 버튼을 없애고, 일별 막대·4분할 통계·순위·CSV 내보내기를 넣었다
- 옛 크루원 목록은 참석자 목록이었다. 새 목록은 선택 기간의 줍기 수 순위다
- CSV는 크루장만 쓸 수 있고 활동 한 회가 한 행이다

## 미결

- `ranking`의 동점 처리·순위 기준은 계약에 없다. 현재 서버가 준 rank 순서대로 보인다
- 전체 기간의 `series`가 너무 길 때 막대를 월 단위로 묶을지 계약에 없다
- CSV의 파일명 규칙·기본 날짜 범위는 미정이다
