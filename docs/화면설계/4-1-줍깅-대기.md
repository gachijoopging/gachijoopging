# 4-1 줍깅 대기

**목적** 줍깅 탭에서 진행 중인 활동이 있는지 확인하고, 없으면 활동 시작 시트를 열거나 있으면 활동 중 화면으로 돌아간다.
**원본** `../legacy/android-res/layout/sheet_start.xml`의 시작 진입점 · **변경** 혼자/근처 사람 선택과 참여 요청을 없애고, 활동을 시작하거나 이어가는 단일 대기 화면으로 바꿨다.
**진입** 하단 탭 줍깅 · 4-7 활동 종료 요약의 "닫기" · 4-2 활동 시작 시트 닫기 · **이탈** 4-2 활동 시작 시트 · 4-3 활동 중 · 1-10 위치 권한 안내

## 배치

옛 시작 시트의 손잡이·제목·주 버튼 리듬을 전체 탭 화면으로 확장한다. 진행 중 활동이 없을 때는 큰 새싹 그림·설명·시작 버튼, 있을 때는 현재 활동 요약 카드·이어가기 버튼을 보인다. 하단 탭은 유지한다.

```
┌──────────────────────────────────────┐
│ ① 줍깅                                │
├──────────────────────────────────────┤
│ ②             🌱                      │
│    지금 걸으며 주운 것을 기록해 보세요. │
│                                      │
│ ③ ┌────────────────────────────────┐ │
│    │ 활동을 시작하면 거리·시간·줍기를 │ │
│    │ 기록할 수 있어요.                │ │
│    └────────────────────────────────┘ │
│ ④ [          줍깅 시작          ]      │
├──────────────────────────────────────┤
│ ⑤ 홈  피드  줍깅  모이깅  내 정보       │
└──────────────────────────────────────┘

진행 중 활동이 있으면 ②~④가 다음으로 바뀐다.
│ ② 활동을 이어갈까요?                   │
│ ③ 1.2km · 42분 · 17개 · 일시정지 중    │
│ ④ [          활동 이어가기      ]      │
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 제목 | "줍깅" | `Txt` display | — |
| ② | 대기 그림·문구 | 새싹 그림과 "지금 걸으며 주운 것을 기록해 보세요." | `신규` 빈 상태 캐릭터 + `Txt` section | — |
| ② | 진행 중 제목 | `GET /activities/current`의 `data`가 있으면 "활동을 이어갈까요?" | `Txt` section | — |
| ③ | 대기 안내 카드 | "활동을 시작하면 거리·시간·줍기를 기록할 수 있어요." | `Card` + `Txt` | — |
| ③ | 현재 활동 요약 | `distanceM`·`startedAt`·`pausedSec`·`itemCount`·`locationShared` (`GET /activities/current`) | `Card` + `Txt` + `Chip` | 4-3 |
| ④ | 시작 버튼 | "줍깅 시작". 위치 권한이 있으면 4-2를 연다 | `Button` primary lg | 4-2 |
| ④ | 이어가기 버튼 | 진행 중이면 "활동 이어가기" | `Button` primary lg | 4-3 |
| ⑤ | 하단 탭 | 홈 · 피드 · 줍깅 · 모이깅 · 내 정보. 줍깅 선택 | `BottomNav` | 각 탭 |

현재 활동 시간은 `startedAt`부터 현재까지에서 `pausedSec`을 뺀 값으로 "42분" 또는 "1시간 8분"으로 보인다. `distanceM`은 1000 미만이면 "820m", 이상이면 "1.2km". `pausedSec`이 0보다 크다고 일시정지 여부를 단정할 수 없으므로, 현재 일시정지 상태는 `GET /activities/current` 응답에 없는 계약 구멍으로 미결에 둔다.

## 상태

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | ①·⑤는 보이고 ②~④ 자리에 `Loading` "활동을 확인하고 있어요" | 하단 탭 |
| 대기 | `data`가 null. ② 대기 그림·③ 안내·④ "줍깅 시작" | 시작 → 위치 권한 확인 |
| 진행 중 | `data`가 있음. ② 진행 중 제목·③ 요약·④ "활동 이어가기" | 이어가기 → 4-3 |
| 새로고침 | 당겨서 새로고침. 기존 대기·진행 중 값을 남기고 상단 스피너 | 평소처럼 |
| 빈 | **해당 없음.** data null은 대기 상태로 표현한다 | 시작 |
| 오류 | `GET /activities/current` 4xx·5xx면 `ErrorState` "활동 상태를 불러오지 못했어요" / [다시 시도] | 다시 시도 |
| 오프라인 | 이전 상태가 있으면 그대로, ① 아래 `Banner` "인터넷 연결을 확인해 주세요.". 값이 없으면 오류 상태 | 이전 이어가기·탭 |
| 권한 거부 | 위치 권한이 없고 시작을 누르면 1-10을 모달로 연다. 허용 뒤 4-2를 다시 연다 | 위치 권한 안내 |
| 부분 실패 | **해당 없음.** 현재 활동 조회 하나다 | — |
| 다른 기기에서 종료됨 | 이어가기 뒤 4-3 진입 시 활동이 없으면 "활동이 이미 끝났어요." `Snackbar` 뒤 이 화면을 재조회한다 | 시작 |

## 인터랙션

- 스크롤: 없음. 작은 화면에서는 ②~④만 세로 스크롤
- 당겨서 새로고침: 있음. `GET /activities/current` 재조회
- 길게 누르기: 없음
- 시트: 대기 상태의 ④가 4-2 활동 시작 시트를 연다
- 뒤로 가기: 하단 탭 첫 화면이라 앱을 벗어난다
- 키보드: 없음
- 시작: 위치 권한이 있으면 4-2. 없으면 1-10 허용 후 4-2. 4-2를 닫으면 이 화면으로 돌아온다
- 이어가기: 4-3으로 푸시. 백그라운드 알림을 누른 경우와 같은 활동 id를 연다

## 접근성

- ② 대기 상태: "줍깅 대기, 지금 걸으며 주운 것을 기록해 보세요"
- ③ 진행 중 요약: "진행 중인 활동, 1.2킬로미터, 42분, 17개, 활동 이어가기"
- ④: "줍깅 시작" 또는 "활동 이어가기"
- 하단 탭·주 버튼은 44dp 이상이다

## 옛 화면과의 차이

- 옛 시작 시트의 혼자/근처 사람 선택과 참여 요청 받기 토글을 없앴다. 활동은 언제나 개인 단위다
- 위치 공유 토글은 4-2 활동 시작 시트가 맡는다
- 진행 중인 활동을 앱 재실행 뒤 이어가는 상태를 새로 추가했다

## 미결

- `GET /activities/current`의 Activity에 현재 일시정지 상태 필드가 없어 요약에서 "일시정지 중"을 확정해 보일 수 없다
- 대기 화면의 새싹 그림은 `design-system/assets/character/`에 별도 에셋이 없다
- 오프라인에서 이전에 기록한 활동을 이어갈 때 시작·종료 동기화 정책은 4-3·4-7과 함께 정리해야 한다
