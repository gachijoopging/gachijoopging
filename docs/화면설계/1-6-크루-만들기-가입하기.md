# 1-6 크루 만들기/가입하기

**목적** 아직 크루가 없는 사람이 새 크루를 만들거나, 받은 초대 코드로 가입 신청하는 길을 고른다.
**원본** `../legacy/android-res/layout/fragment_hood.xml` · **변경** 현재 위치·검색·후보 목록·개인정보 안내를 없애고, 두 선택 카드(크루 만들기 / 초대 코드로 가입하기)로 바꿨다. 동네 설정은 없다.
**진입** 1-3 이메일 가입 완료 · 1-4 닉네임 저장 뒤 `membership.status` NONE · 1-1·1-2 로그인 뒤 NONE · 5-7에서 크루 나가기 완료 뒤 · **이탈** 1-7 크루 만들기 · 1-8 초대 코드 입력 · 내 활동 기록 → 5-5 기록 전용 진입 → 5-3 · 뒤로 가기 → 앱 벗어나기

## 배치

옛 XML의 순서(헤더 → 짙은 알약 → 큰 제목·설명 → 본문 카드 영역 → 아래 고정 주 버튼)를 따른다. 검색·GPS·결과 목록이 있던 세로 본문을 두 선택 카드로 바꾸고, 아래 고정 버튼 자리는 쓰지 않는다. 두 카드는 제목·설명·오른쪽 화살표가 같은 높이로 쌓인다.

```
┌──────────────────────────────────────┐
│ ① ‹  크루 시작하기                    │
├──────────────────────────────────────┤
│ ② [🌱 크루 시작하기]                   │
│    함께 줍는 크루를 선택해 주세요        │
│    한 사람은 크루 하나에만 소속될 수 있어요│
│                                      │
│ ③ ┌────────────────────────────────┐ │
│    │ ＋  새 크루 만들기          ›  │ │
│    │    이름만 정하면 바로 시작해요 │ │
│    └────────────────────────────────┘ │
│                                      │
│ ④ ┌────────────────────────────────┐ │
│    │ #   초대 코드로 가입하기    ›  │ │
│    │    크루장에게 받은 코드를 입력해요│ │
│    └────────────────────────────────┘ │
│                                      │
│ ⑤ 크루장이 승인하면 크루원이 돼요.      │
│ ⑥ [내 활동 기록 보기]                  │
└──────────────────────────────────────┘
```

온보딩 완료 후 `GET /users/me`의 `membership.status`가 NONE일 때만 이 화면으로 온다. MEMBER면 2-1, PENDING이면 1-9로 간다. 이 화면은 크루 목록을 내려받지 않으므로 목록·검색·위치 기반 추천을 제공하지 않는다.

## 인터랙션

- 스크롤: 장식 여백부터 줄이고 작은 화면·큰 글씨에서는 헤더 아래 본문 전체 스크롤. 안내와 내 기록 진입을 보존한다
- 당겨서 새로고침: 없음
- 길게 누르기: 없음
- 시트: 없음
- 뒤로 가기: ①과 시스템 뒤로 가기는 앱을 벗어난다. 로그아웃·계정 삭제가 아니며 재실행 시 미완료 크루 선택을 이어간다
- 키보드: 없음
- 카드 탭: ③·④ 카드 전체가 터치 영역이다. 짧게 눌렀을 때만 푸시하며 중복 탭은 첫 전환이 시작되면 막는다
- 전환: 1-7·1-8은 푸시. 1-9·2-1은 소속 상태가 바뀐 경우에만 기존 온보딩 스택을 지우고 전환한다

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - ①: "뒤로, 앱 나가기"
  - ③: "새 크루 만들기, 이름만 정하면 바로 시작해요"
  - ④: "초대 코드로 가입하기, 크루장에게 받은 코드를 입력해요"
  - ⑤: "크루장이 승인하면 크루원이 돼요"
  - ⑥: "내 활동 기록 보기, 이전 크루의 내 기록 포함"
  - ②의 🌱와 카드의 장식 화살표는 읽지 않는다
- 최소 터치 크기 예외: 없음. ①·③·④는 모두 48dp 이상이며 카드 전체를 누를 수 있다

## 옛 화면과의 차이

- "우리 동네 설정"·"어디에서 함께 주울까요?"·현재 위치 찾기·동네 검색·후보 목록·행정동 개인정보 안내를 모두 없앴다. 새 앱에는 동네 개념이 없다
- 옛 `grantedCard`·`findByGps`·`deniedBanner`·`hoodInput`·`candidateList`·`noResult`·아래 "우리 동네로 설정하고 시작" 버튼 자리에 ③·④ 두 선택 카드를 넣었다
- GPS 권한을 여기서 묻지 않는다. 활동에 필요한 위치 권한은 1-10에서 다룬다
- 옛 화면은 선택을 저장하면 곧바로 시작했다. 새 화면은 크루 만들기는 곧 크루장이 되고, 초대 코드 가입은 1-9에서 승인 대기한다

## 미결

- 본인 기록 조회는 현재 크루 소속 없이도 허용하고 과거 크루 기록을 포함하도록 5-5·5-3 및 서버 인가를 맞춰 구현해야 한다.
