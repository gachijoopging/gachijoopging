# 2-1 홈

**목적** 크루의 최근 성과와 지금 뛰는 크루원을 한눈에 본다.
**원본** `../legacy/android-res/layout/fragment_home.xml` · **변경** 동네→크루, 지도→크루 캐릭터, 근처 사람→활동 중인 크루원
**진입** 하단 탭 홈 · 앱 실행 후 소속 크루가 있으면(MEMBER) 첫 화면 · 알림 딥링크의 기본 착지 · **이탈** 크루 정보(3-2) · 알림 목록(2-3) · 크루 기록(3-4) · 활동 중인 크루원 목록(2-2)

## 배치

옛 XML 의 세로 순서(상단 → offlineCard → weekCard → 지도 → nearbyCard·mineCard → 탭 바)를 그대로 따른다. 지도 자리에 크루 캐릭터가, nearbyCard 자리에 활동 중인 크루원이 들어간다. 한 화면에 다 들어가며 스크롤하지 않는다.

```
┌──────────────────────────────────────┐
│ ① 가치줍깅(워드마크)   [한강줍깅크루 ˅] 🔔● │
│    오늘도 가볍게 한 바퀴 🌱               │
├──────────────────────────────────────┤
│ ② (!) 수거 현황을 불러오지 못했어요 [다시 시도] │  ← 평소 숨김
├──────────────────────────────────────┤
│ ③ (⚡) 최근 7일 우리 크루가 주운 쓰레기      │
│    168 [개]                  ▂▅ ▇▄▆▃  │
│    크루 기록 보기 ›           최근 7일   │

│ ④                                    │
│           (크루 캐릭터 · 단계 5 파티)      │
│         ┌ 최근 14일 312개, 목표 달성! ┐    │  ← 탭하면 3초
│                                      │
├──────────────────┬───────────────────┤
│ ⑤-a 지금 활동 중인 │ ⑤-b 최근 7일        │
│     크루원        │     내가 주운 쓰레기   │

│ ⑥  홈   피드   줍깅   모이깅   내 정보     │

```

## 상태

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | ① 워드마크·인사·벨(점 없음)은 바로 보인다. 크루 알약은 이름 자리가 빈 알약. ③·④·⑤ 카드 자리에 `Loading` ("불러오는 중") 하나. ⑥ 탭 바 | 벨(2-3) · 탭 바. 크루 알약과 카드는 눌리지 않는다 |
| 새로고침 | 당겨서 새로고침. 위에 스피너가 돌고 이전 값이 그대로 남아 있다가 새 값으로 바뀐다. 실패하면 값은 그대로, `Snackbar` "새로고침에 실패했어요" | 전부 평소처럼 눌린다 |
| 빈 | **없음.** 크루에 소속돼야 이 화면에 오고, 소속이면 항상 응답이 있다. 0 도 값이다 — ③ "0 [개]", ⑤-a "0 · 지금 뛰는 크루원이 없어요", ⑤-b "0 · 아직 없어요", ④ 는 `stage` 1 축 처짐 | 평소와 같다 |
| 오류 | 서버 오류·인증 외 4xx/5xx. ③·④·⑤ 자리에 `ErrorState` ("불러오지 못했어요" / "연결 상태를 확인하고 다시 시도해 주세요." / [다시 시도]). ① 은 그대로(알약 이름 비어 있음) | 다시 시도 → `GET /crew/home` 재요청 · 벨 · 탭 바 |
| 오프라인 | 네트워크 없음. ② 오프라인 카드가 ①과 ③ 사이에 나타난다("수거 현황을 불러오지 못했어요" / "네트워크 연결을 확인하고 다시 시도해 주세요." / [다시 시도]). 이전에 받은 값이 있으면 ③·④·⑤ 는 그 값을 흐리지 않고 그대로 보인다. 없으면 ③·④·⑤ 자리는 비워 둔다(`ErrorState` 를 겹치지 않는다) | 다시 시도 → 재요청 · 이전 값이 있으면 카드도 눌린다 · 벨 · 탭 바 |
| 권한 거부 | **해당 없음.** 홈은 위치·카메라·알림 권한을 쓰지 않는다(위치 권한은 1-10 에서 다룬다) | — |
| 부분 실패 | **해당 없음.** 요청이 `GET /crew/home` 하나라 전체 성공 또는 전체 실패다 | — |

알림 점: `unreadNotifications` 가 0 이면 점을 그리지 않는다. 숫자는 점에 쓰지 않는다(개수는 2-3 에서 본다).

## 인터랙션

- 스크롤: 없음. 한 화면에 다 들어간다. ④ 캐릭터가 남는 높이를 흡수한다
- 당겨서 새로고침: 있음. 화면 어디서든 아래로 당기면 `GET /crew/home` 재요청. 화면으로 돌아올 때(탭 복귀·다른 화면에서 뒤로)도 조용히 다시 받는다
- 길게 누르기: 없음
- 시트: 없음
- 뒤로 가기: 하단 탭의 첫 화면이라 앱을 벗어난다(Android 기본). 말풍선이 떠 있으면 먼저 말풍선을 닫는다
- 키보드: 없음
- 캐릭터 탭: 캐릭터 위에 말풍선이 3초 떠 있다가 사라진다. 떠 있는 동안 다시 탭하면 바로 닫힌다
- 전환: 3-2 · 2-3 · 3-4 · 2-2 모두 푸시. 모달·시트 없음

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - 벨: "알림, 안 읽음 3개" (`unreadNotifications`). 0 이면 "알림"
  - 크루 알약: "한강줍깅크루, 크루 정보 보기"
  - 크루 캐릭터: "크루 캐릭터, 파티" 처럼 단계 이름을 붙인다. 탭 힌트 "목표 진행을 들으려면 두 번 탭"
  - 말풍선: 뜨는 순간 내용을 읽어 준다(live region)
  - ③ 카드: 카드 하나를 한 요소로 묶어 "최근 7일 우리 크루가 주운 쓰레기, 168개, 크루 기록 보기". 막대는 읽지 않는다(숫자가 대신한다)
  - ⑤-a 카드: "지금 활동 중인 크루원, 2명, 목록 보기". 얼굴은 읽지 않는다
  - ⑤-b 카드: "최근 7일 내가 주운 쓰레기, 23개, 담배꽁초 14, 플라스틱 6, 캔 3"
  - 워드마크·원 아이콘·chevron: 장식이라 읽지 않는다
- 최소 터치 크기 예외: 없음. 벨·크루 알약은 44dp 이상. 카드 3장은 카드 전체가 터치 영역이다

## 옛 화면과의 차이

- 동네 알약(`hoodButton`, 동네 선택 시트) → 크루 알약. 선택이 아니라 크루 정보로 이동한다. chevron 은 남긴다
- 지도(`view_map_frame`)·내 것 보기(`myOnlyChip`)·다시보기(`replayButton`)·전체화면 지도(`mapFullLayer`) → 모두 없음. 그 자리에 크루 캐릭터
- GPS 불안정 배너(`gpsBanner`) → 없음(지도가 빠졌다)
- "이번 주 우리 동네" → "최근 7일 우리 크루가 주운 쓰레기". 부제 "이웃 N명이 함께 줍고 있어요" → "크루 기록 보기 ›". 카드가 3-4 로 이동하게 됐다
- "지금 근처에서 함께 줍는 사람" → "지금 활동 중인 크루원". 원 아이콘(`ic_people`) 자리에 얼굴 최대 3개. 카드가 2-2 로 이동하게 됐다
- "이번 주 내가 주운 쓰레기" → "최근 7일 내가 주운 쓰레기". 부제 카테고리 분류(`mineBreakdown`)는 유지하되 최대 3개
- 오프라인 카드·문구·다시 시도 버튼은 그대로
- 당겨서 새로고침은 새로 생겼다(옛 화면은 지도 이동으로 다시 받았다)

## 미결

- 캐릭터 단계별 그림: `design-system/assets/character/` 에 `sprout.png` 1장만 있다. 5단계(축 처짐·보통·신남·반짝·파티) 그림이 필요하며 4장이 비어 있다
- 크루 알약이 길 때(크루 이름 최대 길이)의 말줄임 위치 — 크루 이름 글자 수 제한은 1-7 크루 만들기에서 정한다
