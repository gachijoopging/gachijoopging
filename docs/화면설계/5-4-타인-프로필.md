# 5-4 타인 프로필

**목적** 다른 크루원의 기본 정보·누적 기록·게시물을 보고, 팔로우·차단·신고(크루원) 또는 추방·위임(크루장)으로 그 사람과의 관계를 관리한다.
**원본** `../legacy/android-res/layout/fragment_user_profile.xml` · `sheet_safety.xml` · **변경** 친구 요청 → 팔로우(한 방향, 상대에게 안 보임), 신고/차단 2행 시트 → 뷰어 역할에 따라 행이 달라지는 시트(크루원: 신고·차단 / 크루장: 차단·추방·위임), 공개 게시글 그리드 하나 → 기록/게시물 탭 2개(기록에 활동 달력 추가)
**진입** 5-1·5-2 게시물 작성자 아바타 · 3-7 크루 채팅 말풍선 아바타 · 2-2 활동 중인 크루원 목록 · 3-11 크루원 관리 · 3-2 크루 정보 크루원 목록 · **이탈** 5-3 활동 기록 상세 · 5-2 게시물 상세 · 6-1 신고 · 뒤로 가기 · (자기 자신이면 5-5 내 정보로 대체)

## 배치

옛 XML 의 세로 순서(헤더 → 얼굴·이름·소개·통계 묶음 → 차단 배너 → 친구 버튼 → "공개 게시글" 그리드)를 그대로 따르되, 통계 한 줄은 5-5 내 정보와 같은 누적 3분할 카드로 키우고 게시글 그리드 앞에 기록/게시물 탭을 넣는다. 헤더만 고정하고 프로필·배너·누적·탭·목록 전체를 세로 스크롤한다. "기록" 탭을 고르면 목록 위에 활동 달력이 먼저 나온다.

```
┌──────────────────────────────────────┐
│ ① [< 뒤로]        상혁          [⋯]  │
├──────────────────────────────────────┤
│ ②  ╭────╮  상혁   👑크루장             │
│    │ 얼굴 │  한강 서쪽 자주 다녀요       │
│    ╰────╯  2026년 3월 5일 가입         │
│    [ 팔로우 ]                          │
│    활동을 시작하면 알려 드려요           │
├──────────────────────────────────────┤
│ ③ (!) 차단한 크루원이에요. 내 화면에서 │  ← 내가 차단했을 때만
│     개인 콘텐츠 숨김.      [차단 해제] │
├──────────────────────────────────────┤
│ ④   12          38.4km        412     │
│     활동          거리          개수     │
├──────────────────────────────────────┤
│ ⑤ [ 기록 ]  [ 게시물 ]                  │
├──────────────────────────────────────┤
│ ⑥ (최근 6개월 활동 달력 · 26주×7일 격자) │  ← 기록 탭에서만, 목록 맨 위
├──────────────────────────────────────┤
│ ⑦ ┌────────────────────────────────┐ │
│   │ (썸네일) 9월 5일(금) 오후 6:02    │ │
│   │  27        42분       3.1km      │ │
│   │  개수       시간       거리        │ │
│   └────────────────────────────────┘ │
│            불러오는 중…                 │  ← 다음 장 받을 때만
└──────────────────────────────────────┘
```

④ 에서 "게시물" 을 고르면 ⑥⑦ 자리가 5-5 와 같은 3열 사진 그리드로 바뀐다(달력은 기록 탭 전용이라 사라진다).

```
│ ⑥⑦┌────┐┌────┐┌────┐               │
│   │사진 ││사진 ││ 글  │                │
│   └────┘└────┘└────┘                │
```

## 안전 시트

⋯ 를 누르면 뜬다. 제목 "OOO님"(`nickname`, 옛 `up_menu_title`). 행 구성은 뷰어(나)의 역할에 따라 다르다 — 대상이 크루장인지가 아니라 **내가** 크루장인지로 갈린다. 권한표의 "게시물·사용자 신고" 행은 크루장이 "—" 라 신고 행은 크루원 뷰어에게만 준다(크루장은 신고를 접수·처리하는 쪽이라 자기가 신고를 낼 수는 없다).

| 행 | 크루원이 볼 때 | 크루장이 볼 때 | 탭하면 |
|---|---|---|---|
| 신고하기 | 있음 · "부적절한 행동을 알려 주세요" | 없음 | 6-1 신고 |
| 차단하기 | 있음 · "위치·음성·미니카드가 바로 숨겨져요" 문구는 무전 기능 삭제로 "내 게시물·댓글·채팅·위치 화면에서 바로 숨겨져요" 로 바꿔 씀 | 있음(동일) | 확인 대화상자 → `PUT /users/{userId}/block` |
| 크루원 추방 | 없음 | 있음(신규) · "크루에서 내보내요. 활동 기록은 남아요" | 확인 대화상자 → `DELETE /crew/members/{userId}` |
| 크루장 위임 | 없음 | 있음(신규) · "이 크루원이 크루장이 되고, 나는 일반 크루원이 돼요" | 확인 대화상자 → `PUT /crew/leader` |
| 닫기 | 있음 | 있음 | 시트 닫기 |

이미 차단한 상대(`blocked` true)면 "차단하기" 행 대신 "차단 해제" 행으로 바뀐다(② 의 차단 해제 버튼과 같은 동작).

확인 대화상자 문구:

- 차단: "OOO님을 차단할까요?" / "차단하면 내 게시물·댓글·채팅·위치 화면에서 이 크루원이 보이지 않아요. 크루 소속은 그대로예요." [차단](위험) [취소]
- 추방: "OOO님을 크루에서 추방할까요?" / "추방해도 활동 기록은 개인 기록과 크루 합산에 남아요. 미처리 사용자 신고가 함께 해결되고 신고자에게 결과를 알려요. 현재 유효한 초대 코드로 다시 가입 신청할 수 있어요." [추방](위험) [취소]
- 위임: "OOO님에게 크루장을 넘길까요?" / "위임하면 회원님은 크루장 권한을 잃고 일반 크루원이 돼요." [위임](위험) [취소]

성공하면 시트와 대화상자를 닫고 `Snackbar` — 차단 "OOO님을 차단했어요" · 차단 해제 "차단을 해제했어요" · 추방 "OOO님을 추방했어요"(화면도 닫고 이전 화면으로) · 위임 "크루장을 위임했어요"(② 배지가 바뀌고 내 ⋯ 시트도 다음부터 크루원용으로 바뀜). 실패하면 대화상자만 닫고 `Snackbar` "OOO에 실패했어요"(각 행동 이름을 넣는다), 화면 상태는 그대로.

## 인터랙션

- 스크롤: ① 헤더만 고정, ②③④⑤⑥⑦ 함께 세로 스크롤. 끝에 닿으면 `nextCursor` 로 다음 장을 이어 받는다
- 당겨서 새로고침: 있음. 지금 탭의 첫 장과 ②③④ 를 다시 받는다. 화면으로 돌아올 때(5-3·5-2·6-1 에서 뒤로)도 조용히 다시 받는다
- 길게 누르기: 없음
- 시트: ⋯ 를 누르면 안전 시트. 팔로우·차단 해제 버튼은 시트가 아니라 바로 요청(차단 해제만 확인 없이 즉시 처리 — 차단과 달리 위험하지 않다)
- 뒤로 가기: 진입 출처로 돌아간다(5-1·5-2·3-7·2-2·3-11·3-2). 시트·대화상자가 떠 있으면 먼저 닫는다
- 키보드: 없음
- 전환: 5-3 · 5-2 · 6-1 모두 푸시. 자기 자신이면 5-5 로 스택에 5-4 를 남기지 않고 대체. 안전 시트·대화상자는 모달

## 접근성

- 모든 내용과 동작을 유지한다. 작은 화면·큰 글자에서는 장식과 미리보기 높이를 먼저 줄이고 본문을 스크롤하며, 글자와 48dp 터치 영역은 줄이지 않는다.

- 스크린리더 라벨이 필요한 요소:
  - ① 뒤로: "뒤로 가기"
  - ① ⋯: 크루원 뷰어 "신고 또는 차단"(옛 `cd_report_block` 그대로) · 크루장 뷰어 "크루원 관리"
  - ② 아바타: 장식(이름과 함께 이미 읽힘이라 별도 라벨 없음)
  - ② 크루장 배지: 닉네임과 묶어 "상혁, 크루장"
  - ② 팔로우 버튼: "팔로우" 또는 "팔로우 중, 해제하려면 두 번 탭"
  - ③ 배너: 뜨는 순간 문구를 읽어 준다(live region)
  - ④ 3분할: 셋을 한 요소로 묶어 "누적 활동 12회, 거리 38.4킬로미터, 개수 412개"
  - ⑤ 탭: "기록 탭, 2개 중 1번째, 선택됨" / "게시물 탭, 2개 중 2번째"
  - ⑥ 달력: "최근 6개월 활동 달력, N일 활동" 정도로 요약해 읽고 칸 하나하나는 읽지 않는다
  - ⑦ 기록 카드: "9월 5일 금요일 오후 6시 2분, 27개, 42분, 3.1킬로미터, 활동 기록 상세로 이동"
  - ⑦ 게시물 칸: "게시물, 사진" 또는 "게시물, 글 앞부분을 읽는다"
  - 안전 시트 각 행: "차단하기, 내 게시물·댓글·채팅·위치 화면에서 바로 숨겨져요" 등 제목+설명을 묶어 읽는다
- 최소 터치 크기 예외: 없음. ① ⋯ 는 48dp. 팔로우·차단 해제 버튼은 sm 이지만 위아래 여백을 더해 48dp 를 채운다. 기록 카드는 카드 전체, 게시물 칸은 108dp 칸 전체가 터치 영역이다

## 옛 화면과의 차이

- 친구 요청 버튼(`friendButton`, "친구 요청"/"요청됨"/"수락"/"친구") → 팔로우 토글(`following`, "팔로우"/"팔로우 중"). 친구 관계가 없어져 수락 단계가 사라지고 한 방향·비공개 설정이 됐다
- "공개 게시글"(`up_public_posts`) 그리드 하나 → 기록/게시물 탭 2개. 기록 탭에는 옛 화면에 없던 누적 3분할과 활동 달력이 새로 붙는다(기능범위의 "기록: 누적 거리·개수·활동 달력·활동 상세")
- 차단 배너(`up_blocked` "차단한 사용자예요. 친구 요청을 할 수 없어요. 차단 관리에서 해제할 수 있어요.") → 새 문구로 교체하고 차단 관리(5-9)로 보내는 대신 이 화면에서 바로 해제한다(② 버튼 + ⋯ 시트 행)
- `sheet_safety.xml` 의 신고·차단 2행 고정 → 뷰어 역할에 따라 행이 달라진다(크루원: 신고·차단 / 크루장: 차단·추방·위임). 추방·위임은 신규 — 옛 앱엔 크루(모임) 운영 개념이 얕아 이런 행동이 없었다
- 통계 한 줄(`stats`, "N회 · N km" 같은 요약 텍스트로 추정) → 5-5 와 같은 큼직한 3분할 카드로 승격
- 소속 표시가 없던 자리에 크루장 배지(`isLeader`)와 가입일(`joinedAt`)이 새로 붙는다
- 헤더 더보기 버튼(`headerAction`, 기본 숨김)이 이 화면에서 켜지고 라벨이 `cd_report_block`("신고 또는 차단")로 바뀐다 — 크루장이 볼 때는 라벨을 다시 바꿔야 한다(신규 결정)
