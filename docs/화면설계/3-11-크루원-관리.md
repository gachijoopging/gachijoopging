# 3-11 크루원 관리

**목적** 크루장이 크루원 목록을 보고 크루장을 위임하거나 크루원을 추방한다.
**원본** `../legacy/android-res/layout/fragment_meet_manage.xml`의 크루원 카드 · **변경** 활동 참여자 목록을 지속되는 크루원 관리 목록으로 바꾸고, 추방·위임 행동을 추가했다. 크루장만 접근한다.
**진입** 3-2 크루 정보의 "크루원 관리" · 5-7에서 크루장 위임 안내 · **이탈** 5-4 타인 프로필 · 3-2 크루 정보 · 뒤로 가기 → 3-2

## 배치

옛 크루원 카드의 제목·세로 목록·안내 문구 순서를 따른다. 각 행은 아바타·닉네임·누적 줍기 수·가입일·크루장 배지와 더보기 버튼으로 구성한다.

```
┌──────────────────────────────────────┐
│ ① ‹  크루원 관리                      │
├──────────────────────────────────────┤
│ ② 크루원 18명                         │
│ ③ (◉) 관열  크루장  412개          ⋯ │
│    2026년 9월 1일 가입                 │
│ ③ (◉) 상혁          380개          ⋯ │
│    2026년 9월 2일 가입                 │
│ ④ 추방해도 활동 기록과 크루 합산은 남아요.│
└──────────────────────────────────────┘
```

관리 시트는 대상이 현재 크루장이 아니고 내 행이 아닐 때 [크루장 위임] · [크루원 추방]을 보인다. 현재 크루장 행과 내 행에는 시트를 열지 않는다. 위임은 `PUT /crew/leader`의 `userId`, 추방은 `DELETE /crew/members/{userId}`을 쓴다.

## 인터랙션

- 스크롤: 크루원 행을 세로 스크롤
- 당겨서 새로고침: 있음. `GET /crew/members` 재조회
- 길게 누르기: 없음
- 시트: 대상 크루원 더보기에서 관리 시트
- 뒤로 가기: 3-2로 팝한다. 시트·대화상자가 열렸으면 먼저 닫는다
- 키보드: 없음
- 행 탭: 자기 자신이면 5-5, 다른 크루원이면 5-4로 푸시
- 전환: 위임 성공 뒤 내 역할이 바뀌므로 3-2를 새로 받고 대체 전환한다

## 접근성

- ③: "상혁, 누적 380개, 2026년 9월 2일 가입, 크루원 관리"로 읽는다
- 크루장 행은 "관열, 크루장, 누적 412개"로 읽고 더보기는 없다
- 위임·추방 대화상자는 결과와 되돌릴 수 없는 영향을 읽는다
- 행·더보기·시트 버튼은 44dp 이상이다

## 옛 화면과의 차이

- 옛 활동 참여자 목록은 한 활동이 끝나면 사라졌다. 새 목록은 크루가 존재하는 동안의 크루원이다
- 옛 관리 화면에 없던 크루장 위임·크루원 추방을 추가했다
- 위치 공유 안내를 추방 뒤에도 기록이 남는다는 안내로 바꿨다

## 미결

- 크루원 목록 정렬 기준이 계약에 없다. 현재는 서버 응답 순서를 유지한다
- 추방된 사람이 같은 크루에 다시 신청할 수 있는지, 제한이 있는지 정책이 없다
- 위임 가능한 후보에서 차단 관계를 고려하는지 계약에 없다
