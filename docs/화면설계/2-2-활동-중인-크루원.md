# 2-2 활동 중인 크루원 목록

**목적** 지금 활동 중인 크루원의 진행 상황과 위치 공유 여부를 보고, 크루원의 프로필로 이동한다.
**원본** `../legacy/android-res/layout/fragment_friends.xml` · **변경** 친구·받은 요청 탭과 양방향 관계를 없애고, 활동 중인 크루원 한 목록으로 바꿨다. 위치는 공유한 크루원만 "위치 공유 중"으로 보인다.
**진입** 2-1 홈의 "지금 활동 중인 크루원" 카드 · 4-3 활동 중의 크루원 버튼 · 알림의 LIVE 대상 · **이탈** 5-4 타인 프로필 · 뒤로 가기 → 진입 화면

## 배치

옛 XML의 순서(헤더 → 탭 영역 → 로딩·빈 상태·목록 → 아래 안내)를 따른다. 친구/받은 요청 두 탭 자리에는 제목 아래 활동 수와 새로고침 아이콘만 놓고, 목록 행은 아바타·닉네임·진행 지표·위치 공유 상태로 재구성한다.

```
┌──────────────────────────────────────┐
│ ① ‹  활동 중인 크루원          ↻       │
├──────────────────────────────────────┤
│ ② 지금 2명이 활동 중이에요             │
├──────────────────────────────────────┤
│ ③ ┌────────────────────────────────┐ │
│    │ (◉) 상혁         활동 중        │ │
│    │     1.2km · 15분 · 9개           │ │
│    │     ● 위치 공유 중              │ │
│    └────────────────────────────────┘ │
│ ③ ┌────────────────────────────────┐ │
│    │ (◉) 지수         일시정지       │ │
│    │     400m · 5분 · 2개             │ │
│    │     위치를 공유하지 않아요       │ │
│    └────────────────────────────────┘ │
│                                      │
│ ④ 활동 중인 크루원의 위치는            │

└──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 뒤로 버튼 | "뒤로" | `Icon`(arrow-left) | 진입 화면 |
| ① | 헤더 제목 | "활동 중인 크루원" | `Txt` title | — |
| ① | 새로고침 버튼 | "새로고침" | `Icon`(refresh) | `GET /crew/live` 재조회 |
| ② | 활동 수 | `GET /crew/live` 배열의 길이. "지금 2명이 활동 중이에요" · 1명이면 "지금 1명이 활동 중이에요" | `Txt` subtitle | — |
| ③ | 크루원 행 | `user.photoUrl`·`user.nickname`·`activityId`·`startedAt`·`elapsedSec`·`distanceM`·`itemCount`·`paused`·`location` (`GET /crew/live`) | `ListRow` + `Avatar` + `Badge` | 5-4 |
| ③ | 아바타·닉네임 | `user.photoUrl`이 null이면 `user.nickname` 첫 글자. 닉네임 "상혁" | `Avatar` md + `Txt` body strong | 5-4 |
| ③ | 활동 상태 | `paused` false면 "활동 중", true면 "일시정지" | `Badge` green / neutral | — |
| ③ | 진행 지표 | `distanceM` 1000 미만은 "400m", 이상은 "1.2km" · `elapsedSec`은 "15분" 또는 "1시간 8분" · `itemCount`는 "9개" | `Txt` caption | — |
| ③ | 위치 공유 상태 | `location`이 있으면 "위치 공유 중", null이면 "위치를 공유하지 않아요". 좌표 자체는 이 목록에 숫자로 보이지 않는다 | `Txt` micro + `Dot` | — |
| ④ | 안내 문구 | "활동 중인 크루원의 위치는 위치 공유를 켠 경우에만 보여요." | `Banner` neutral | — |

`GET /crew/live` 뒤 갱신은 `docs/소켓.md`의 LIVE 이벤트를 따른다. LIVE_START는 행을 추가하고, LIVE_UPDATE는 `elapsedSec`·`distanceM`·`itemCount`·`paused`·`location`을 바꾸며, LIVE_END는 행을 뺀다. 목록은 차단한 크루원을 서버가 이미 걸러 낸 값만 받는다.

## 상태

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | ① 제목·뒤로·새로고침은 보이고 ②·③ 자리에 `Loading` "활동 중인 크루원을 불러오고 있어요" | ① 뒤로만 |
| 새로고침 | ③의 이전 행은 남기고 ① 새로고침 아이콘이 돈다. 소켓 LIVE 이벤트도 계속 반영한다 | 뒤로·각 행은 평소처럼 |
| 빈 | 빈 배열. `EmptyState` "지금 활동 중인 크루원이 없어요" / "크루원과 함께 다음 활동을 시작해 보세요." | 뒤로·새로고침 |
| 오류 | 첫 조회 4xx·5xx면 `ErrorState` "불러오지 못했어요" / "연결 상태를 확인하고 다시 시도해 주세요." | 다시 시도 → `GET /crew/live` |
| 오프라인 | 이전 목록이 있으면 그대로 보이고 ② 아래 `Banner` "인터넷 연결을 확인해 주세요.". 이전 값이 없으면 오류 상태 | 뒤로·새로고침 |
| 권한 거부 | **해당 없음.** 내 위치 권한을 쓰지 않는다. 위치 공유 여부는 서버가 준 `location` null 여부로만 보인다 | — |
| 부분 실패 | **해당 없음.** 목록 요청 하나와 소켓 LIVE 이벤트가 같은 데이터 모양을 갱신한다 | — |
| 소켓 끊김 | 기존 목록을 흐리지 않고 ② 아래 "실시간 연결이 끊겼어요. 다시 연결하고 있어요." `Banner`. 재연결 뒤 `GET /crew/live`으로 전체를 맞춘다 | 뒤로·새로고침 |

## 인터랙션

- 스크롤: ③ 행이 화면보다 많으면 세로 스크롤한다
- 당겨서 새로고침: 있음. `GET /crew/live`을 다시 부른다
- 길게 누르기: 없음
- 시트: 없음
- 뒤로 가기: 진입 화면으로 팝한다
- 키보드: 없음
- 행 탭: 행 전체(위치 공유 상태 포함)를 누르면 5-4 타인 프로필로 푸시한다. 자기 자신의 행은 5-5로 대체한다
- 전환: 5-4·5-5는 푸시. LIVE_END로 보고 있던 행이 사라져도 열린 프로필은 닫지 않는다

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - ① 새로고침: "활동 중인 크루원 새로고침"
  - ②: "지금 2명이 활동 중이에요"
  - ③: "상혁, 활동 중, 1.2킬로미터, 15분, 9개, 위치 공유 중, 프로필 보기"처럼 행 하나로 읽는다
  - 위치를 공유하지 않는 행은 "위치를 공유하지 않아요"로 읽고 지도·좌표가 없음을 분명히 한다
  - LIVE_START·LIVE_END로 활동 수가 바뀌면 ②를 live region으로 읽는다
- 최소 터치 크기 예외: 없음. ①·③은 44dp 이상이다

## 옛 화면과의 차이

- 친구 목록·받은 요청 탭·친구 요청 수락·거절·친구 검색을 모두 없앴다. 크루원은 별도 친구 관계가 없다
- 옛 목록 행의 친구 상태 대신 활동 상태·거리·시간·줍기 개수·위치 공유 상태를 보인다
- 옛 아래 안내(`fl_note`)는 친구 관계 설명이었다. 새 안내는 위치 공유가 선택이라는 설명으로 바꿨다
- 활동 중인 크루원만 보이므로, 활동을 끝낸 크루원은 LIVE_END와 함께 바로 목록에서 사라진다

## 미결

- 위치 공유 중인 크루원의 위치를 이 목록에서 지도 미리보기로도 보여 줄지 결정되지 않았다. 현재는 위치 공유 상태만 보이고, 좌표 지도는 4-3 활동 중 화면이 담당한다
- LIVE 이벤트 재연결 정책·재연결 대기 시간은 `소켓.md`에 화면별로 정해져 있지 않다. 현재는 끊김 배너와 전체 재조회로만 적었다
- 빈 상태 문구와 위치 공유 안내 문구는 새 문구다
