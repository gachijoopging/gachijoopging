# 5-1 피드

**목적** 크루원이 올린 게시물을 최신순으로 훑고, 좋아요를 누르고, 새 게시물을 쓴다.
**원본** `../legacy/android-res/layout/fragment_feed.xml` · `item_post.xml` · **변경** 동네 피드 → 크루 피드. 탭 "전체 / 친구" → "전체 / 나만 보기". 검색 버튼 → 달력(날짜로 찾기). 카드의 동네 이름이 빠지고 "나만 보기" 배지와 "내 글" 표시가 붙었다
**진입** 하단 탭 피드 · 게시물 작성(5-6) 완료 뒤 돌아옴 · **이탈** 게시물 상세(5-2) · 타인 프로필(5-4, 얼굴·닉네임) · 게시물 작성(5-6, 글쓰기)

## 배치

옛 XML 의 세로 순서(제목 줄 → 탭 2개 → 목록·로딩·빈 상태)를 그대로 따른다. 제목 줄 오른쪽의 검색 아이콘 자리에 달력 아이콘이, 그 옆 글쓰기 버튼은 그대로 있다. 탭 아래에 날짜 필터 알약 ③ 이 새로 들어가는데 평소에는 숨김이다. 카드는 옛 `item_post` 그대로 작성자 줄 → 사진(또는 글만 상자) → 글 → 좋아요·댓글 알약이다. 제목 줄·탭·날짜 알약은 고정이고 목록만 세로 스크롤한다.

```

│ ① 피드                    (📅) [+ 글쓰기] │
├──────────────────────────────────────┤
│ ② [ 전체 ]  [ 나만 보기 ]                │
├──────────────────────────────────────┤
│ ③ [ 9월 6일 이전 × ]                    │  ← 평소 숨김
├──────────────────────────────────────┤
│ ④ ┌────────────────────────────────┐ │
│   │ (◉) 상혁            10분 전      │ │
│   │ ┌──────────────────────────┐   │ │
│   │ │        (사진 1장)   [3장]  │   │ │
│   │ └──────────────────────────┘   │ │
│   │ 오늘 여의도 3km. 꽁초가 유난히…    │ │
│   │ [♥ 고마워요 6] [💬 댓글 2]         │ │
│   ├────────────────────────────────┤ │
│   │ (◉) 관열  [내 글]  🔒 나만 보기  어제 │ │
│   │ ┌──────────────────────────┐   │ │
│   │ │ 사진 없는 글은 연한 상자 안에   │   │ │
│   │ │ 세 줄까지…                 │   │ │
│   │ │ 전체 보기 →               │   │ │
│   │ └──────────────────────────┘   │ │
│   │ [♡ 고마워요 0] [💬 댓글 0]         │ │
│   └────────────────────────────────┘ │
│            불러오는 중…                 │  ← 다음 장 받을 때만
├──────────────────────────────────────┤
│ ⑤  홈   피드   줍깅   모이깅   내 정보     │
└──────────────────────────────────────┘
```

| ④ | 사진 | `media` (`Post`) 가 1장 이상일 때. 첫 장의 `thumbUrl` 을 190dp 높이, 가로 꽉, 가운데 잘라 채움. 받는 동안·실패하면 연한 바탕에 사진 아이콘 | `신규` 사진 틀 (옛 `bg_photo_placeholder`) + `Icon`(image-outline) | 5-2 게시물 상세 (`id`) |
| ④ | 장수 배지 | `media` (`Post`) 가 2장 이상일 때 사진 오른쪽 아래에 "3장". 1장이면 없음 | `Chip` (옛 `bg_pill_overlay` — 반투명 검정 위 흰 글자는 `신규`) | (사진과 같다) |
| ④ | 글 (사진 있음) | `text` (`Post`). 사진 아래 최대 3줄, 넘치면 말줄임. 비어 있으면 줄 자체를 그리지 않는다 | `Txt` body | 5-2 게시물 상세 |
| ④ | 글만 상자 | `media` (`Post`) 가 비어 있을 때 사진 자리 대신. 연한 상자 안에 `text` 최대 3줄 + 아래 "전체 보기 →" 초록 글자. 3줄 안에 다 들어가도 링크는 남긴다 | `Tile` + `Txt` body + `Txt` caption strong (옛 `bg_tile`) | 5-2 게시물 상세 |
| ④ | 좋아요 알약 | "고마워요 " + `likeCount` (`Post`). `liked` (`Post`) 가 true 면 채운 하트·선택 색, false 면 빈 하트 | `Chip` (옛 `Gachi.Chip.Choice`) + `Icon`(heart / heart-outline) | `liked` false → `PUT /posts/{postId}/like`, true → `DELETE /posts/{postId}/like`. 화면은 응답을 기다리지 않고 먼저 바뀐다(아래 상태 "좋아요 반영 중") |
| ④ | 댓글 알약 | "댓글 " + `commentCount` (`Post`) | `Chip` (옛 `Gachi.Chip.Choice`) + `Icon`(comment-outline) | 5-2 게시물 상세, 댓글 입력칸에 초점 |
| ④ | 카드 | 위 요소를 담는 카드. `items` (`GET /crew/posts`) 순서 그대로(서버가 `createdAt` 내림차순). 카드 사이 12dp | `Card` | 작성자 줄·알약을 뺀 나머지 전부 → 5-2 게시물 상세 |
| ④ | 다음 장 로딩 | 끝까지 스크롤하면 `nextCursor` (`GET /crew/posts`) 를 cursor 로 다음 장(limit 20)을 받는 동안 목록 아래 "불러오는 중…". `nextCursor` 가 null 이면 더 받지 않는다 | `Loading` | — |
| ⑤ | 하단 탭 | 홈 · 피드 · 줍깅 · 모이깅 · 내 정보. 피드 선택 상태 | `BottomNav` | 각 탭 |

작성자가 탈퇴했으면 서버가 `author.nickname` 을 "탈퇴한 크루원" 으로, `author.photoUrl` 을 null 로 준다(기능범위 회원 탈퇴). 카드는 그대로 보이되 얼굴·닉네임이 눌리지 않고 얼굴은 "탈" 이 아니라 사람 실루엣 아이콘(`Icon`(account-outline))이다. 차단한 사람의 게시물은 서버가 빼고 준다 — 화면이 거를 것은 없다.

## 인터랙션

- 스크롤: ①②③ 고정, ④ 만 세로 스크롤. 끝에 닿으면 `nextCursor` 로 다음 장(limit 20)을 이어 받는다. 받는 동안 목록 아래 "불러오는 중…", 실패하면 그 자리에 [다시 시도] 한 줄
- 당겨서 새로고침: 있음. 지금 탭·날짜 조건으로 첫 장을 다시 받는다. 화면으로 돌아올 때(5-2·5-4·5-6 에서 뒤로, 다른 탭에서 복귀)도 조용히 첫 장을 다시 받는다 — 5-2 에서 지운 게시물, 5-4 에서 차단한 사람의 글, 바뀐 좋아요·댓글 수가 여기서 맞춰진다. 스크롤 위치는 유지한다(맨 위로 올리는 건 작성 뒤 복귀만)
- 길게 누르기: 없음. 삭제·신고·차단은 5-2 의 메뉴(`sheet_post_menu`)에서 한다
- 스와이프: 없음
- 시트: 달력 아이콘 → 날짜 선택 시트. 오늘이 기본, 오늘 이후는 고를 수 없다. 월 단위 달력 하나와 아래 [이 날 이전 보기] · [필터 지우기](필터가 있을 때만). 고르면 시트가 닫히고 ③ 알약이 나타나며 첫 장부터 다시 받는다. 어느 날에 게시물이 있는지는 표시하지 않는다
- 뒤로 가기: 하단 탭 화면이라 앱을 벗어난다(Android 기본). 날짜 선택 시트가 떠 있으면 시트만 닫는다. 날짜 필터가 걸려 있어도 뒤로 가기가 필터를 지우지는 않는다
- 키보드: 없음
- 탭 전환: 목록을 비우고 `Loading` 을 보인 뒤 새 탭의 첫 장을 받는다. 날짜 필터는 탭을 바꿔도 유지된다
- 전환: 5-2 · 5-4 · 5-6 모두 푸시. 날짜 선택은 시트. 카드가 처음 뜰 때 옛 `layout_anim_list` 처럼 위에서 아래로 짧게 순서대로 나타난다(첫 장에만, 다음 장은 그냥 붙는다)

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - 달력: "날짜로 찾기". 필터가 걸려 있으면 "날짜로 찾기, 9월 6일 이전 보는 중"
  - 글쓰기: "글쓰기"("+" 는 읽지 않는다)
  - 탭: "전체, 선택됨" / "나만 보기"
  - ③ 알약: "9월 6일 이전, 필터 지우기"
  - 얼굴·닉네임: 묶어서 "상혁, 프로필 보기". 탈퇴한 크루원은 "탈퇴한 크루원" 만 읽고 버튼이 아니다
  - 내 글·나만 보기 배지: "내 글" / "나만 보기" 그대로 읽는다(🔒 는 읽지 않는다)
  - 사진: "게시물 사진, 3장 중 첫 장". 1장이면 "게시물 사진"
  - 카드 본문 영역(사진+글): 한 요소로 묶어 "상혁, 10분 전, 사진 3장, 오늘 여의도 3km…, 게시물 보기". 글이 3줄을 넘어도 전체를 읽는다
  - 좋아요 알약: "고마워요 6, 눌림" / "고마워요 6, 안 눌림". 누른 뒤 바뀐 숫자를 읽어 준다
  - 댓글 알약: "댓글 2, 댓글 쓰기"
  - 빈 상태 캐릭터·사진 자리 아이콘: 장식이라 읽지 않는다
- 최소 터치 크기 예외: 없음. 달력·글쓰기는 44dp 이상. 얼굴(38dp)은 닉네임까지 한 터치 영역이라 44dp 를 넘는다. 좋아요·댓글 알약은 높이가 낮아 위아래 여백까지 터치 영역에 넣어 44dp 를 채운다

## 옛 화면과의 차이

- 탭 "전체 / 친구" → "전체 / 나만 보기". 친구 관계가 없어졌고(기능범위 소셜), 나만 보기 게시물을 볼 자리가 필요했다
- 검색 버튼(`searchButton`) → 달력. 날짜 필터 알약 ③ 은 새로 생겼다
- 카드 부제 "10분 전 · 역삼동" → 시각만. 동네가 빠졌다. 시각이 작성자 줄 오른쪽 끝으로 갔다
- "내 글" 표시와 "🔒 나만 보기" 배지가 카드에 붙었다. 옛 피드 카드에는 없었고 배지는 프로필 그리드(`item_post_grid`)에만 있었다
- 사진 장수 배지(`photoBadge`)는 옛 XML 에 자리만 있고 문구가 없었다 → "3장" 으로 정했다
- 좋아요 알약 문구 "고마워요 N" · 댓글 알약 "댓글 N" · 글만 상자 "전체 보기 →" 는 그대로
- 빈 상태 "아직 우리 동네 소식이 없어요 / 첫 줍깅 이야기를 남겨 이웃에게 알려 보세요." → "아직 크루 소식이 없어요 / 첫 게시물을 남겨 보세요." CTA "글쓰기" 는 그대로. 친구 탭 빈 상태(CTA "사용자 검색")는 없어졌다. 아이콘(`ic_sprout`) 자리에 캐릭터
- 무한 스크롤(커서)·당겨서 새로고침·좋아요 즉시 반영은 새로 정했다. 옛 XML 에는 없다

## 미결

- **게시물에 활동 요약을 붙일 필드가 계약에 없다.** `Post` 는 `media` 만 있고 활동 id 가 없다. 기능범위대로 "활동 종료 화면의 피드에 올리기 = 요약 이미지를 첨부한 자유 게시물" 이라면 요약은 사진 한 장일 뿐이라 카드에 활동 칩을 그릴 수 없고, 카드에서 5-3 활동 기록 상세로 갈 수도 없다. 칩과 5-3 이동이 필요하면 `Post` 에 활동 참조(`activityId` 같은)가 필요하다. 여기서는 칩 없이 사진으로만 다뤘다
- **탈퇴한 작성자를 닉네임 문자열로만 안다.** `UserBrief` 에 탈퇴 여부 필드가 없어 `nickname` 이 "탈퇴한 크루원" 인지로 판단한다. 같은 닉네임을 쓰는 살아 있는 계정과 구별할 수 없다 — 닉네임 금지어로 막거나 `UserBrief` 에 플래그가 필요하다
- **날짜 선택의 번호.** `화면.md` 이동 지도에는 F → CAL1[날짜 선택] 이 있는데 색인에 번호가 없다. 여기서는 5-1 안의 시트로 다뤘다. 별도 화면으로 둘지, 3-9 활동 달력과 합칠지는 색인에서 정한다. 3-9 는 활동 내역용이라 이 화면의 `before` 와는 다른 것으로 봤다
- `before` 는 "그날 이전(포함)부터" 라 필터를 걸어도 그 이후 게시물만 빠질 뿐 목록 모양은 같다. 사용자가 "그 날의 게시물" 을 기대하면 어긋난다. 알약 문구를 "N월 D일 이전" 으로 써서 의미를 드러냈지만, 하루 단위로 보고 싶다면 계약에 종료 날짜가 하나 더 필요하다
- 글쓰기 버튼을 옛 자리(제목 줄 오른쪽 알약)에 그대로 뒀다. 떠 있는 둥근 버튼(FAB)으로 바꾸면 스크롤 중에도 보이지만 하단 탭과 겹친다 — 확정이 필요하다
- 장수 배지 "3장", 빈 상태 문구 3쌍, 스낵바 문구("좋아요를 반영하지 못했어요" · "삭제된 게시물이에요" · "게시물을 올렸어요")는 내가 정한 안이다
- 마지막에 본 탭을 기억하는지(여기서는 기억)와, 작성 뒤 복귀 때 나만 보기 게시물이면 탭을 바꿀지(여기서는 안 바꿈)는 정한 대로 확정이 필요하다
- 빈 상태 캐릭터: `design-system/assets/character/` 에 "게시물 없음" 그림이 아직 없다(기능범위 로고·캐릭터 결정의 빈 상태 3장 중 하나)
