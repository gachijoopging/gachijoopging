# 1-9 승인 대기

**목적** 비공개 크루에 가입 신청을 낸 사람이 어느 크루의 승인을 기다리는지 확인하고, 원하면 요청을 취소해 크루 선택으로 돌아간다. 거절됐으면 거절 안내를 한 번 보여 주고 확인을 받는다. 승인 대기는 크루원이 아니므로 이 화면 밖의 앱 기능은 열리지 않는다.
**원본** 신규 — `fragment_invite_redeem.xml`의 가운데 상태 묶음과 `view_empty_state.xml`의 안내 구성을 재조립 · **변경** 옛 초대는 승인 없이 바로 소속됐다. 새 화면은 비공개 크루 가입 신청 뒤 PENDING 상태를 명확히 보여 주고 취소를 제공한다. 공개 크루 가입은 바로 크루원이 되어 이 화면에 오지 않는다.
**진입** 1-8 크루 검색에서 `POST /crews/join-requests` 201·200 의 `status` PENDING · 첫 로그인·재로그인·앱 실행·복귀 때 `GET /users/me` 의 `membership.status` PENDING, 또는 NONE 이면서 `membership.rejection` 이 있을 때 · 1-7·1-8 의 409 JOIN_REQUEST_PENDING · JOIN_REJECTED 푸시 · **이탈** 승인됨 → 2-1 홈 · 요청 취소 → 1-6 · 거절 안내 [확인] → 1-6 · 설정 → 5-7(로그아웃·탈퇴만) · 시스템 뒤로 가기 → 앱 종료

## 배치

옛 초대 처리 화면의 가운데 정렬 상태 묶음(아이콘 → 제목 → 설명 → 보조 행동)을 따른다. 서버에서 받은 크루 이름을 큰 카드로 보이고, 아래에 크루장 승인 안내와 요청 취소 버튼을 둔다. 수동 확인 버튼을 제공하고 작은 화면·큰 글씨에서는 장식 여백부터 줄인 뒤 본문 전체를 스크롤한다.

```
 ┌── 승인 대기 (PENDING) ────────────────┐   ┌── 거절 안내 (미확인 거절) ─────────────┐
 │ ①             ⏳                       │   │ ①             ✕                        │
 │  한강줍깅크루 크루 가입 승인 대기 중입니다. │   │  가입 신청이 승인되지 않았어요            │
 │                                      │   │                                      │
 │ ② ┌────────────────────────────────┐ │   │ ② ┌────────────────────────────────┐ │
 │    │  한강줍깅크루                    │ │   │    │  한강줍깅크루                    │ │
 │    │  크루장이 승인하면 크루원이 돼요    │ │   │    │  다른 크루를 찾거나 다시 신청할 수 │ │
 │    └────────────────────────────────┘ │   │    │  있어요                         │ │
 │                                      │   │    └────────────────────────────────┘ │
 │ ③ [          요청 취소          ]      │   │ ⑤ [             확인             ]    │
 │ ④ [          다시 확인하기      ]      │   │                                      │
 └──────────────────────────────────────┘   └──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| 헤더 | 제목·설정 | "가입 신청" + 톱니 아이콘. 뒤로 화살표는 두지 않는다. 승인 대기 중에도 로그아웃·탈퇴할 수 있게 한다 | `AppHeader` + `IconButton`(cog-outline) | 5-7 설정 |
| ① | 상태 아이콘 | 대기 모래시계 · 거절 닫힘 원 | `Icon`(timer-sand · close-circle-outline) | — |
| ① | 큰 제목 | 대기 "{크루명} 크루 가입 승인 대기 중입니다." (회의 확정 문구) · 거절 "가입 신청이 승인되지 않았어요". 크루명은 `membership.crew.name`·`membership.rejection.crew.name` (`GET /users/me`), 조회 뒤에는 `crew.name` (`GET /crews/join-requests/mine`) | `Txt` display | — |
| ② | 신청 크루 카드 | `crew.name` · 부제 대기 "크루장이 승인하면 크루원이 돼요" · 거절 "다른 크루를 찾거나 다시 신청할 수 있어요" | `Card` + `Txt` title + `Txt` caption | — |
| ③ | 요청 취소 버튼 | "요청 취소" (회의 확정 문구). PENDING 일 때만 | `Button` ghost lg | 확인 대화상자 → `DELETE /crews/join-requests/mine` → 1-6 |
| ④ | 상태 확인 | "다시 확인하기". PENDING 일 때만. 당겨서 새로고침과 같은 일 | `Button` soft lg | `GET /users/me`·`GET /crews/join-requests/mine` 재조회 |
| ⑤ | 거절 확인 버튼 | "확인". 거절 안내일 때만 | `Button` primary lg | `POST /crews/join-requests/{requestId}/read` (`requestId` = `membership.rejection.requestId` 또는 `GET /crews/join-requests/mine` 의 `id`) → 1-6 |

이 화면이 무엇을 보일지는 `GET /users/me` 의 `membership` 이 정한다.

| `membership` | 보이는 것 |
|---|---|
| `status` MEMBER | 이 화면을 거치지 않고 2-1 (대기 중 승인된 경우 포함) |
| `status` PENDING | 승인 대기. 크루 탭·활동 시작·알림·내 기록 등 다른 기능은 열지 않는다 |
| `status` NONE, `rejection` 있음 | 거절 안내. [확인]을 누르기 전에는 1-6 으로 가지 않는다 |
| `status` NONE, `rejection` null | 이 화면이 아니라 1-6 |

이 화면에서 다시 확인할 때는 `GET /crews/join-requests/mine` 의 `data.status` 를 본다. PENDING 이면 그대로, APPROVED 면 `GET /users/me` 로 MEMBER 를 확인한 뒤 2-1, REJECTED 면 거절 안내로 바뀐다. CANCELED 나 `data` null 이면(다른 기기에서 취소) 1-6 으로 간다.

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | ① 아이콘은 보이고 ② 카드 자리는 `Loading` "신청을 확인하고 있어요". ③·④·⑤ 숨김 | 헤더 설정 |
| 새로고침 | 푸시 수신·앱 복귀·④ 수동 확인·당겨서 새로고침 때 ② 값은 남기고 상단에 작은 스피너 | 조회 중 ③·④ 중복 요청 잠금 |
| 빈 | **해당 없음.** 신청이 없으면 1-6 으로 간다 | — |
| 오류 | 첫 조회가 4xx·5xx면 "신청을 불러오지 못했어요" / "네트워크 상태를 확인하고 다시 시도해 주세요." `ErrorState` | 다시 시도 → 재조회 |
| 오프라인 | 이전 카드가 있으면 그대로 보이고 ② 아래 `Banner` "인터넷 연결을 확인해 주세요.". 값이 없으면 오류 상태 | ③·⑤ 는 누르면 실패 `Snackbar` |
| 권한 거부 | **해당 없음.** 위치·카메라·사진·알림 권한을 쓰지 않는다 | — |
| 부분 실패 | 신청 APPROVED 뒤 내 소속 재조회 실패면 승인 확인 중 안내와 재시도. 성공을 추정해 이동하지 않는다 | 상태 확인 재시도 |
| 승인됨 | `membership.status` MEMBER 확인. `Snackbar` "크루 가입이 승인됐어요." 뒤 2-1으로 전환 | 전환 전 모두 비활성 |
| 거절 안내 | 오른쪽 그림. ⑤ 만 보인다 | ⑤ · 헤더 설정 |

| 취소 중 | ③ 라벨 자리에 스피너. 모두 비활성 | 없음 |

요청 취소 확인 대화상자: 제목 "가입 요청을 취소할까요?" · 본문 "취소하면 다른 크루를 찾거나 만들 수 있어요. 이 크루에 들어가려면 다시 신청해야 해요." · 버튼 줄 [계속 기다리기] ghost / [요청 취소] danger. 204면 `Snackbar` "가입 요청을 취소했어요." 뒤 1-6으로 간다. 4xx·5xx·오프라인이면 대화상자를 닫고 "요청을 취소하지 못했어요. 다시 시도해 주세요." `Snackbar`, PENDING 카드를 유지한다.

## 인터랙션

- 스크롤: 작은 화면·큰 글씨에서는 장식부터 줄인 뒤 본문 전체 스크롤. 거절 설명과 버튼을 보존한다
- 당겨서 새로고침: 승인 대기일 때만 있다
- 길게 누르기: 없음
- 시트: 없음
- 뒤로 가기: 헤더에 뒤로 화살표는 없다. 시스템 뒤로 가기는 신청·거절 안내를 그대로 둔 채 앱을 종료한다. 다시 열면 `membership` 분기로 이 화면에 온다
- 키보드: 없음
- 다른 크루: 승인 대기 중에는 이 화면에서 검색·만들기로 가는 길이 없다. [요청 취소] 뒤 1-6 에서 한다
- 전환: 1-9→2-1은 신청 화면과 1-6·1-8을 스택에서 지운다. 취소 완료·거절 확인 뒤 1-6 대체 전환. 거절은 자동으로 넘기지 않는다
- 개별 거절 사유 입력·전달은 하지 않는다. 거절된 사람은 같은 비공개 크루에 바로 다시 신청할 수 있다

## 옛 화면과의 차이

- 옛 초대 화면은 스피너 뒤 곧바로 소속되는 흐름이었다. 새 화면은 가입 신청 PENDING을 독립 화면으로 유지한다
- 옛 다시 시도·취소 텍스트 버튼은 상태 오류에만 있었고, 새 [요청 취소]는 사용자가 대기 자체를 끝내는 행동이다
- 초대 링크·모임 용어·즉시 참여 메시지를 없애고 크루장 승인·크루원 용어로 바꿨다
- 2026-10 회의: 큰 제목·취소 버튼을 확정 문구("{크루명} 크루 가입 승인 대기 중입니다." · [요청 취소])로 바꿨다. 거절 안내는 재로그인 때도 보이고 [확인]으로 한 번만 확인한다(`membership.rejection`). 신청이 없을 때의 빈 상태는 1-6 으로 대신한다

## 미결

- 승인 대기 중인 사람의 본인 기록 진입로. 미가입자 모두 본인 기록을 볼 수 있지만 이 화면에는 기록으로 가는 버튼이 없다(1-6 에만 있다). 여기에도 둘지 확인 필요(`feature-scope.md` §미결)
