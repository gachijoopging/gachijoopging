# 3-4 크루 기록

**목적** 기간별 크루 전체 활동 성과와 크루원 순위를 보고, 크루장은 기간을 골라 CSV로 내보낸다.
**원본** `../legacy/android-res/layout/fragment_group_record.xml` · **변경** 내 기록/전체 기록 탭과 지도·개인 기여 상자를 없애고, 크루 전체 통계·추이·순위·CSV 내보내기로 바꿨다.
**통합** 3-1 모이깅의 달력/기록 탭으로 합쳤다. 별도 화면은 없다. 아래 ①(헤더)은 없고 ②~⑥ 이 3-1 의 기록 탭이다. ⑦ CSV 내보내기는 3-11 크루원 관리(크루장)에서 연다
**진입** 3-1 모이깅의 기록 탭 · 2-1 홈의 최근 7일 카드(기록 탭으로) · **이탈** 5-4 타인 프로필

## 배치

옛 XML의 순서(헤더 → 탭 → 지도 → 지표 행 → 카테고리 칩 → 크루원 목록 → 공유 버튼)를 따른다. 지도 자리에는 기간 선택과 일별 막대, 내/전체 탭 자리에는 이번 주·이번 달·전체 기간 칩을 둔다. 크루원 목록은 순위 카드가 된다.

```
┌──────────────────────────────────────┐
│ ① ‹  크루 기록                        │
├──────────────────────────────────────┤
│ ② [이번 주] [이번 달] [전체]           │
│ ③ ▂▅▇▄▆▃▅  9월 7일 ~ 9월 13일          │
├──────────────────────────────────────┤
│ ④  1,430개   128.0km   26시간40분  62회 │
│      개수       거리       시간     활동 │
├──────────────────────────────────────┤
│ ⑤ [담배꽁초 620] [플라스틱 310] ...    │
│ ⑥ 크루원 순위                         │
│    1  (◉) 관열  412개 · 30.1km        │
│    2  (◉) 상혁  380개 · 28.8km        │
└──────────────────────────────────────┘
```

## 요소

| ② | 기간 칩 | `range` (`GET /crew/stats`) WEEK "이번 주" · MONTH "이번 달" · ALL "전체" | `Chip` `selected` | 기간 재조회 |
| ③ | 일별 막대 | `series[].date`·`series[].items` (`GET /crew/stats`). WEEK·MONTH는 일별, ALL은 월별 줍기 수를 막대로 표시 | `신규` 막대 그래프 (옛 `view_map_frame` 자리) + `Txt` micro | — |

| ⑤ | 카테고리 칩 | `byCategory`를 수량 내림차순으로 최대 7개. "담배꽁초 620" | `Chip` | — |

거리 `distanceM`은 1000 미만이면 "820m", 이상이면 "128.0km". `durationSec`은 "26시간 40분" 또는 "42분"으로 표시한다.

CSV 기간 선택 시트(3-11 크루원 관리에서 연다): 제목 "기록 내보내기" · 시작일/종료일 입력 · [취소] / [CSV 내보내기]. 시작일이 종료일보다 늦으면 "시작일은 종료일보다 앞서야 해요.". `GET /crew/export` 200의 `text/csv; charset=utf-8` 파일을 시스템 공유 시트로 보낸다. 실패하면 "CSV를 만들지 못했어요. 다시 시도해 주세요." `Snackbar`.

## 인터랙션

- 스크롤: 장식·그래프 높이를 먼저 줄이고 ②~⑦ 본문은 세로 스크롤한다. 글자·48dp 터치 크기는 줄이지 않는다
- 당겨서 새로고침: 있음. 현재 `range`로 `GET /crew/stats` 재조회
- 길게 누르기: 없음
- 시트: 없음. CSV 시트는 3-11 에 있다
- 기간 전환: ②의 칩을 누르면 선택 상태가 즉시 바뀌고 ③~⑥만 `Loading`으로 갱신한다
- 순위 행 탭: 내 행은 5-5, 다른 크루원은 5-4로 푸시
- 전환: 5-4·5-5는 푸시

## 접근성

- ②: 선택된 기간을 "이번 주, 선택됨"처럼 읽는다
- ③: 막대 하나씩이 아니라 요약 "이번 주, 총 1,430개"를 읽는다
- ④: "1,430개, 128킬로미터, 26시간 40분, 활동 62회"를 하나로 읽는다
- ⑤: 각 칩은 "담배꽁초 620개"처럼 읽는다
- ⑥: "1위, 관열, 412개, 30.1킬로미터, 프로필 보기"로 읽는다
- 모든 버튼은 48dp 이상이다

## 옛 화면과의 차이

- 옛 내 기록/전체 기록 탭은 제거했다. 크루 하나의 기간 통계를 모두에게 같은 모양으로 보여 준다
- 옛 지도·GPS 약함 칩·내 기여 상자·피드 공유 버튼을 없애고, 일별 막대·4분할 통계·순위·CSV 내보내기를 넣었다
- 옛 크루원 목록은 참석자 목록이었다. 새 목록은 선택 기간의 줍기 수 순위다
- CSV는 크루장만 쓸 수 있고 활동 한 회가 한 행이다

- 기간은 KST(Asia/Seoul) 기준이다. WEEK는 이번 주 월요일 00:00부터 다음 월요일 직전, MONTH는 이번 달 1일부터 다음 달 1일 직전이며 미래 데이터는 포함하지 않는다. 홈의 최근 7일·14일 이동 창은 그대로 유지한다.
- 순위는 선택 기간 줍기 수(`items`) 내림차순이며 동점자는 같은 순위다. 서버의 `rank`를 표시하고 거리로 동점을 깨지 않는다. ALL의 추이는 월별 합계다.

- CSV의 파일명 규칙·기본 날짜 범위는 미정이다
