# 2-3 알림 목록

**목적** 나에게 온 알림을 시간순으로 보고, 누르면 그 일이 벌어진 화면으로 간다. 크루장은 처리해야 할 가입 신청·신고를 목록 위에서 먼저 본다.
**원본** `../legacy/android-res/layout/fragment_notification.xml` · `item_notification.xml` · **변경** 친구 요청·모임 초대가 빠지고 신고 처리 결과를 포함한 크루 알림으로 바뀌었다. 활동 시작 알림은 팔로우한 크루원 것만 온다. 크루장 처리 대기 묶음과 시각을 표시한다
**진입** 홈(2-1)·모이깅(3-1) 벨 · 푸시 대상이 삭제되거나 접근 불가일 때 안내 뒤 · 신고 처리 결과 푸시 · **이탈** 가입 신청 관리(3-8) · 신고 처리(6-2) · 게시물 상세(5-2) · 공지 상세(3-6) · 크루 채팅(3-7) · 활동 중인 크루원(2-2) · 뒤로 가기 → 진입 화면(앱 시작 푸시는 소속에 따라 2-1 또는 1-6)

푸시는 `target`에 해당하는 화면을 바로 연다. 목록을 한 번 더 누르게 하지 않는다. 인증·온보딩이 필요하면 먼저 완료한 뒤 이동하며, 대상 삭제·접근 불가이면 이유를 알리고 이 목록으로 돌아온다. 본인 알림은 비소속이어도 볼 수 있다.

## 배치

옛 XML 의 세로 순서(헤더 → 로딩·빈 상태 → 모두 읽음 링크 → 목록 → 안내 문구)를 그대로 따른다. 헤더만 고정이고 그 아래가 통째로 세로 스크롤이다. 크루장 처리 대기 묶음 ② 는 옛 화면에 없던 자리로, 모두 읽음 링크와 목록 사이가 아니라 헤더 바로 아래에 둔다 — 처리할 일이 읽음 여부보다 먼저다. 목록 항목은 옛 `item_notification` 그대로 원 아이콘 · 제목(+안 읽음 점) · 부제 · chevron 이다. 날짜별 묶음은 옛 화면에 없었고 여기서도 하지 않는다.

## 인터랙션

- 스크롤: 헤더 아래가 세로 스크롤. 끝에 닿으면 `nextCursor` 로 다음 장(limit 20)을 이어 받는다. 받는 동안 목록 아래 "불러오는 중…", 실패하면 그 자리에 [다시 시도] 한 줄
- 당겨서 새로고침: 있음. 첫 장과 읽지 않음 수를 다시 받는다. 가입 신청·신고 처리 등에서 돌아오면 pending·unread를 조용히 재조회해 완료된 처리 대기 수를 갱신한다. 기존 목록·스크롤은 응답 전까지 유지한다
- 길게 누르기: 없음
- 스와이프: 없음. 알림은 지우지 않는다(옛 화면과 같다)
- 시트: 없음
- 뒤로 가기: 진입 화면으로 팝한다. 앱 시작 푸시의 기본 화면은 소속이면 2-1, 비소속이면 1-6이다. 홈 복귀 때 벨 점을 다시 확인한다
- 키보드: 없음
- 전환: 목록에서 3-8 · 6-2 · 5-2 · 3-6 · 3-7 · 2-2로 푸시한다. 푸시는 같은 target 규칙으로 바로 착지하고 읽음을 요청한다. POST_REMOVED·REPORT_RESOLVED는 이유·결과를 안내하고 목록을 유지한다

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - 뒤로: "뒤로"
  - 부제: 나타날 때와 숫자가 바뀔 때 읽어 준다(live region) — "읽지 않음 3" / "모두 읽었어요"
  - ② 행: "가입 신청 2건이 기다리고 있어요, 가입 신청 관리로 이동". 배지 숫자는 문장에 이미 있으니 따로 읽지 않는다
  - ③: "모두 읽음"("✓" 는 읽지 않는다). 비활성이면 비활성으로 읽힌다
  - ④ 행: 행 하나를 한 요소로 묶어 "안 읽음, 상혁 님이 줍깅을 시작했어요, 여의도 근처, 5분 전". 읽은 항목은 "안 읽음" 을 빼고 읽는다. 점·원 아이콘·chevron 은 장식이라 읽지 않는다(옛 `importantForAccessibility="no"` 그대로)
  - 빈 상태 캐릭터: 장식이라 읽지 않는다
- 최소 터치 크기 예외: 없음. ②④ 행은 행 전체가 터치 영역(높이 56dp 이상). ③ 링크는 위아래 여백까지 터치 영역에 넣어 48dp를 채운다

## 옛 화면과의 차이

- 알림 종류는 크루 가입·활동·콘텐츠·신고 처리 결과로 정리했다. 활동 시작 알림은 팔로우한 크루원 것만 온다
- 처리 대기 묶음 ② 는 새로 생겼다 — 크루장에게만 보이고, 목록 항목이 아니라 개수 행이다
- 옛 빈 상태 설명 "모임과 댓글, 친구 소식이 여기에 모여요." 를 없앴다. 아이콘(`ic_sprout`) 자리에 캐릭터
- 항목 부제에 시각을 붙였다. 옛 항목은 제목·부제만 있었다
- 안 읽음 점 색: 옛 주황(`bg_dot_orange`) → deep. 주황은 한 화면에 한 번만 쓰는 강조색이라 여러 줄에 반복되는 점에는 맞지 않는다
- 헤더 부제 "읽지 않음 N" / "모두 읽었어요", 모두 읽음 링크, "목록을 열어 보는 것만으로는…" 안내 문구는 그대로
- 옛 `nt_no_active_session`("진행 중인 활동이 없어 참여 요청을 확인할 수 없어요")은 함께줍깅 참여 요청용이라 없어졌다
- 무한 스크롤(커서)과 당겨서 새로고침은 새로 생겼다. 옛 화면은 한 번에 전부 받았다
- 알림 권한 배너는 새로 생겼다(옛 앱은 Android 13 이전 대상이었다)

## 미결

- 알림 없음 캐릭터 제작과 실제 푸시 착지·중복 이벤트·읽음 재시도 검증이 필요하다
- CHAT 알림의 메시지별 발송·묶음 발송 기준은 서버 알림 정책에서 정해야 한다. 댓글 알림은 현재 계약대로 게시물 화면을 열며 특정 댓글 강조는 제공하지 않는다
