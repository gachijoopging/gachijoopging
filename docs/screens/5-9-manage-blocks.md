# 5-9 차단 관리

**목적** 내가 차단한 크루원 목록을 보고, 필요하면 차단을 해제한다.
**원본** `../legacy/android-res/layout/fragment_blocklist.xml` (행 `item_user_row.xml`, 검색·친구·차단 공통 행) · **변경** 대상이 친구→크루원, 행 설명 문구가 크루 용어로 바뀌었다. 해제는 5-4 타인 프로필과 같이 확인 없이 즉시 처리(낙관적)한다. 당겨서 새로고침이 새로 생겼다
**진입** 5-7 설정 "차단 관리" 행 · **이탈** 5-4 타인 프로필(행 탭, 탈퇴한 크루원 제외) · 뒤로 가기 → 5-7

## 배치

옛 XML 의 세로 순서(헤더 → 로딩·빈 상태 → 목록)를 그대로 따른다. 헤더만 고정, 그 아래가 통째로 세로 스크롤이다(옛 `ScrollView` 그대로). 목록 항목은 옛 `item_user_row` 그대로 얼굴·이름·부제 묶음과 오른쪽 액션 버튼이다. 옛 화면엔 없던 헤더 부제(차단 인원 수)를 2-3 알림과 같은 자리에 새로 넣었다.

차단은 내가 보는 개인 콘텐츠에만 적용한다. 차단 성공 즉시 해당 게시물·댓글·채팅·실시간 위치 캐시와 화면을 숨기고, 공식 공지와 크루장의 필수 관리 정보는 남긴다. 상대 화면에는 영향을 주지 않는다.

해제. 확인 없이 낙관적으로 먼저 지우고, 실패하면 되돌린다.

| 순서 | 하는 것 | 결과 | 다음 |
|---|---|---|---|
| 1 | [차단 해제] 를 누르면 목록에서 그 행을 바로 지우고(낙관적) `DELETE /users/{userId}/block` 전송 | — | 행이 바로 사라진다 |
| 2 | 같은 요청 | 204 | 차단 필터를 해제하고 관련 목록을 다시 받는다. `Snackbar` "차단을 해제했어요"(5-4 와 같은 문구) |
| 2 | 같은 요청 | 4xx/5xx/오프라인 | 지웠던 행을 원래 자리에 되돌리고 `Snackbar` "차단 해제에 실패했어요. 다시 시도해 주세요." |

## 인터랙션

- 스크롤: 헤더 아래가 세로 스크롤(옛 `ScrollView` 그대로). 끝에 닿으면 `nextCursor` 로 다음 페이지를 붙인다(null 이면 멈춤)
- 당겨서 새로고침: 있음. 화면으로 돌아올 때(5-4 에서 뒤로)도 조용히 다시 받는다
- 길게 누르기: 없음
- 시트: 없음. 확인 대화상자 없음(5-4 와 동일하게 즉시 처리)
- 뒤로 가기: 5-7 설정으로 돌아간다(pop)
- 키보드: 없음
- 전환: 5-4 는 푸시

## 접근성

- 모든 내용과 동작을 유지한다. 작은 화면·큰 글자에서는 장식과 미리보기 높이를 먼저 줄이고 본문을 스크롤하며, 글자와 48dp 터치 영역은 줄이지 않는다.

- 스크린리더 라벨이 필요한 요소:
  - 뒤로: "뒤로 가기"
  - 부제: "차단 3명" 그대로 읽는다
  - 행: 아바타·닉네임·부제를 묶어 "상혁, 차단됨, 게시물, 댓글, 채팅, 위치에서 숨김, 프로필 보기"로 읽고, 별도로 "차단 해제, 상혁님"을 이어 읽는다
  - 탈퇴한 크루원 행: "탈퇴한 크루원, 차단됨" — 프로필 이동 힌트는 붙이지 않는다
  - 아바타: 장식(이름과 함께 이미 읽힘)
- 최소 터치 크기 예외: 없음. 해제 버튼은 sm 이지만 위아래 여백을 더해 48dp 를 채운다(5-4 의 팔로우 버튼과 같은 처리). 행의 아바타·닉네임·부제 영역은 그 자리 전체가 터치 영역이다

## 옛 화면과의 차이

- 대상이 친구(`friend`)에서 크루원으로 바뀌었다. 화면 구조·행 재사용(`item_user_row`)은 그대로다
- 행 부제 "차단됨 · 피드와 모임에서 숨김"(`bl_row_desc`) → "차단됨, 게시물, 댓글, 채팅, 위치에서 숨김". 5-4 의 차단 배너·안전 시트 문구("게시물, 댓글, 채팅, 위치 화면에서 보이지 않아요")와 같은 범위를 짧게 줄였다
- 빈 상태 제목 "차단한 사용자가 없어요"(`bl_empty_title`) → "차단한 크루원이 없어요"(CONTEXT.md 용어). 설명 "차단하면 서로의 글, 댓글, 요청, 초대가 제한돼요."(`bl_empty_desc`) → "차단하면 내 게시물, 댓글, 채팅, 위치 화면에서 그 사람이 숨겨져요."(기능범위의 차단 결정 문구에 맞춤 — 요청·초대는 크루 모델에 해당하는 개념이 아니다)
- 해제 버튼 라벨 "해제"(`action_unblock`) → "차단 해제". 행 안의 "해제" 만으로는 무엇을 푸는지 드러나지 않는다. 성공 토스트 "차단을 해제했어요"(`toast_unblocked`)는 그대로. 확인 대화상자 없이 즉시 처리하는 것도 옛 화면·5-4 와 같다
- 헤더 부제(차단 인원 수)는 신규. 옛 화면엔 제목만 있었다
- 당겨서 새로고침은 새로 생겼다(옛 화면은 없었다)
