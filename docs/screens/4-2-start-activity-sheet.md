# 4-2 활동 시작 시트

**목적** 이번 활동의 위치 공유 여부를 고르고, 선택 사항인 걸음수 연결 상태를 확인한 뒤 활동을 시작한다.
**원본** `../legacy/android-res/layout/sheet_start.xml` · **변경** 혼자/근처 사람 선택 두 줄과 "참여 요청 받기" 토글을 뺐다. 남는 것은 지도 표시 토글 하나와 시작 버튼이며, 토글 라벨을 "크루원에게 위치 공유" 로 바꾸고 초깃값이 고정 켬 → 내 설정값(`settings.shareLocationDefault`)이 됐다. 알림 권한 묻기와 위치 잡는 중 표시는 새로 넣었다
**진입** 줍깅 대기(4-1)의 "시작" 버튼 · 위치 권한 안내(1-10)가 4-2 때문에 떠서 허용으로 끝났을 때 다시 열린다 · **이탈** 시작 성공 → 활동 중(4-3). 닫기(스크림 탭·뒤로 가기·아래로 끌기) → 4-1. 위치 권한이 없으면 시트를 열지 않고 1-10 으로

시트를 여는 순간 서버는 부르지 않는다. 토글 초깃값은 4-1 이 이미 받아 둔 `GET /users/me` 의 `settings.shareLocationDefault` 다. 이 시트가 부르는 요청은 시작 버튼의 `POST /activities` 하나다.

## 배치

옛 XML 의 세로 순서(손잡이 → 제목 → 선택 두 줄 → 참여 요청 토글 → 지도 표시 토글 → 시작 버튼)에서 선택 두 줄과 참여 요청 토글을 뺀 것이다. 지도 표시 토글 타일(`bg_tile`)이 그 자리에서 위로 올라오고, 타일과 버튼 사이에 위치 상태 한 줄이 새로 들어간다. 좌우 여백 24dp, 아래 여백 32dp. 내용이 적으면 시트는 화면 아래 1/3 정도만 차지한다. 작은 화면·큰 글자에서는 장식 여백을 줄인 뒤 본문을 스크롤한다. 시트 위 나머지는 스크림이며 그 뒤로 4-1 이 흐릿하게 보인다.

```
┌──────────────────────────────────────┐
│ (스크림 · 뒤로 4-1 줍깅 대기)             │
│                                      │
├──────────────────────────────────────┤
│ ①            ▬▬▬▬                    │
│ ② 활동을 시작할까요?                     │
│ ┌──────────────────────────────────┐ │
│ │ ③ [◉ ] 크루원에게 위치 공유          │ │
│ │       켜면 활동 중 내 위치와 경로가    │ │
│ │       크루원 지도에 보여요. 꺼도 내   │ │
│ │       기록에는 경로가 남아요.        │ │
│ └──────────────────────────────────┘ │
│ ④ (◎) 위치를 잡고 있어요…              │  ← 잡히면 "위치 준비됨"
│ ⑦ 걸음수 측정 안 됨   [연결 (선택)]      │
│ ⑤ [          줍깅 시작            ]   │
│ ⑥ 나를 팔로우한 크루원에게 시작 알림이 가요  │
└──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| — | 시트 | 위 모서리만 둥근 바닥 시트. 스크림이 4-1 을 덮는다 | `BottomSheet` | 스크림 → 닫기(4-1) |
| ① | 손잡이 | 가운데 44×4dp 막대 | `BottomSheet` 기본 손잡이 (옛 `Gachi.SheetHandle`) | 아래로 끌면 닫기 |
| ② | 제목 | 고정 문구 "활동을 시작할까요?" 왼쪽 정렬, 섹션 제목 크기 | `Txt` title | — |
| ③ | 위치 공유 토글 | 스위치 + 라벨 "크루원에게 위치 공유" + 설명 "켜면 활동 중 내 위치와 경로가 크루원 지도에 보여요. 꺼도 내 기록에는 경로가 남아요." 초깃값은 `settings.shareLocationDefault` (`GET /users/me`). 타일 전체가 터치 영역이고 스위치 자체는 눌리지 않는다(옛 Gachi.Switch 의 clickable=false 그대로) | `Tile` tint + `Switch` + `Txt` bodyLg + `Txt` caption | 켬↔끔. 이 시트 안에서만 바뀌고 설정값(`shareLocationDefault`)은 건드리지 않는다 |
| ④ | 위치 상태 | 위치 아이콘 + 한 줄. 첫 위치가 아직 안 들어왔으면 "위치를 잡고 있어요…" 흐린 글자, 들어왔으면 "위치 준비됨" 초록 글자. 시작을 막지는 않는다(아래 상태 표) | `Icon`(crosshairs-gps) + `Txt` caption | — |
| ⑤ | 시작 버튼 | "줍깅 시작". 채운 알약, 전체 폭 | `Button` primary lg | 앱이 `id`(uuid)·`startedAt`(지금)·`locationShared`(③ 값)를 만들어 `POST /activities` → 성공하면 시트를 닫고 4-3 |
| ⑥ | 알림 안내 | 고정 문구 "나를 팔로우한 크루원에게 시작 알림이 가요" 가운데 정렬, 흐린 글자. 알림은 서버가 보내며 여기서 끄는 스위치는 없다(끄는 곳은 상대의 설정) | `Txt` caption | — |

| ⑦ | 걸음수 연결 | 연결됨 / 측정 안 됨. 권한이 없으면 "연결 (선택)"을 제공하며 지원되지 않으면 "걸음수 측정 안 됨"만 표시 | `Txt` caption + `Button` ghost | 선택했을 때만 걸음수 접근 권한을 요청한다. 거부하거나 닫아도 ⑤는 활성 상태를 유지한다 |

걸음수는 선택 정보다. Health Connect 미설치·권한 거부·걸음 미측정·비보행 활동이어도 시작·기록·종료를 막지 않는다. 위치 권한은 활동 시작 진입에서만 확인하고 다른 탭 이용은 막지 않는다. 로컬 종료 대기 기록이 있으면 새 시작만 막고 4-7 요약·재시도를 제공한다.

시작 버튼을 누른 뒤 순서.

| 순서 | 하는 것 | 결과 | 다음 |
|---|---|---|---|
| 1 | 위치 권한 재확인(OS) | 허용 | 2 |
| 1 | 같은 확인 | 없음(시트가 열린 사이 OS 설정에서 끈 경우) | 시트를 닫고 1-10 을 모달로. 허용되면 4-2 를 다시 연다 |
| 2 | 알림 권한(Android 13 이상) 아직 안 물었으면 OS 권한 창 | 허용·거부 모두 | 3. 거부해도 시작은 막지 않는다 — 알림창 현황만 안 뜬다 |
| 3 | `POST /activities` (`id`·`startedAt`·`locationShared`) | 201 · `data.id`·`data.status` IN_PROGRESS | 시트 닫고 4-3. 배경 추적(포그라운드 서비스) 시작 |
| 3 | 같은 요청 | 200 · 이미 진행 중인 활동(`data.status` IN_PROGRESS, `data.startedAt` 이 과거) | 새로 만들지 않고 그 활동으로 4-3. `Snackbar` "진행 중인 활동이 있어 이어서 시작해요" |
| 3 | 같은 요청 | 4xx/5xx · 네트워크 실패 | 시트에 남고 오류 행 |

## 상태

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | **해당 없음.** 열리면서 서버를 부르지 않는다. ①②③⑤⑥⑦ 이 한 번에 보이고 ③ 은 `settings.shareLocationDefault` 값으로 켜져 있거나 꺼져 있다. ④ 는 첫 위치가 없으면 "위치를 잡고 있어요…" 로 시작한다 | 전부 |
| 위치 잡는 중 | ④ "위치를 잡고 있어요…" 흐린 글자. 첫 위치가 들어오면 "위치 준비됨" 으로 바뀐다. ⑤ 는 그대로 눌린다 — 실내·건물 사이에서 위치가 늦게 잡혀도 시작을 막지 않고, 오차 큰 첫 점들은 위치 품질 필터(오차 30m 초과 버림)가 걸러낸다 | 전부 |
| 시작 중 | ⑤ 라벨 자리에 스피너. `POST /activities` 가 끝날 때까지. ③ 은 비활성으로 흐려진다 | 아무것도 눌리지 않는다. 스크림 탭·뒤로 가기·끌기로도 닫히지 않는다 |
| 새로고침 | **해당 없음.** 받아 오는 것이 없다 | — |
| 빈 | **해당 없음.** 고정 시트다 | — |
| 오류 | `POST /activities` 가 4xx/5xx 면 스피너가 꺼지고 `Snackbar` "활동을 시작하지 못했어요. 잠시 후 다시 시도해 주세요." 시트는 열린 채 ③ 값도 그대로. NO_CREW 403 만 예외 — 시트를 닫고 `Snackbar` "크루에 소속돼야 활동을 시작할 수 있어요" 뒤 앱 진입 분기(1-6)로 | 전부. 다시 시도는 ⑤ 를 다시 누르는 것 |
| 오프라인 | 시트 자체는 평소와 같다(미리 알리지 않는다). ⑤ 를 누르면 요청이 실패해 오류와 같은 `Snackbar`. 오프라인 시작(나중에 올리기)은 없다 | 전부 |
| 권한 거부 | 위치: 시트를 열기 전에 4-1 이 확인한다 — 없으면 시트 대신 1-10 을 모달로 띄우고, 허용되면 돌아와 4-2 를 연다(1-10 "4-2 에서 왔을 때"). 시트가 열린 뒤 ⑤ 를 누를 때 다시 확인해 그 사이 빠져 있으면 같은 처리. 알림: ⑤ 를 누를 때 OS 창을 한 번 띄우고, 거부해도 그대로 시작한다. 시트 안에 알림 권한 안내 문구·배너는 없다 | 위치 없음 → 1-10 · 알림 거부 → 시작 계속 |
| 부분 실패 | **해당 없음.** 요청이 `POST /activities` 하나라 전체 성공 또는 전체 실패다. 요청은 성공했는데 배경 추적 시작에 실패한 경우는 4-3 이 다룬다 | — |
| 이미 진행 중 | 4-1 이 `GET /activities/current` 로 진행 중을 알고 있으면 "시작" 대신 "이어서" 를 보여 이 시트를 열지 않는다. 그래도 `POST /activities` 가 200 으로 기존 활동을 돌려주면(다른 기기에서 시작한 경우) 위 순서 표 3 처럼 그 활동으로 4-3 | — |

크루장·크루원 차이: **없음.** 활동 시작은 권한표에서 크루원·크루장 모두 ○ 이고 시트 요소도 같다.

## 인터랙션

- 스크롤: 내용이 넘치면 본문 스크롤. 글자·48dp 터치 영역은 줄이지 않는다
- 당겨서 새로고침: 없음
- 길게 누르기: 없음
- 시트: 이 화면 자체가 시트다. 스크림 탭·손잡이 아래로 끌기·뒤로 가기 세 가지로 닫힌다. 시작 중에는 셋 다 막힌다
- 뒤로 가기: 시트를 닫고 4-1 로. 바꿔 둔 ③ 값은 버린다(다음에 열면 다시 `shareLocationDefault`). 알림 권한 창을 닫아도 시작은 이어진다. 걸음수 권한 창을 닫으면 시트로 돌아오며 시작할 수 있다. 위치 권한이 없으면 1-10 흐름을 따른다
- 토글: ③ 타일 어디를 눌러도 스위치가 바뀐다. 스위치 이동만 짧게 애니메이션
- 키보드: 없음
- 전환: 시트는 아래에서 올라오는 슬라이드. 4-3 으로 갈 때는 시트를 닫으면서 4-1 위에 4-3 을 푸시하고 4-1 은 스택에 남긴다(4-3 을 끝내면 4-7 을 거쳐 4-1 로 돌아온다). 1-10 은 모달로 덮고 끝나면 닫는다. ④ 문구 교체는 짧게 페이드

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - 시트가 열리는 순간 ② 제목에 포커스가 가서 "활동을 시작할까요?" 가 먼저 읽힌다
  - ③: 타일 하나를 스위치 한 요소로 묶어 "크루원에게 위치 공유, 켬" / "끔". 설명 문구는 힌트로 이어 읽는다
  - ④: "위치를 잡고 있어요" / "위치 준비됨". 바뀌는 순간 읽어 준다(live region). 아이콘은 읽지 않는다
  - ⑤: "줍깅 시작". 시작 중에는 "시작 중" 으로 바뀌고 나머지 요소는 비활성으로 읽힌다
  - ⑥: 본문 그대로 읽는다
  - ⑦: 걸음수 연결 상태를 읽는다. 연결 버튼은 "걸음수 연결, 선택 사항"으로 읽으며 터치 영역은 최소 48dp다
  - 스크림: "닫기"
  - 손잡이: 장식이라 읽지 않는다(닫기는 스크림·뒤로 가기가 대신한다)
  - `Snackbar`: 나타나는 순간 문구를 읽어 준다
- 최소 터치 크기 예외: 없음. ③ 타일은 높이 48dp 이상, ⑤ 는 lg 버튼 전체 폭. 손잡이는 5dp 지만 끌기 전용이고 같은 일을 스크림이 한다

## 옛 화면과의 차이

- 제목 "어떻게 시작할까요?" → "활동을 시작할까요?". 고를 것이 방식이 아니라 시작 여부 하나가 됐다
- "혼자 시작하기 / 1인 모임으로 바로 시작해요"·"근처 사람과 시작 / 지금 활동 중인 사람을 찾아봐요" 두 선택 줄 → 없음. 활동은 항상 개인 단위다
- "참여 요청 받기 / 켜 두면 근처 사람이 내 활동에 참여를 요청할 수 있어요." 토글과 `start_accept_needs_location` 문구 → 없음. 함께줍깅이 꺼졌다
- "이 활동 지도에 표시 / 끄면 이번 활동은 내 기록에만 남고 지도에 뜨지 않아요." → "크루원에게 위치 공유 / 켜면 활동 중 내 위치와 경로가 크루원 지도에 보여요. 꺼도 내 기록에는 경로가 남아요." 초깃값 고정 켬 → `settings.shareLocationDefault`
- 버튼 "혼자 줍깅 시작"·"근처 사람 찾아보기" → "줍깅 시작" 하나
- 실패 문구 "활동을 시작하지 못했어요. 잠시 후 다시 시도해 주세요." 는 그대로
- 위치 상태 한 줄(④)·팔로우 알림 안내(⑥)·알림 권한 묻기·시작 중 스피너·이미 진행 중 처리는 새로 정했다 — 옛 XML 에 없다

## 미결

- `POST /activities`의 기존 진행 활동 200 응답과 오류 응답은 API 구현에서 계약을 일치시켜야 한다.
- 시작은 서버 확인 뒤 진행하며 오프라인 신규 시작은 지원하지 않는다. 이미 시작한 활동의 오프라인 기록·종료는 4-3~4-7의 확정 흐름을 따른다.
