# 3-2 크루 정보

**목적** 내 크루의 사진·이름·소개·목표와 크루원 수를 본다. 정보만 보이는 화면이다.
**원본** `../legacy/android-res/layout/fragment_meet_manage.xml` · **변경** 활동 장소·시간·참여자 관리 대신 지속되는 크루 소개·14일 목표를 보인다. 채팅은 3-1 의 채팅 줄에, 기록은 3-1 의 [기록] 탭에, 초대 코드·가입 신청·크루원 관리는 3-11 에, 크루 나가기는 5-7 에 둔다. 같은 곳으로 가는 버튼을 두 번 두지 않는다.
**진입** 3-1 모이깅의 크루 카드 · 2-1 홈 크루 알약 · **이탈** 3-11 크루원 관리 · 3-10 크루 정보 수정(크루장)

## 인터랙션

- 스크롤: 길면 세로 스크롤
- 당겨서 새로고침: 있음. `GET /crew`·`GET /crew/members` 재조회
- 길게 누르기·시트·키보드: 없음
- 뒤로 가기: 들어온 화면으로 팝한다
- 전환: 3-11·3-10 은 푸시. 3-10 저장·3-11 위임 뒤 돌아오면 `Snackbar` 로 결과를 알린다

## 접근성

- ②: "한강줍깅크루, 매주 토요일 아침 여의도, 14일 목표 300개"로 묶어 읽는다
- ③: "크루원 18명, 가입 신청 2건, 크루원 보기". 얼굴은 장식이다
- ① 수정: "크루 정보 수정"

## 옛 화면과의 차이

- 옛 대표 카드의 장소·시간·활동 상태를 크루 소개·14일 목표로 바꿨다
- 옛 참여자 카드·위치 공유 안내·초대하기·활동 시작·나가기 버튼을 없앴다. 크루원 카드 하나가 3-11 로 가고, 초대 코드·가입 신청도 거기서 연다
