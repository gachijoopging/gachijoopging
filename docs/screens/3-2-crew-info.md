# 3-2 크루 정보

**목적** 내 크루의 소개·목표·크루원·초대 코드·처리 대기를 보고, 역할에 맞는 크루 관리 화면으로 이동한다.
**원본** `../legacy/android-res/layout/fragment_meet_manage.xml` · **변경** 활동 장소·시간·참여자 관리 대신 지속되는 크루 소개·14일 목표·크루원 관리로 바꿨다. 크루장이 아니어도 같은 정보와 채팅을 보며, 관리 버튼만 달라진다.
**진입** 3-1 모이깅의 크루 카드 · 2-1 홈 크루 알약 · **이탈** 3-7 크루 채팅 · 3-3 초대 코드 · 3-4 크루 기록 · 3-11 크루원 관리 · 3-10 크루 정보 수정 · 3-8 가입 신청 관리 · 5-4 타인 프로필 · 5-7 설정

## 배치

옛 XML의 순서(헤더 → 대표 카드 → 크루원 카드 → 채팅 버튼 → 두 행동 버튼 → 나가기 링크)를 따른다. 대표 카드는 크루 사진·소개·목표를, 크루원 카드는 대표 크루원 최대 4명과 전체 보기 링크를 보인다. 옛 초대/시작 버튼 자리는 역할별 관리 바로가기로 바꾼다.

```
┌──────────────────────────────────────┐
│ ① ‹  크루 정보                         │
├──────────────────────────────────────┤
│ ② ┌────────────────────────────────┐ │
│    │ (◯) 한강줍깅크루                 │ │
│    │ 매주 토요일 아침 여의도            │ │
│    │ 목표: 14일에 300개          [수정] │ │
│    └────────────────────────────────┘ │
│ ③ 크루원 18명                       › │
│    (◉) 관열 크루장  (◉) 상혁  (◉) 지수  │
│ ④ [        크루 채팅 열기        ]     │
│ ⑤ [초대 코드] [크루 기록]              │
│ ⑥ [가입 신청 2건] [크루원 관리]         │ ← 크루장만
│ ⑦           크루 나가기                │
└──────────────────────────────────────┘
```

## 인터랙션

- 스크롤: ②~⑦이 길면 세로 스크롤. ①은 고정
- 당겨서 새로고침: 있음. `GET /crew`·`GET /crew/members`을 재조회
- 길게 누르기: 없음
- 시트: 없음. 크루 나가기 확인은 5-7에서 한다
- 뒤로 가기: 3-1에서 왔으면 3-1, 2-1에서 왔으면 2-1로 팝한다
- 키보드: 없음
- 대표 크루원 탭: 자기 자신이면 5-5 내 정보, 다른 크루원이면 5-4 타인 프로필
- 전환: 3-7·3-3·3-4·3-11·3-10·3-8·5-4·5-7은 푸시

## 접근성

- ②: "한강줍깅크루, 매주 토요일 아침 여의도, 14일 목표 300개"로 묶어 읽는다. 크루장만 "크루 정보 수정"을 추가한다
- ③: "크루원 18명, 관열 크루장, 상혁, 지수, 크루원 전체 보기"로 읽는다. 장식 아바타는 이름이 대신한다
- ④: "크루 채팅 열기, 안 읽은 메시지 5개". 0이면 수를 생략한다
- ⑥: 크루장에게만 보이는 관리 버튼을 역할과 함께 읽는다
- 모든 버튼은 48dp 이상이다

## 옛 화면과의 차이

- 옛 대표 카드의 장소·시간·활동 상태를 크루 소개·14일 목표로 바꿨다. 활동마다 관리하던 화면이 아니라 지속되는 크루 정보다
- 옛 참여자 카드·위치 공유 안내는 크루원 수·대표 크루원·크루원 관리 링크로 바꿨다. 위치 공유는 활동 시작 때 정하는 선택이다
- 옛 초대하기·활동 시작·활동 나가기 버튼을 초대 코드·크루 기록·크루 나가기로 바꿨다
- 채팅 버튼과 위험한 나가기 링크의 위치는 유지했다

- 크루원 목록(③ → 3-11)은 모든 크루원이 읽을 수 있고 위임·추방 메뉴만 크루장에게 보인다. 크루를 나가도 내 활동 기록은 보존되며 1-6의 내 기록 진입점에서 확인한다.

## 미결

- `GET /crew/members`는 배열 전체를 돌려줘 대표 4명만 고르는 기준(가입 순 / 활동량 순)이 계약에 없다. 현재는 응답 첫 4명으로 보인다
