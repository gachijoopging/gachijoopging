# 3-10 크루 정보 수정

**목적** 크루장이 크루 이름·소개·대표 사진·활동 지역·가입 방식(공개/비공개)·14일 목표를 고친다.
**원본** `../legacy/android-res/layout/fragment_meet_edit.xml` · **변경** 활동 시간·공개 범위 입력을 없애고, 지속되는 크루의 소개·대표 사진·활동 지역·가입 방식·목표 입력을 추가했다. 크루장만 수정할 수 있다.
**진입** 3-11 크루 정보의 수정(연필) · **이탈** 저장 성공 → 3-11 크루 정보 · 뒤로 가기 → 3-11

## 배치

옛 수정 화면의 순서(헤더 → 이름 입력 → 나머지 입력 → 저장)를 따른다. 시간·공개 범위 대신 사진·소개·활동 지역·가입 방식·목표 스테퍼를 둔다. 저장 버튼은 바뀐 값이 있고 모두 유효할 때만 활성이다.

```
┌──────────────────────────────────────┐
│ ① ‹  크루 정보 수정                   │
├──────────────────────────────────────┤
│ ② (◯) 대표 사진 변경                  │
│ ③ 크루 이름                            │
│    ┌ 한강줍깅크루 ───────────────────┐ │
│ ④ 소개                                 │
│    ┌ 매주 토요일 아침 여의도 ────────┐ │
│ ⑤ 활동 지역          서울특별시     › │
│ ⑥ 가입 방식                            │
│    ○ 공개    승인 없이 바로 가입        │
│    ◉ 비공개  크루장이 승인해야 가입      │
│ ⑦ 14일 목표                            │
│    [ − ]       300개       [ + ]       │
├──────────────────────────────────────┤
│ ⑧ [       변경사항 저장       ]        │
└──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 뒤로 버튼 | "뒤로" | `AppHeader` | 3-11 |
| ① | 헤더 제목 | "크루 정보 수정" | `AppHeader` | — |
| ② | 대표 사진 | `photoUrl` (`GET /crew`). null이면 `name` 첫 글자 | `Avatar` xl + `Button` ghost sm | 사진 선택 시트 |
| ② | 사진 변경 시트 | "카메라로 촬영" · "사진 선택"(OS 기본 사진 선택기) · 사진이 있으면 "사진 삭제" | `BottomSheet` | `POST /media` purpose CREW → `photoMediaId` |
| ③ | 이름 입력창 | `name` (`PATCH /crew`) · 2~20자, 기존 "한강줍깅크루" | `Field` | 키보드 |
| ④ | 소개 입력창 | `intro` (`PATCH /crew`) · 최대 200자 · "크루를 소개해 주세요." | `Field` | 키보드 |
| ⑤ | 활동 지역 | `region` (`GET /crew` → `PATCH /crew`). 시·도 이름으로 표시. 1-7 과 같은 지역 시트(17개)에서 고른다 | `SelectRow` + `BottomSheet` + `ListRow` | 지역 시트 |
| ⑥ | 가입 방식 | `joinPolicy` (`GET /crew` → `PATCH /crew`). "공개 — 승인 없이 바로 가입" / "비공개 — 크루장이 승인해야 가입" | `SelectRow` | 그 값 선택 |
| ⑦ | 목표 스테퍼·직접 숫자 입력 | `goalCount` (`PATCH /crew`) · 1 이상 | `NumberStepper` | − / + / 수량 탭으로 숫자 입력 |
| ⑧ | 저장 버튼 | "변경사항 저장". 유효한 변경이 있을 때만 활성 | `Button` primary lg | `PATCH /crew` (공개 전환이면 먼저 확인 대화상자) |

이름은 2~20자, 소개는 200자 이하, 목표는 1개 이상이다. 이름은 앞뒤 공백과 줄바꿈을 제거하고 기존 길이 제한을 검사한다. 소개는 앞뒤 공백을 지운다. 별도 문자 제한을 추가하지 않으며 이름 중복은 저장 시 서버에서 검사하고 오류를 이름 입력 아래에 표시한다. 바뀌지 않은 필드는 요청에서 생략하고, 사진을 삭제하면 `photoMediaId`에 null을 보낸다.

비공개 → 공개로 바꿔 저장하면 먼저 대화상자: 제목 "공개 크루로 바꿀까요?" · 본문 "이제부터 누구나 승인 없이 바로 가입해요. 지금 기다리는 가입 신청 N건은 모두 바로 가입돼요." (N 은 `pendingJoinRequests`, 0 이면 둘째 문장을 뺀다). `memberCount` + N 이 50 을 넘으면 저장 전에 미리 위 "공개 전환 정원 초과" 대화상자를 보인다(서버 409 와 같은 문구) · [그대로 두기] [공개로 바꾸기]. 공개 → 비공개는 확인 없이 저장하며, 이후 가입부터 승인이 필요하다.

## 인터랙션

- 스크롤: ②~⑦이 키보드·작은 화면에서 세로 스크롤, 장식·사진 높이를 먼저 줄이고 필요하면 버튼을 포함해 스크롤한다. 글자·터치 크기는 유지
- 당겨서 새로고침: 없음
- 길게 누르기: 입력창 OS 기본 붙여넣기
- 시트: ② 사진 변경 시트 · ⑤ 지역 시트
- 뒤로 가기: 변경이 없으면 3-11로 팝, 있으면 버리기 확인
- 키보드: 이름·소개 입력 시 보이고 완료 키는 다음 입력 또는 ⑧으로 이동
- 목표: −는 1에서 비활성. +를 누르면 1씩 늘어난다
- 전환: 저장 성공 시 `Snackbar` "크루 정보를 저장했어요." 후 3-11로 팝한다. 공개 전환으로 대기 신청이 가입됐으면 "공개 크루로 바꿨어요. 기다리던 N명이 가입했어요."

## 접근성

- ②: "크루 대표 사진 변경" 또는 "대표 사진 없음, 사진 추가"
- ③: "크루 이름, 2자에서 20자"
- ④: "크루 소개, 200자까지"
- ⑤: "활동 지역, 서울특별시, 바꾸기"
- ⑥: "가입 방식" 묶음 안에서 "공개, 승인 없이 바로 가입" / "비공개, 크루장이 승인해야 가입" 과 선택 상태
- ⑦: "14일 목표, 300개, 줄이기, 늘리기"
- ⑧: "변경사항 저장", 활성·비활성을 읽는다. 모든 조작은 48dp 이상이다

## 옛 화면과의 차이

- 옛 시간·공개 범위 입력과 활동 잠금 배너를 없앴다. 크루 정보는 활동 상태와 무관하게 크루장이 수정한다
- 대표 사진·소개·14일 목표를 새로 추가했다. 2026-10 회의로 활동 지역(시·도)·가입 방식(공개/비공개) 수정을 추가했다. 옛 "공개 범위"는 노출 범위였지만 새 가입 방식은 승인 필요 여부다
- 옛 모임 정보 수정은 일정 수정이었고, 새 화면은 크루 자체의 정보를 수정한다

- 이름·목표의 유효성 오류는 해당 입력 아래에 표시한다. 저장 요청은 한 번만 실행하고 실패 시 입력·준비된 사진을 보존한다. OS 사진 선택기는 전체 앨범 접근 권한을 요구하지 않는다.
