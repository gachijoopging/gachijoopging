# 3-10 크루 정보 수정

**목적** 크루장이 크루 이름·소개·대표 사진·14일 목표를 고친다.
**원본** `../legacy/android-res/layout/fragment_meet_edit.xml` · **변경** 활동 시간·공개 범위 입력을 없애고, 지속되는 크루의 소개·대표 사진·목표 입력을 추가했다. 크루장만 수정할 수 있다.
**진입** 3-11 크루 정보의 수정(연필) · **이탈** 저장 성공 → 3-11 크루 정보 · 뒤로 가기 → 3-11

## 배치

옛 수정 화면의 순서(헤더 → 이름 입력 → 나머지 입력 → 저장)를 따른다. 시간·공개 범위 대신 사진·소개·목표 스테퍼·직접 숫자 입력을 둔다. 저장 버튼은 바뀐 값이 있고 모두 유효할 때만 활성이다.

```
┌──────────────────────────────────────┐
│ ① ‹  크루 정보 수정                   │
├──────────────────────────────────────┤
│ ② (◯) 대표 사진 변경                  │
│ ③ 크루 이름                            │
│    ┌ 한강줍깅크루 ───────────────────┐ │
│ ④ 소개                                 │
│    ┌ 매주 토요일 아침 여의도 ────────┐ │
│ ⑤ 14일 목표                            │
│    [ − ]       300개       [ + ]       │
├──────────────────────────────────────┤
│ ⑥ [       변경사항 저장       ]        │
└──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 뒤로 버튼 | "뒤로" | `AppHeader` | 3-11 |
| ① | 헤더 제목 | "크루 정보 수정" | `AppHeader` | — |
| ② | 대표 사진 | `photoUrl` (`GET /crew`). null이면 `name` 첫 글자 | `Avatar` xl + `Button` ghost sm | 사진 선택 시트 |
| ② | 사진 변경 시트 | "카메라로 촬영" · "사진 선택"(OS 기본 사진 선택기) · 사진이 있으면 "사진 삭제" | `BottomSheet` | `POST /media` purpose CREW → `photoMediaId` |
| ③ | 이름 입력창 | `name` (`PATCH /crew`) · 2~20자, 기존 "한강줍깅크루" | `Field` | 키보드 |
| ④ | 소개 입력창 | `intro` (`PATCH /crew`) · 최대 200자 · "크루를 소개해 주세요." | `Field` | 키보드 |
| ⑤ | 목표 스테퍼·직접 숫자 입력 | `goalCount` (`PATCH /crew`) · 1 이상 | `NumberStepper` | − / + / 수량 탭으로 숫자 입력 |
| ⑥ | 저장 버튼 | "변경사항 저장". 유효한 변경이 있을 때만 활성 | `Button` primary lg | `PATCH /crew` |

이름은 2~20자, 소개는 200자 이하, 목표는 1개 이상이다. 이름은 앞뒤 공백과 줄바꿈을 제거하고 기존 길이 제한을 검사한다. 소개는 앞뒤 공백을 지운다. 별도 문자 제한을 추가하지 않으며 이름 중복은 저장 시 서버에서 검사하고 오류를 이름 입력 아래에 표시한다. 이름을 바꾸지 않으면 `name`은 요청에서 생략하고, 사진을 삭제하면 `photoMediaId`에 null을 보낸다.

## 인터랙션

- 스크롤: ②~⑤가 키보드·작은 화면에서 세로 스크롤, 장식·사진 높이를 먼저 줄이고 필요하면 버튼을 포함해 스크롤한다. 글자·터치 크기는 유지
- 당겨서 새로고침: 없음
- 길게 누르기: 입력창 OS 기본 붙여넣기
- 시트: ② 사진 변경 시트
- 뒤로 가기: 변경이 없으면 3-2로 팝, 있으면 버리기 확인
- 키보드: 이름·소개 입력 시 보이고 완료 키는 다음 입력 또는 ⑥으로 이동
- 목표: −는 1에서 비활성. +를 누르면 1씩 늘어난다
- 전환: 저장 성공 시 `Snackbar` "크루 정보를 저장했어요." 후 3-2로 팝한다

## 접근성

- ②: "크루 대표 사진 변경" 또는 "대표 사진 없음, 사진 추가"
- ③: "크루 이름, 2자에서 20자"
- ④: "크루 소개, 200자까지"
- ⑤: "14일 목표, 300개, 줄이기, 늘리기"
- ⑥: "변경사항 저장", 활성·비활성을 읽는다. 모든 조작은 48dp 이상이다

## 옛 화면과의 차이

- 옛 시간·공개 범위 입력과 활동 잠금 배너를 없앴다. 크루 정보는 활동 상태와 무관하게 크루장이 수정한다
- 대표 사진·소개·14일 목표를 새로 추가했다
- 옛 모임 정보 수정은 일정 수정이었고, 새 화면은 크루 자체의 정보를 수정한다

- 이름·목표의 유효성 오류는 해당 입력 아래에 표시한다. 저장 요청은 한 번만 실행하고 실패 시 입력·준비된 사진을 보존한다. OS 사진 선택기는 전체 앨범 접근 권한을 요구하지 않는다.
