**원본** `../legacy/android-res/layout/fragment_meet_manage.xml`의 크루원 카드 · **변경** 활동 참여자 목록을 지속되는 크루원 관리 목록으로 바꾸고, 추방·위임 행동을 추가했다. 크루원 모두 접근하며 관리 메뉴는 크루장만 본다.
**통합** 3-2 크루 정보(ⓐ 크루 카드)를 흡수했다. 3-3 초대 코드는 끔(2026-10 회의)

## 배치

옛 크루원 카드의 제목·세로 목록 순서를 따른다. 각 행은 아바타·닉네임·누적 줍기 수·가입일·크루장 배지와 더보기 버튼으로 구성한다.

│ ① ‹  크루 정보                   [✎]  │ ← 수정은 크루장만
├──────────────────────────────────────┤
│ ⓐ             (◯)                     │
│           한강줍깅크루                 │
│       매주 토요일 아침 여의도            │
│      서울특별시 · [비공개]              │

## 인터랙션

- 스크롤: 크루원 행을 세로 스크롤
- 당겨서 새로고침: 있음. `GET /crew/members` 재조회
- 길게 누르기: 없음
- 시트: ⓪ 기록 내보내기에서 기간 시트, 대상 크루원 더보기에서 관리 시트
- 뒤로 가기: 3-1로 팝한다. 시트·대화상자가 열렸으면 먼저 닫는다
- 키보드: 없음
- 행 탭: 자기 자신이면 5-5, 다른 크루원이면 5-4로 푸시
- 전환: 위임 성공 뒤 내 역할이 바뀌므로 이 화면에서 다시 받는다. 3-10 저장 뒤 돌아오면 `Snackbar` "크루 정보를 저장했어요."

## 접근성

- ③: "상혁, 누적 380개, 2026년 9월 2일 가입, 프로필 보기"로 읽는다
- 크루장 행은 "관열, 크루장, 누적 412개"로 읽고 더보기는 없다
- 위임·추방·나가기 대화상자는 제목으로 무엇을 하는지 읽는다
- ④: "크루 나가기, 한강줍깅크루에서 나가기"
- 행·더보기·시트 버튼은 48dp 이상이다

## 옛 화면과의 차이

- 크루 정보(옛 3-2)를 이 화면으로 합쳤다. 초대 코드(옛 3-3)는 끔(2026-10 회의) — 크루 검색으로 들어온다. 크루 카드를 누르고 크루원 카드를 다시 누르던 두 단계가 한 단계가 됐다

- 옛 활동 참여자 목록은 한 활동이 끝나면 사라졌다. 새 목록은 크루가 존재하는 동안의 크루원이다
- 옛 관리 화면에 없던 크루장 위임·크루원 추방을 추가했다
- 옛 위치 공유 안내를 없앴다

- 차단은 위임·추방에 필요한 크루장 관리 정보를 숨기지 않는다. 차단한 사람의 프로필 개인 콘텐츠는 차단 규칙을 따른다.
- 사용자 신고에서 넘어온 추방은 해당 사용자의 대기 USER 신고도 함께 처리한다. 성공 후 해당 신고들을 해결하고 신고자에게 결과를 알리는 계약과 연동한다.
- 크루 나가기는 원래 5-7 설정에 있었는데 이 화면으로 옮겼다(2026-10-13). 크루장은 위임이 먼저 필요한데 위임할 크루원 목록이 여기 있다. 마지막 1명인 크루장은 위임 후보가 없으므로 해산을 확인하고 나간다. 활동·로컬 미동기화 기록이 있으면 나가기는 보류한다.
