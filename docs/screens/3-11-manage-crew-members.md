# 3-11 크루원 관리

**목적** 모든 크루원이 목록을 읽고, 크루장만 위임·추방 메뉴를 사용한다.
**원본** `../legacy/android-res/layout/fragment_meet_manage.xml`의 크루원 카드 · **변경** 활동 참여자 목록을 지속되는 크루원 관리 목록으로 바꾸고, 추방·위임 행동을 추가했다. 크루원 모두 접근하며 관리 메뉴는 크루장만 본다.
**진입** 3-2 크루 정보의 크루원 카드 · 5-7에서 크루장 위임 안내 · **이탈** 3-3 초대 코드 · 3-8 가입 신청(크루장) · 5-4 타인 프로필 · 3-2 크루 정보 · 뒤로 가기 → 3-2

## 배치

옛 크루원 카드의 제목·세로 목록 순서를 따른다. 각 행은 아바타·닉네임·누적 줍기 수·가입일·크루장 배지와 더보기 버튼으로 구성한다.

```
┌──────────────────────────────────────┐
│ ① ‹  크루원 관리                      │
├──────────────────────────────────────┤
│ ⓪ 초대 코드   HG-7K2P              › │
│    가입 신청                  [2]  › │ ← 크루장만
│    기록 내보내기                   › │ ← 크루장만
│ ② 크루원 18명                         │
│ ③ (◉) 관열  크루장  412개 │
│    2026년 9월 1일 가입                 │
│ ③ (◉) 상혁          380개          ⋯ │ ← 더보기는 크루장만
│    2026년 9월 2일 가입                 │
└──────────────────────────────────────┘
```

## 요소

관리 시트는 내가 크루장이며 대상이 현재 크루장이 아니고 내 행이 아닐 때 [크루장 위임] · [크루원 추방]을 보인다. 현재 크루장 행과 내 행에는 시트를 열지 않는다. 위임은 `PUT /crew/leader`의 `userId`, 추방은 `DELETE /crew/members/{userId}`을 쓴다.

위임 확인: "상혁 님에게 크루장을 넘길까요?" / [그대로 두기] [위임]. 204면 목록을 재조회하고 `Snackbar` "상혁 님에게 크루장을 위임했어요." 뒤 3-2로 팝한다.

추방 확인: "상혁 님을 크루에서 추방할까요?" / [그대로 두기] [추방]. 204면 행을 제거하고 `Snackbar` "상혁 님을 추방했어요.".

## 인터랙션

- 스크롤: 크루원 행을 세로 스크롤
- 당겨서 새로고침: 있음. `GET /crew/members` 재조회
- 길게 누르기: 없음
- 시트: 대상 크루원 더보기에서 관리 시트
- 뒤로 가기: 3-2로 팝한다. 시트·대화상자가 열렸으면 먼저 닫는다
- 키보드: 없음
- 행 탭: 자기 자신이면 5-5, 다른 크루원이면 5-4로 푸시
- 전환: 위임 성공 뒤 내 역할이 바뀌므로 3-2를 새로 받고 대체 전환한다

## 접근성

- ③: "상혁, 누적 380개, 2026년 9월 2일 가입, 프로필 보기"로 읽는다
- 크루장 행은 "관열, 크루장, 누적 412개"로 읽고 더보기는 없다
- 위임·추방 대화상자는 제목으로 무엇을 하는지 읽는다
- 행·더보기·시트 버튼은 48dp 이상이다

## 옛 화면과의 차이

- 옛 활동 참여자 목록은 한 활동이 끝나면 사라졌다. 새 목록은 크루가 존재하는 동안의 크루원이다
- 옛 관리 화면에 없던 크루장 위임·크루원 추방을 추가했다
- 옛 위치 공유 안내를 없앴다

- 차단은 위임·추방에 필요한 크루장 관리 정보를 숨기지 않는다. 차단한 사람의 프로필 개인 콘텐츠는 차단 규칙을 따른다.
- 사용자 신고에서 넘어온 추방은 해당 사용자의 대기 USER 신고도 함께 처리한다. 성공 후 해당 신고들을 해결하고 신고자에게 결과를 알리는 계약과 연동한다.
- 마지막 1명인 크루장은 위임 후보가 없으므로 5-7에서 해산을 확인하고 나갈 수 있다. 활동·로컬 미동기화 기록이 있으면 나가기는 보류한다.
