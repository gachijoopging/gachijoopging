# 3-1 모이깅

**목적** 내 크루의 핵심 상태를 한 곳에서 보고 크루 정보·공지·채팅·기록으로 이동한다.
**원본** `../legacy/android-res/layout/fragment_meet.xml` · **변경** 지금 활동·크루 찾기·예정 활동 3탭과 검색을 없애고, 하나뿐인 내 크루의 요약 허브로 바꿨다. 탭 이름 "모이깅"만 유지한다.
**진입** 하단 탭 모이깅 · 2-1 홈의 크루 알약 · **이탈** 3-2 크루 정보 · 3-5 공지 목록 · 3-7 크루 채팅 · 3-4 크루 기록 · 3-9 활동 달력 · 2-3 알림

## 배치

옛 XML의 상단 제목·알림 벨·탭 아래 스크롤 본문 순서를 따른다. 세 개의 옛 탭·검색·활동 찾기 영역은 제거하고 크루 대표 카드, 바로가기 4개, 최신 공지, 하단 탭으로 재배치한다.

```
┌──────────────────────────────────────┐
│ ① 모이깅                         🔔● │
├──────────────────────────────────────┤
│ ② ┌────────────────────────────────┐ │
│    │ (◯) 한강줍깅크루             › │ │
│    │ 크루원 18명 · 목표 14일 300개   │ │
│    └────────────────────────────────┘ │
│ ③ [공지] [채팅 ●] [크루 기록] [달력]    │
│ ④ 📌 9월 정기 활동 안내              › │
│                                      │
│ ⑤ 홈  피드  줍깅  모이깅  내 정보       │
└──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 제목 | "모이깅" | `Txt` display | — |
| ① | 알림 벨·점 | 안 읽은 알림이 있으면 점. 수는 `unreadNotifications` (`GET /crew/home`) | `Icon`(bell-outline) + `Dot` | 2-3 |
| ② | 크루 대표 카드 | `photoUrl`·`name`·`memberCount`·`goalCount`·`isLeader` (`GET /crew`) | `Card` + `Avatar` lg + `Txt` + `Badge` | 3-2 |
| ② | 크루장 배지 | `isLeader` true면 "크루장" | `Badge` deep | — |
| ③ | 공지 바로가기 | "공지" | `Tile` + `Icon`(bullhorn-outline) + `Txt` | 3-5 |
| ③ | 채팅 바로가기 | "채팅" · `unreadChat`이 1 이상이면 점 | `Tile` + `Icon`(chat-outline) + `Dot` + `Txt` | 3-7 |
| ③ | 기록 바로가기 | "크루 기록" | `Tile` + `Icon`(chart-box-outline) + `Txt` | 3-4 |
| ③ | 달력 바로가기 | "활동 달력" | `Tile` + `Icon`(calendar-month-outline) + `Txt` | 3-9 |
| ④ | 최신 공지 | 최신 작성 공지 한 건인 `pinnedNotice.title`·`pinnedNotice.createdAt` (`GET /crew`). null이면 "아직 공지가 없어요" | `ListRow` + `Icon`(pin) + `Txt` | 3-6 |
| ⑤ | 하단 탭 | 홈 · 피드 · 줍깅 · 모이깅 · 내 정보. 모이깅 선택 | `BottomNav` | 각 탭 |

## 상태

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | ①·⑤는 보이고 ②~④는 `Loading` "크루를 불러오고 있어요" | 벨·하단 탭 |
| 새로고침 | 당겨서 새로고침. 이전 ②~④ 값은 남기고 상단 스피너 | 전부 평소처럼 |
| 빈 | **해당 없음.** MEMBER만 이 화면에 온다. 공지는 `pinnedNotice` null로 표현한다 | ②·③ |
| 오류 | ②~④ 자리에 `ErrorState` "크루를 불러오지 못했어요" / [다시 시도] | 다시 시도 → `GET /crew` |
| 오프라인 | 이전 값이 있으면 그대로, ② 아래 `Banner` "인터넷 연결을 확인해 주세요.". 없으면 오류 상태 | 이전 카드·바로가기·탭 |
| 권한 거부 | **해당 없음.** 권한을 쓰지 않는다 | — |
| 부분 실패 | `GET /crew`는 성공했지만 알림 수를 못 받으면 벨 점을 숨긴다. 공지·바로가기는 그대로 | 전부 |
| 크루장/크루원 | ②의 "크루장" 배지만 `isLeader`에 따라 다르다. 바로가기 구성은 같다 | 전부 |

## 인터랙션

- 스크롤: ②~④가 길면 세로 스크롤, ①·⑤는 고정
- 당겨서 새로고침: 있음. `GET /crew`와 홈 알림 수를 재조회
- 길게 누르기: 없음
- 시트: 없음
- 뒤로 가기: 하단 탭 첫 화면이면 앱을 벗어난다. 다른 화면에서 푸시로 왔으면 이전 화면으로 팝한다
- 키보드: 없음
- 전환: 3-2·3-5·3-7·3-4·3-9·3-6·2-3은 푸시

## 접근성

- ②: "한강줍깅크루, 크루원 18명, 14일 목표 300개, 크루 정보 보기"로 묶어 읽는다
- ③ 바로가기: 각 이름과 안 읽은 채팅 수를 읽는다
- ④: "최신 공지, 9월 정기 활동 안내". null이면 "아직 공지가 없어요"
- 벨·타일·하단 탭은 48dp 이상이다

## 옛 화면과의 차이

- 지금 활동·크루 찾기·예정 활동 세 탭과 장소·크루 검색을 없앴다. 사용자는 크루 하나에만 소속되고 공개 크루 목록도 없다
- 옛 활동 목록·상태 선택·더 찾기 버튼 대신 내 크루 카드와 공지·채팅·기록·달력 바로가기를 넣었다
- 옛 알림 벨·점과 상단 제목·하단 탭의 위치는 유지했다

- `pinnedNotice`는 최신 `createdAt`의 공지 한 건을 자동으로 가리키는 읽기 전용 값이다. 카드에는 제목과 날짜만 보이며 수동 고정은 없다
- 알림 점은 `GET /crew/home`을 함께 조회한다

- 추가 디자인 미결 없음.
