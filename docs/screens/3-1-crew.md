# 3-1 모이깅

**목적** 내 크루의 핵심 상태를 한 화면에서 본다. 최신 공지·채팅으로 가고, 활동 달력과 크루 기록을 탭으로 바로 본다.
**원본** `../legacy/android-res/layout/fragment_meet.xml` · **변경** 지금 활동·크루 찾기·예정 활동 3탭과 검색을 없애고, 하나뿐인 내 크루의 요약 허브로 바꿨다. 활동 달력(3-9)과 크루 기록(3-4)은 별도 화면이 아니라 이 화면의 [달력 | 기록] 탭이다. 탭 이름 "모이깅"만 유지한다.
**진입** 하단 탭 모이깅 · 2-1 홈의 크루 알약 · 2-1 홈의 "크루 기록 보기"(기록 탭으로) · **이탈** 3-2 크루 정보 · 3-5 공지 목록 · 3-6 공지 상세 · 3-7 크루 채팅 · 5-3 활동 기록 상세 · 5-4 타인 프로필 · 2-3 알림

## 배치

같은 곳으로 가는 입구를 두 번 두지 않는다. 공지는 최신 공지 줄 하나, 채팅은 한 줄이다.

```
┌──────────────────────────────────────┐
│ ① 모이깅                         🔔● │
├──────────────────────────────────────┤
│ ② ┌────────────────────────────────┐ │
│    │ (◯) 한강줍깅크루             › │ │
│    │ 크루원 18명 · 목표 14일 300개   │ │
│    └────────────────────────────────┘ │
│ ③ 📌 9월 정기 활동 안내      전체 ›    │
│ ④ 💬 크루 채팅                 ●  ›  │
│ ⑤ [ 달력 | 기록 ]                     │
│    ‹ 2026년 9월 ›                     │
│    … 달력 격자 · 날짜 요약 · 활동 목록 … │
│                                      │
│ ⑥ 홈  피드  줍깅  모이깅  내 정보       │
└──────────────────────────────────────┘
```

## 인터랙션

- 스크롤: 화면 전체가 세로 스크롤. 탭 안에 스크롤을 겹치지 않는다
- 당겨서 새로고침: 있음. 위 표대로
- 길게 누르기·시트·키보드: 없음
- 뒤로 가기: 하단 탭 첫 화면이면 앱을 벗어난다
- 전환: 3-2·3-5·3-6·3-7·5-3·5-4·2-3은 푸시. 탭 전환은 제자리에서 바뀐다

## 접근성

- ②: "한강줍깅크루, 크루원 18명, 14일 목표 300개, 크루 정보 보기"로 묶어 읽는다
- ③: "최신 공지, 9월 정기 활동 안내" · "공지 전체 보기"
- ④: "크루 채팅, 안 읽은 메시지 5개". 0이면 수를 생략한다
- ⑤: 탭은 선택 상태를 읽는다. 탭 안은 3-9·3-4 문서의 접근성 절을 따른다
- 벨·줄·탭은 48dp 이상이다

## 옛 화면과의 차이

- 지금 활동·크루 찾기·예정 활동 세 탭과 장소·크루 검색을 없앴다. 사용자는 크루 하나에만 소속되고 공개 크루 목록도 없다
- 공지·채팅·기록·달력 바로가기 4개를 없앴다. 공지·채팅은 한 줄씩, 달력·기록은 이 화면의 탭이다
- 옛 알림 벨·점과 상단 제목·하단 탭의 위치는 유지했다

- `pinnedNotice`는 최신 `createdAt`의 공지 한 건을 자동으로 가리키는 읽기 전용 값이다
- 알림 점은 `GET /crew/home`을 함께 조회한다
