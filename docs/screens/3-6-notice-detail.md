# 3-6 공지 상세

**목적** 공지 본문과 댓글을 읽고, 크루장은 공지를 수정·삭제하며 크루원은 댓글을 남긴다.
**원본** `../legacy/android-res/layout/fragment_post_detail.xml` · **변경** 작성자 프로필·사진·좋아요·일반 게시물 메뉴를 없애고 공지 제목·본문·최신 여부·댓글로 바꿨다. 공지 관리는 크루장만 한다.
**진입** 3-5 공지 목록 행 · 3-1 최신 공지 · 2-3 NOTICE 알림 · **이탈** 3-5 공지 목록 · 3-12 공지 작성·수정 · 6-1 신고(공지 댓글) · 뒤로 가기

## 배치

옛 상세의 순서(헤더 → 본문 카드 → 메뉴 → 댓글 목록 → 아래 댓글 입력)를 따른다. 사진·좋아요·활동 기록 카드 대신 제목·최신 표시·본문을 넣고, 아래 댓글 입력은 유지한다.

```
┌──────────────────────────────────────┐
│ ① ‹  공지 상세                    ⋯  │
├──────────────────────────────────────┤
│ ② 📌 9월 정기 활동 안내               │
│    9월 1일                             │
│    9월 첫째 주 토요일, 여의도에서...    │
├──────────────────────────────────────┤
│ ③ 댓글 3개                            │
│    (◉) 상혁  확인했습니다!        ⋯   │
│    (◉) 지수  저도 참여할게요.           │
├──────────────────────────────────────┤
│ ④ 댓글을 남겨 보세요.          [전송] │
└──────────────────────────────────────┘
```

## 인터랙션

- 스크롤: ②·③을 세로 스크롤. ④ 댓글 입력은 키보드 위에 고정
- 당겨서 새로고침: 있음. 상세와 댓글 전체를 재조회
- 길게 누르기: 댓글 길게 누르기는 댓글 메뉴와 같다
- 시트: 크루장 공지 메뉴·댓글 메뉴는 바텀 시트
- 뒤로 가기: 3-5 또는 진입 화면으로 팝한다. 키보드가 열렸으면 먼저 내린다
- 키보드: ④에 포커스하면 올라온다. 완료 키는 유효한 입력이면 전송한다
- 댓글 전송: 성공하면 댓글 목록 아래에 추가하고 입력을 비운다. 실패하면 글과 요청 `id`를 보존해 재시도하고 연속 탭·완료 키의 중복 전송을 막는다. 화면 이동 후에도 공지별 댓글 초안을 복원한다
- 전환: 수정은 3-12, 댓글 신고는 6-1, 작성자 프로필은 5-4로 푸시

## 접근성

- ②: "최신 공지, 9월 정기 활동 안내, 9월 1일"과 본문을 순서대로 읽는다
- ③ 댓글은 "상혁, 9월 1일, 확인했습니다!, 댓글 메뉴"로 읽는다
- ④ 입력창은 "댓글, 500자까지", 전송 버튼은 활성·비활성을 읽는다
- 크루장 메뉴는 "공지 관리, 크루장만 가능"으로 읽는다. 모든 조작은 48dp 이상이다

## 옛 화면과의 차이

- 옛 게시물 상세의 작성자·사진·좋아요·활동 기록 카드·게시물 신고를 없애고 공지 제목·본문·최신 표시·댓글로 바꿨다
- 일반 게시물의 본인/크루장 삭제 규칙 대신 공지는 크루장만 수정·삭제한다
- 공지 댓글은 작성자 또는 크루장이 삭제하고, 크루원은 다른 댓글을 6-1로 신고할 수 있다

- 공지는 텍스트만 표시한다. 차단한 작성자의 공식 공지도 유지하며 개인 댓글만 차단한 사람의 화면에서 즉시 숨긴다. 크루장에게 필요한 댓글 관리 정보는 유지한다.
- 최신 표시는 자동 파생되며 삭제 후 다음 최신 공지가 대신한다. 공지를 수정해도 작성 시각 순서는 바뀌지 않는다.

## 미결

- 추가 디자인 미결 없음. 공지 작성자 이름은 현재 스키마에 없어 표시하지 않는다.
