# 1-6 크루 만들기/가입하기

**목적** 아직 크루가 없는 사람이 새 크루를 만들거나, 받은 초대 코드로 가입 신청하는 길을 고른다.
**원본** `../legacy/android-res/layout/fragment_hood.xml` · **변경** 현재 위치·검색·후보 목록·개인정보 안내를 없애고, 두 선택 카드(크루 만들기 / 초대 코드로 가입하기)로 바꿨다. 동네 설정은 없다.
**진입** 1-3 이메일 가입 완료 · 1-4 닉네임 저장 뒤 `membership.status` NONE · 1-1·1-2 로그인 뒤 NONE · 5-7에서 크루 나가기 완료 뒤 · **이탈** 크루 만들기 시트(이 화면 안) → 생성 성공 시 2-1 · 1-8 초대 코드 입력 · 내 활동 기록 → 5-5 기록 전용 진입 → 5-3 · 설정 → 5-7 · 시스템 뒤로 가기 → 앱 벗어나기

## 배치

옛 XML의 순서(헤더 → 짙은 알약 → 큰 제목·설명 → 본문 카드 영역 → 아래 고정 주 버튼)를 따른다. 검색·GPS·결과 목록이 있던 세로 본문을 두 선택 카드로 바꾸고, 아래 고정 버튼 자리는 쓰지 않는다. 두 카드는 제목·설명·오른쪽 화살표가 같은 높이로 쌓인다.

```
┌──────────────────────────────────────┐
│ ① 크루 시작하기                    ⚙ │
├──────────────────────────────────────┤
│ ② 함께 줍는 크루를 선택해 주세요        │
│                                      │
│ ③ ┌────────────────────────────────┐ │
│    │ ＋  새 크루 만들기          ›  │ │
│    └────────────────────────────────┘ │
│                                      │
│ ④ ┌────────────────────────────────┐ │
│    │ #   초대 코드로 가입하기    ›  │ │
│    └────────────────────────────────┘ │
│                                      │
│ ⑥ [내 활동 기록 보기]                  │
└──────────────────────────────────────┘
```

크루 만들기 시트 (③ 을 누르면 이 화면 위로 올라온다. 옛 1-7 을 흡수했다)

```
├──────────────────────────────────────┤
│ ⑦            ▬▬▬▬                    │
│    새 크루 만들기                       │
│    크루 이름                            │
│    [ 예: 한강줍깅크루              ]    │
│    이미 사용 중인 크루 이름이에요.        │  ← 평소 숨김
│    [         크루 만들기          ]    │
└──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 헤더 제목 | "크루 시작하기". 뒤로 화살표는 두지 않는다(누르면 앱이 꺼지는 화살표는 플랫폼 관례에 어긋난다) | `AppHeader` | — |
| ① | 설정 | 톱니 아이콘. 크루가 없어도 로그아웃·탈퇴할 수 있게 한다 | `IconButton`(cog-outline) | 5-7 설정 |
| ② | 큰 제목 | "함께 줍는 크루를 선택해 주세요" | `Txt` display | — |
| ③ | 새 크루 만들기 카드 | "새 크루 만들기" / 오른쪽 화살표. 누르기 직전 소속을 재확인한다 | `Card` + `Icon`(plus) + `Txt` + `Icon`(chevron-right) | ⑦ 크루 만들기 시트 |
| ④ | 초대 코드 가입 카드 | "초대 코드로 가입하기" / 오른쪽 화살표. 가입은 `POST /crews/join-requests`로 신청하고, 승인 전에는 크루원이 아니다 | `Card` + `Icon`(key-outline) + `Txt` + `Icon`(chevron-right) | 1-8 |

| ⑥ | 내 활동 기록 | 현재 소속이 없어도 이전 크루를 포함한 본인 기록 | `Button` ghost lg | 5-5 기록 전용 화면 → 5-3 상세 |
| ⑦ | 크루 만들기 시트 | 제목 "새 크루 만들기" | `BottomSheet` | 스크림·뒤로·끌기 → 닫기(만드는 중에는 닫히지 않는다) |
| ⑦ | 크루 이름 | 라벨 "크루 이름", 플레이스홀더 "예: 한강줍깅크루". 앞뒤 공백을 지워 `name` 으로 `POST /crews` (2~20자). 포커스를 떠날 때 길이 검사 | `Field` | — |
| ⑦ | 이름 오류 | 409 CREW_NAME_TAKEN 은 "이미 사용 중인 크루 이름이에요.", 422 VALIDATION 은 "크루 이름을 다시 확인해 주세요." 입력값 유지 | `Field` 의 error | — |
| ⑦ | 요청 오류 | 409 ALREADY_IN_CREW 는 "이미 크루에 소속돼 있어요." 를 보이고 `GET /users/me` 로 소속을 다시 확인해 MEMBER 면 2-1, PENDING 이면 1-9. 그 밖의 실패는 "크루를 만들지 못했어요. 네트워크 상태를 확인하고 다시 시도해 주세요." | `Banner` danger | — |
| ⑦ | 만들기 버튼 | "크루 만들기". 이름이 규칙에 맞을 때만 활성 | `Button` primary lg | `POST /crews` → 201 이면 온보딩 스택을 지우고 2-1 |

온보딩 완료 후 `GET /users/me`의 `membership.status`가 NONE일 때만 이 화면으로 온다. MEMBER면 2-1, PENDING이면 1-9로 간다. 이 화면은 크루 목록을 내려받지 않으므로 목록·검색·위치 기반 추천을 제공하지 않는다.

## 인터랙션

- 스크롤: 장식 여백부터 줄이고 작은 화면·큰 글씨에서는 헤더 아래 본문 전체 스크롤. 안내와 내 기록 진입을 보존한다
- 당겨서 새로고침: 없음
- 길게 누르기: 없음
- 시트: ⑦ 크루 만들기. 이름 하나만 받으므로 화면을 따로 두지 않는다. 열리면 이름 칸에 포커스·키보드. 만들기가 끝나면 시트가 다 내려간 뒤에 다음 화면으로 넘어간다. 닫았다 다시 열면 입력한 이름은 남고 오류·배너는 지워져 있다
- 뒤로 가기: 시스템 뒤로 가기는 시트가 열려 있으면 시트를 닫고, 아니면 앱을 벗어난다. 로그아웃·계정 삭제가 아니며 재실행 시 미완료 크루 선택을 이어간다
- 키보드: ⑦ 이름 칸 완료 키 = [크루 만들기] 와 같다
- 카드 탭: ③·④ 카드 전체가 터치 영역이다. 짧게 눌렀을 때만 푸시하며 중복 탭은 첫 전환이 시작되면 막는다
- 전환: 1-8·5-7은 푸시. ⑦ 은 아래에서 올라오는 시트. 1-9·2-1은 소속 상태가 바뀐 경우에만 기존 온보딩 스택을 지우고 전환한다

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - ① 설정: "설정"
  - ⑦: 시트가 열리면 제목 "새 크루 만들기" 가 먼저 읽힌다. 이름 오류는 칸의 오류로 붙여 읽는다
  - ③: "새 크루 만들기"
  - ④: "초대 코드로 가입하기"
  - ⑥: "내 활동 기록 보기, 이전 크루의 내 기록 포함"
  - ②의 🌱와 카드의 장식 화살표는 읽지 않는다
- 최소 터치 크기 예외: 없음. ①·③·④는 모두 48dp 이상이며 카드 전체를 누를 수 있다

## 옛 화면과의 차이

- "우리 동네 설정"·"어디에서 함께 주울까요?"·현재 위치 찾기·동네 검색·후보 목록·행정동 개인정보 안내를 모두 없앴다. 새 앱에는 동네 개념이 없다
- 옛 `grantedCard`·`findByGps`·`deniedBanner`·`hoodInput`·`candidateList`·`noResult`·아래 "우리 동네로 설정하고 시작" 버튼 자리에 ③·④ 두 선택 카드를 넣었다
- GPS 권한을 여기서 묻지 않는다. 활동에 필요한 위치 권한은 4-2 활동 시작 시트 안에서 다룬다
- 옛 크루 만들기 화면(1-7)은 이 화면의 ⑦ 시트로 합쳤다(GAC-61)
- 옛 화면은 선택을 저장하면 곧바로 시작했다. 새 화면은 크루 만들기는 곧 크루장이 되고, 초대 코드 가입은 1-9에서 승인 대기한다
