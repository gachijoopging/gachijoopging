# 1-6 크루 선택

**목적** 소속 크루도 승인 대기 신청도 없는 사람이 기존 크루에 들어갈지(크루 검색) 새 크루를 만들지 고른다. 크루에 소속돼야 앱을 쓰므로, 미가입자가 머무는 기본 화면이다.
**원본** `../legacy/android-res/layout/fragment_hood.xml` · **변경** 현재 위치·검색·후보 목록·개인정보 안내를 없애고, 두 선택 카드(기존 크루에 들어가기 / 크루 만들기)로 바꿨다. 동네 설정은 없다. 초대 코드 가입·크루 만들기 시트는 끔(2026-10 회의). 내 활동 기록 진입(⑤)은 유지한다.
**진입** 1-3 이메일 가입 완료 · 1-4 닉네임 저장 뒤 · 1-1·1-2 로그인·앱 실행 때 `membership.status` NONE 이고 `membership.rejection` 이 없을 때 · 1-9 요청 취소 완료·거절 안내 확인 뒤 · 3-11에서 크루 나가기 완료 뒤 · 크루 기능 요청이 403 NO_CREW 일 때 · **이탈** 1-8 크루 검색 · 1-7 크루 만들기 · 내 활동 기록 → 5-5 기록 전용 → 5-3 · 설정 → 5-7(로그아웃·탈퇴만) · 시스템 뒤로 가기 → 앱 벗어나기

## 배치

옛 XML의 순서(헤더 → 짙은 알약 → 큰 제목·설명 → 본문 카드 영역 → 아래 고정 주 버튼)를 따른다. 검색·GPS·결과 목록이 있던 세로 본문을 두 선택 카드로 바꾸고, 아래 고정 버튼 자리는 쓰지 않는다. 두 카드는 제목·설명·오른쪽 화살표가 같은 높이로 쌓인다.

```
┌──────────────────────────────────────┐
│ ① 크루 시작하기                    ⚙ │
├──────────────────────────────────────┤
│ ② 함께 줍는 크루를 선택해 주세요        │
│                                      │
│ ③ ┌────────────────────────────────┐ │
│    │ 🔍  기존 크루에 들어가기    ›  │ │
│    └────────────────────────────────┘ │
│                                      │
│ ④ ┌────────────────────────────────┐ │
│    │ ＋  크루 만들기             ›  │ │
│    └────────────────────────────────┘ │
│                                      │
│ ⑤ [내 활동 기록 보기]                  │
└──────────────────────────────────────┘
```

이 화면에는 `GET /users/me` 의 `membership.status` 가 NONE 이고 `membership.rejection` 이 null 일 때만 온다. MEMBER 면 2-1, PENDING 이면 1-9, 미확인 거절이 있으면 1-9 거절 안내로 간다. 크루 목록은 1-8 이 맡고, 위치 기반 추천은 없다. 하단 탭·알림 등 크루 기능으로 가는 길은 없다. 예외로 본인 활동 기록(⑤)은 볼 수 있다.

- 당겨서 새로고침: 없음
- 길게 누르기: 없음
- 시트: 없음. 크루 만들기는 1-7 화면이다
- 뒤로 가기: 시스템 뒤로 가기는 앱을 벗어난다. 로그아웃·계정 삭제가 아니며 재실행 시 `membership` 분기로 다시 온다
- 키보드: 없음
- 카드 탭: ③·④ 카드 전체가 터치 영역이다. 짧게 눌렀을 때만 푸시하며 중복 탭은 첫 전환이 시작되면 막는다
- 전환: 1-7·1-8·5-7은 푸시. 1-9·2-1은 소속 상태가 바뀐 경우에만 기존 온보딩 스택을 지우고 전환한다

## 옛 화면과의 차이

- "우리 동네 설정"·"어디에서 함께 주울까요?"·현재 위치 찾기·동네 검색·후보 목록·행정동 개인정보 안내를 모두 없앴다. 새 앱에는 동네 개념이 없다
- 옛 `grantedCard`·`findByGps`·`deniedBanner`·`hoodInput`·`candidateList`·`noResult`·아래 "우리 동네로 설정하고 시작" 버튼 자리에 ③·④ 두 선택 카드를 넣었다
- GPS 권한을 여기서 묻지 않는다. 활동에 필요한 위치 권한은 4-2 활동 시작 시트 안에서 다룬다
- 옛 화면은 선택을 저장하면 곧바로 시작했다. 새 화면은 크루 만들기는 곧 크루장이 되고, 공개 크루 가입은 바로 크루원, 비공개 크루 가입은 1-9에서 승인 대기한다
- 2026-10 회의: 초대 코드로 가입하기 카드를 기존 크루에 들어가기(크루 검색) 카드로 바꿨다. 크루 만들기 시트(옛 1-7 을 흡수했던 것)를 다시 1-7 화면으로 뺐다. 내 활동 기록 버튼은 그대로 둔다(미가입자도 본인 기록·통계 조회 가능)
