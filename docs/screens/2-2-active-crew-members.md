# 2-2 활동 중인 크루원 목록

**목적** 지금 활동 중인 크루원의 진행 상황과 공유 위치를 보고, 크루원의 프로필로 이동한다. 보는 사람은 활동 중일 필요가 없다.
**원본** `../legacy/android-res/layout/fragment_friends.xml` · **변경** 친구·받은 요청 탭과 양방향 관계를 없애고, 활동 중인 크루원 한 목록으로 바꿨다. 위치는 공유한 크루원만 "위치 공유 중"으로 보인다.
**진입** 2-1 홈의 "지금 활동 중인 크루원" 카드 · 4-3 활동 중의 크루원 버튼 · 알림의 LIVE 대상 · **이탈** 5-4 타인 프로필 · 뒤로 가기 → 진입 화면

## 배치

헤더 → 활동 수 → 읽기 전용 지도 → 목록 → 안내 순서다. 지도는 활동 중이고 위치 공유를 켠 크루원의 좌표만 표시한다. 내 활동 여부나 내 위치 권한으로 열람을 막지 않는다. 목록 행은 아바타·닉네임·진행 지표·위치 공유 상태로 구성한다.

```
┌──────────────────────────────────────┐
│ ① ‹  활동 중인 크루원          ↻       │
├──────────────────────────────────────┤
│ ② 지금 2명이 활동 중이에요             │
├──────────────────────────────────────┤
│ ⑤ 공유 위치 지도 · 상혁 ●              │
│    위치 공유를 켠 활동만 표시           │
├──────────────────────────────────────┤
│ ③ ┌────────────────────────────────┐ │
│    │ (◉) 상혁         활동 중        │ │
│    │     1.2km · 15분 · 9개           │ │
│    │     ● 위치 공유 중              │ │
│    └────────────────────────────────┘ │
│ ③ ┌────────────────────────────────┐ │
│    │ (◉) 지수         일시정지       │ │
│    │     400m · 5분 · 2개             │ │
│    │     위치를 공유하지 않아요       │ │
│    └────────────────────────────────┘ │
│                                      │
│ ④ 활동 중인 크루원의 위치는            │
│    위치 공유를 켠 경우에만 보여요.      │
└──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 뒤로 버튼 | "뒤로" | `Icon`(arrow-left) | 진입 화면 |
| ① | 헤더 제목 | "활동 중인 크루원" | `Txt` title | — |
| ① | 새로고침 버튼 | "새로고침" | `Icon`(refresh) | `GET /crew/live` 재조회 |
| ② | 활동 수 | `GET /crew/live` 배열의 길이. "지금 2명이 활동 중이에요" · 1명이면 "지금 1명이 활동 중이에요" | `Txt` subtitle | — |
| ③ | 크루원 행 | `user.photoUrl`·`user.nickname`·`activityId`·`startedAt`·`elapsedSec`·`distanceM`·`itemCount`·`paused`·`locationShared`·`location` (`GET /crew/live`) | `ListRow` + `Avatar` + `Badge` | 5-4 |
| ③ | 아바타·닉네임 | `user.photoUrl`이 null이면 `user.nickname` 첫 글자. 닉네임 "상혁" | `Avatar` md + `Txt` body strong | 5-4 |
| ③ | 활동 상태 | `paused` false면 "활동 중", true면 "일시정지" | `Badge` green / neutral | — |
| ③ | 진행 지표 | `distanceM` 1000 미만은 "400m", 이상은 "1.2km" · `elapsedSec`은 "15분" 또는 "1시간 8분" · `itemCount`는 "9개" | `Txt` caption | — |
| ③ | 위치 공유 상태 | `locationShared`가 false면 "위치를 공유하지 않아요". true이고 `location`이 없으면 "위치를 확인하고 있어요", 좌표가 있으면 "위치 공유 중" | `Txt` micro + `Dot` | — |
| ④ | 안내 문구 | "활동 중인 크루원의 위치는 위치 공유를 켠 경우에만 보여요." | `Banner` neutral | — |
| ⑤ | 공유 위치 지도 | `activityId`·`locationShared`·`location`·`paused` (`GET /crew/live`). 활동 중이며 공유가 켜져 있고 좌표가 있는 크루원만 표시한다. 일시정지는 유지하고 종료하면 마커를 제거한다 | `신규` 지도 (4-3의 카카오맵·크루원 마커 재사용) + `Avatar` + `Badge` | 마커를 누르면 크루원 이름·진행 상황, 프로필 보기 |

`GET /crew/live` 뒤 갱신은 `docs/realtime.md`의 LIVE 이벤트를 따른다. LIVE_STARTED는 행을 추가하고, LIVE_UPDATE는 `elapsedSec`·`distanceM`·`itemCount`·`paused`·`locationShared`·`location`을 바꾸며, LIVE_ENDED는 행을 뺀다. 목록은 차단한 크루원을 서버가 이미 걸러 낸 값만 받는다.

## 인터랙션

- 스크롤: 헤더 아래 지도·목록·안내를 세로 스크롤한다. 지도 조작은 보기용 이동·확대만 제공하고 내 위치 수집·활동 시작을 요구하지 않는다
- 당겨서 새로고침: 있음. `GET /crew/live`을 다시 부른다
- 길게 누르기: 없음
- 시트: 없음
- 뒤로 가기: 진입 화면으로 팝한다
- 키보드: 없음
- 행 탭: 행 전체(위치 공유 상태 포함)를 누르면 5-4 타인 프로필로 푸시한다. 자기 자신의 행은 5-5로 대체한다
- 전환: 5-4·5-5는 푸시. LIVE_ENDED로 보고 있던 행이 사라져도 열린 프로필은 닫지 않는다

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - ① 새로고침: "활동 중인 크루원 새로고침"
  - ②: "지금 2명이 활동 중이에요"
  - ③: "상혁, 활동 중, 1.2킬로미터, 15분, 9개, 위치 공유 중, 프로필 보기"처럼 행 하나로 읽는다
  - 위치를 공유하지 않는 행은 "위치를 공유하지 않아요"로 읽고 지도·좌표가 없음을 분명히 한다
  - LIVE_STARTED·LIVE_ENDED로 활동 수가 바뀌면 ②를 live region으로 읽는다
- 지도 마커는 이름·활동 상태·위치 공유 여부를 읽는다. 목록으로 같은 정보에 접근할 수 있다
- 최소 터치 크기 예외: 없음. ①·③·지도 마커의 터치 영역은 48dp 이상이다

## 옛 화면과의 차이

- 친구 목록·받은 요청 탭·친구 요청 수락·거절·친구 검색을 모두 없앴다. 크루원은 별도 친구 관계가 없다
- 옛 목록 행의 친구 상태 대신 활동 상태·거리·시간·줍기 개수·위치 공유 상태를 보인다
- 옛 아래 안내(`fl_note`)는 친구 관계 설명이었다. 새 안내는 위치 공유가 선택이라는 설명으로 바꿨다
- 활동 중인 크루원만 보이므로, 활동을 끝낸 크루원은 LIVE_ENDED와 함께 바로 목록에서 사라진다

## 미결

- 읽기 전용 지도와 목록의 부품은 4-3과 공유한다. 마커의 겹침 처리와 지도·스크롤 제스처는 구현 때 실기기에서 검증한다
