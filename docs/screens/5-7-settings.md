# 5-7 설정

**목적** 프로필·위치 공유·알림 같은 개인 설정을 바꾸고, 필요하면 크루를 나가거나 계정을 정리한다.
**원본** `../legacy/android-res/layout/fragment_settings.xml` (행 `view_settings_row.xml`) · **변경** 우리 동네 변경·지도에 내 활동 표시가 빠지고 그 자리에 위치 공유 기본값·활동 시작 알림 토글이 들어갔다. 크루 나가기 행이 새로 생겼다(다른 크루원이 있는 크루장은 위임 뒤에만). 앱 버전 행을 맨 아래에 더했다
**진입** 5-5 내 정보의 기어 아이콘 · **이탈** 5-9 차단 관리 · 1-5 비밀번호 재설정 · 1-1 시작(로그아웃·회원 탈퇴 직후) · 1-6 크루 만들기/가입하기(크루 나가기 직후) · 3-11 크루원 관리(크루장이 나가기·탈퇴를 시도해 위임이 먼저 필요할 때)

## 배치

옛 XML 의 세로 순서(헤더 → 카드1[프로필 수정·우리 동네 변경·지도에 내 활동 표시·차단 관리] → 카드2[비밀번호 재설정·로그아웃·회원 탈퇴])를 그대로 따르되, 동네·지도 두 행을 위치 공유 기본값·활동 시작 알림 토글로 바꾸고 카드2 맨 위에 크루 나가기 행을 더했다. 카드 밖, 화면 맨 아래에 앱 버전 한 줄을 새로 붙인다. 헤더만 고정이고 그 아래가 세로 스크롤이다(옛 `ScrollView` 그대로).

```

│ ① ‹  설정                             │
├──────────────────────────────────────┤

│      닉네임과 사진을 바꿔요.            │
│ ②-b  위치 공유 기본값          ( ●)  │
```

크루 나가기. 다른 크루원이 있으면 크루장은 먼저 위임한다. 혼자 남은 마지막 크루장은 크루 해산을 명시한 확인 후 나갈 수 있다. 해산 확인의 계약 필드와 서버 처리에 맞춘다.

| 순서 | 하는 것 | 결과 | 다음 |
|---|---|---|---|
| 1 | 행을 누르면 계정별 로컬 미동기화 큐와 `GET /activities/current`를 함께 확인 | 진행 중 또는 로컬 미동기화 기록 있음 | 대화상자 "먼저 활동 종료와 동기화를 완료해 주세요" / "진행 중이거나 아직 저장되지 않은 기록이 있어요. 줍깅 탭에서 종료와 동기화를 완료한 뒤 다시 시도해 주세요." [확인] 하나뿐. 여기서 멈춘다 |
| 1 | 같은 확인 | 현재 활동 없음·로컬 대기 없음 모두 확인 | 확인 대화상자 "크루를 나갈까요?" / "{crew.name}에서 나가요. 크루원 목록에서 빠지고, 활동 기록과 게시물은 그대로 남아요. 다시 가입하려면 초대 코드가 필요해요." [돌아가기] · [나가기](위험) |
| 2 | [나가기] → `POST /crew/leave` | 204 | 대화상자를 닫고 `Snackbar` "크루를 나갔어요." 이 화면과 5-5 등 하단 탭 스택을 모두 지우고 1-6 크루 만들기/가입하기로 교체. 보존된 내 기록은 1-6의 내 활동 기록 → 5-5 기록 모드로 다시 조회 |
| 2 | 같은 요청 | 403 LEADER_MUST_DELEGATE | 확인 대화상자를 닫고 새 대화상자 "위임한 뒤에 나갈 수 있어요" / "크루장은 다른 크루원에게 위임한 뒤에만 크루를 나갈 수 있어요." [닫기] · [크루원 관리로 이동] → 3-11 |

로그아웃. 크루장 여부와 무관하지만 진행 중 활동 또는 계정별 미동기화 큐가 있으면 막는다. 서버 현재 활동 조회가 실패해 안전한 상태를 확인하지 못했을 때도 확인을 재시도하며 토큰·기록을 지우지 않는다.

| 순서 | 하는 것 | 결과 | 다음 |
|---|---|---|---|
| 1 | 로컬 큐·현재 활동 없음 확인 후 대화상자 "로그아웃할까요?" / "이 기기에서 로그아웃돼요. 기록·크루·게시물은 그대로라 다시 로그인하면 이어서 볼 수 있어요." [취소] · [로그아웃] | — | — |
| 2 | [로그아웃] → `POST /auth/logout` | 사전 활동·큐 확인이 끝난 상태에서 204 또는 세션 종료 요청 실패 | 저장된 `accessToken`·`refreshToken` 을 지우고 대화상자를 닫은 뒤 스택 전체를 지우고 1-1 로. 현재 활동 없음과 로컬 큐 비어 있음을 확인한 뒤에만 세션을 정리한다. 계정별 기록을 다른 계정에 넘기거나 미동기화 원본을 지우지 않는다 |

회원 탈퇴. 다른 크루원이 있는 크루장은 먼저 위임한다. 혼자 남은 크루장은 크루 해산과 회원 탈퇴를 함께 명시한 확인 후 진행한다.

| 순서 | 하는 것 | 결과 | 다음 |
|---|---|---|---|
| 1 | 행을 누르면 계정별 로컬 미동기화 큐와 `GET /activities/current`를 함께 확인 | 진행 중 또는 로컬 미동기화 기록 있음 | 크루 나가기와 같은 차단 대화상자("진행 중인 활동이 있으면 회원 탈퇴를 할 수 없어요.") [확인]. 여기서 멈춘다 |
| 1 | 같은 확인 | 현재 활동 없음·로컬 대기 없음 모두 확인 | 확인 대화상자 "정말 탈퇴할까요?" / "계정과 활동 상세 기록(경로 포함)이 삭제되고 되돌릴 수 없어요. 게시물과 크루 합산 기록은 \"탈퇴한 크루원\" 이름으로 남아요." [계속 사용하기] · [탈퇴하기](위험) |
| 2 | [탈퇴하기] → `DELETE /users/me` | 204 | 저장된 토큰을 지우고 대화상자를 닫은 뒤 스택 전체를 지우고 1-1 로. 1-1 에 `Snackbar` "탈퇴가 완료됐어요." |
| 2 | 같은 요청 | 403 LEADER_MUST_DELEGATE | 확인 대화상자를 닫고 크루 나가기와 같은 "위임한 뒤에" 대화상자 → 3-11 |
| 2 | 같은 요청 | 그 외 4xx/5xx | 대화상자를 닫지 않고 `Snackbar` "탈퇴하지 못했어요. 다시 시도해 주세요." |

마지막 크루장 확인: "크루를 해산하고 나갈까요?" / "혼자 남은 크루장이 나가면 크루가 해산돼요. 내 활동 기록은 남아요." [취소]·[해산하고 나가기]. 회원 탈퇴라면 계정·개인 상세 삭제와 크루 해산을 함께 명시한다. 서버가 현재 구성원을 다시 검증하며 그 사이 다른 구성원이 생기면 위임 안내로 전환한다.

활동·로컬 큐 확인 중에는 나가기·로그아웃·탈퇴 요청을 중복 전송하지 않는다. 확인 실패는 입력이나 기록을 지우지 않고 재시도한다. 비밀번호 재설정 완료 시에는 다시 로그인하며, 소셜 전용 계정에 비밀번호 추가 기능은 제공하지 않는다.

## 접근성

- 모든 내용과 동작을 유지한다. 작은 화면·큰 글자에서는 장식과 미리보기 높이를 먼저 줄이고 본문을 스크롤하며, 글자와 48dp 터치 영역은 줄이지 않는다.

- 스크린리더 라벨이 필요한 요소:
  - 뒤로: "뒤로 가기"
  - 위치 공유 기본값 스위치: "위치 공유 기본값, 켜짐" / "위치 공유 기본값, 꺼짐"
  - 활동 시작 알림 스위치: "활동 시작 알림, 켜짐" / "활동 시작 알림, 꺼짐"
  - 크루 나가기: "크루 나가기, 한강줍깅크루에서 나가기"
  - 비밀번호 재설정: 숨겨진 동안은 트리에서 완전히 빠진다(존재 자체가 계정 유형을 드러내지 않게)
  - 회원 탈퇴: "회원 탈퇴" + 힌트 "계정을 삭제해요"
  - 대화상자: 뜨는 순간 제목과 본문을 읽어 준다(live region)
  - 앱 버전: "앱 버전 1.0.0" 그대로 읽는다(정보 값이라 장식이 아니다)
  - chevron: 장식이라 읽지 않는다
- 최소 터치 크기 예외: 없음. 각 행은 48dp 이상(옛 `view_settings_row` 그대로)이고 행 전체가 터치 영역이다 — 스위치가 있는 행도 행 어디를 눌러도 토글된다(스위치 자체만 반응하지 않는다)

## 옛 화면과의 차이

- 우리 동네 변경(`settings_hood`, `rowHood`)·지도에 내 활동 표시(`settings_map`, `rowMap`) → 모두 없음. 동네 개념이 꺼졌다(기능범위)
- 위치 공유 기본값·활동 시작 알림 토글은 신규. 옛 화면의 `rowSwitch` 는 정의만 있고 항상 `visibility="gone"` 이라 실제로 쓰인 적이 없다
- 크루 나가기 행은 신규. 옛 앱은 동네 소속이라 "나간다"는 개념이 없었다(동네를 바꾸는 것으로 대체됐다)
- 회원 탈퇴 문구 "게시글과 동네 수거 통계는 익명으로만 남아요."(`withdraw_desc`) → "게시물과 크루 합산 기록은 \"탈퇴한 크루원\" 이름으로 남아요." 동네 개념 제거와 기능범위의 회원 탈퇴 결정에 맞췄다. 제목 "정말 탈퇴할까요?"(`withdraw_title`)와 버튼 "계속 사용하기"/"탈퇴하기"(`withdraw_keep`/`withdraw_go`)는 그대로
- 로그아웃 문구 "기록·친구·게시글은 그대로"(`logout_desc`) → "기록·크루·게시물은 그대로"(CONTEXT.md 에 따라 "친구" 를 빼고 "게시글"을 "게시물"로). 제목 "로그아웃할까요?"(`logout_title`)는 그대로
- 프로필 수정·차단 관리 행은 그대로
- 앱 버전 행은 신규. 옛 화면에는 없었다
- 비밀번호 재설정 행을 `hasPassword` 로 숨기는 것은 신규 — 옛 화면은 소셜 전용 계정 개념 자체가 이 화면에 반영돼 있지 않았다
