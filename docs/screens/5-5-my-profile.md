# 5-5 내 정보

**목적** 내 프로필과 지금까지 쌓인 누적 수치를 보고, 내 활동 기록과 게시물을 되짚는다.
**원본** `../legacy/android-res/layout/fragment_profile.xml` · `item_record.xml` · `item_post_grid.xml` · `view_record_metrics.xml` · `view_empty_state.xml` · **변경** 동네 표시와 친구 수 링크가 빠지고 크루 알약이 들어갔다. "다가오는 모임" 묶음 자리에 누적 수치 3분할이 들어갔다. 탭 라벨 "피드" → "게시물"
**진입** 하단 탭 내 정보 · 1-6의 내 활동 기록(기록 전용 모드) · **이탈** 설정(5-7) · 프로필 수정(5-8) · 활동 기록 상세(5-3) · 게시물 상세(5-2) · 크루 정보(3-11)

## 배치

옛 XML 의 세로 순서(제목·기어 → 아바타·이름 묶음·[프로필 수정] → upcomingSection → 탭 2개 → 스크롤 목록)를 그대로 따른다. 헤더만 고정이고 프로필·누적 수치·탭·목록을 함께 세로 스크롤한다(옛 `ScrollView` 자리). 옛 "다가오는 모임" 묶음이 있던 자리에 누적 수치 3분할 ③ 이 들어간다 — 옛 `view_record_metrics` 와 같은 3분할 꼴이다. 이름 아래 동네(`area`) 자리에 소개가, 친구 수 링크(`friendCount`) 자리에 크루 알약이 들어간다. 기록 목록은 옛 화면처럼 월별로 묶지 않고 최신순 카드가 이어진다.

```
┌──────────────────────────────────────┐
│ ① 내 정보                          ⚙  │
├──────────────────────────────────────┤
│ ②  ╭────╮  관열  👑크루장    [프로필 수정] │
│    │ 얼굴 │  한강 서쪽 담당              │
│    ╰────╯  [한강줍깅크루 ›]              │
├──────────────────────────────────────┤
│ ③   12          38.4km        412     │
│     활동          거리          개수     │
├──────────────────────────────────────┤
│ ④ [ 기록 ]  [ 게시물 ]                  │
├──────────────────────────────────────┤
│ ⑤ ┌────────────────────────────────┐ │
│   │ (썸네일) 9월 5일(금) 오후 6:02   ⋯ │ │
│   │  27        42분       3.1km      │ │
│   │  개수       시간       거리        │ │
│   └────────────────────────────────┘ │
│   ┌────────────────────────────────┐ │
│   │ (썸네일) 9월 3일(수) 오전 7:10   ⋯ │ │
│   │  0         18분       1.2km      │ │
│   │  ( 줍기 기록 없음 )                │ │
│   └────────────────────────────────┘ │
│            불러오는 중…                 │  ← 다음 장 받을 때만
├──────────────────────────────────────┤
│ ⑥  홈   피드   줍깅   모이깅   내 정보     │
└──────────────────────────────────────┘
```

④ 에서 "게시물" 을 고르면 ⑤ 자리가 3열 사진 그리드로 바뀐다.

```
│ ⑤ ┌────┐┌────┐┌────┐                │
│   │사진 ││사진 ││ 글  │                │
│   │    ││🔒  ││    │                │
│   └────┘└────┘└────┘                │
```

소속 없는 기록 전용 모드는 다음과 같다. 위 기본 화면의 크루 전용 요소는 이 모드에 적용하지 않는다.

```
┌──────────────────────────────────────┐
│ [‹ 뒤로] 내 활동 기록               │
│ 누적 활동 12 · 거리 38.4km · 412개   │
│ (과거·현재 모든 크루의 기록 목록)    │
│ [날짜·시간·거리·개수]          [⋯]  │
└──────────────────────────────────────┘
```

빈 기록은 안내만 표시하고 활동 시작 버튼은 없다. 사진/상세·항목 수정·기록 삭제는 5-3으로 이어진다. 누적·목록은 크루 단위 API로 대체하지 않는다.

## 인터랙션

- 스크롤: ① 헤더만 고정, ②③④⑤ 함께 세로 스크롤(옛 `ScrollView` 와 같다). 끝에 닿으면 `nextCursor` 로 다음 장을 이어 받는다. 받는 동안 목록 아래 "불러오는 중…", 실패하면 그 자리에 [다시 시도] 한 줄
- 당겨서 새로고침: 있음. 지금 보이는 탭의 첫 장과 ②③ 을 다시 받는다. 화면으로 돌아올 때(탭 복귀 · 5-3·5-8 에서 뒤로)도 조용히 다시 받는다 — 프로필을 고치거나 기록을 지우고 돌아오는 길이다
- 길게 누르기: 기록 카드를 길게 누르면 ⋯ 와 같은 삭제 확인 대화상자가 뜬다. 게시물 칸은 없음(게시물 삭제는 5-2 에서 한다)
- 시트: 없음. ⋯ 는 시트가 아니라 확인 대화상자 하나다(선택지가 삭제뿐이다)
- 뒤로 가기: 기본 모드는 홈(2-1) 탭, 기록 전용 모드는 1-6으로 돌아간다. 대화상자가 떠 있으면 먼저 대화상자를 닫는다
- 키보드: 없음. 이 화면에는 입력이 없다
- 전환: 5-7 · 5-8 · 5-3 · 5-2 · 3-11 모두 푸시. 탭 전환은 좌우 슬라이드 없이 내용만 바꾼다

## 접근성

- 모든 내용과 동작을 유지한다. 작은 화면·큰 글자에서는 장식과 미리보기 높이를 먼저 줄이고 본문을 스크롤하며, 글자와 48dp 터치 영역은 줄이지 않는다.

- 스크린리더 라벨이 필요한 요소:
  - 기어: "설정"
  - 아바타: "프로필 사진, 프로필 수정으로 이동"
  - 크루장 배지: 닉네임과 묶어 "관열, 크루장" 으로 읽는다
  - 크루 알약: "한강줍깅크루, 크루 정보 보기"
  - ③ 3분할: 셋을 한 요소로 묶어 "누적 활동 12회, 거리 38.4킬로미터, 개수 412개". 값이 없으면 "누적 수치를 불러오지 못했어요"
  - ④ 탭: "기록 탭, 2개 중 1번째, 선택됨" / "게시물 탭, 2개 중 2번째"
  - ⑤ 기록 카드: 카드 하나를 한 요소로 묶어 "9월 5일 금요일 오후 6시 2분, 27개, 42분, 3.1킬로미터, 활동 기록 상세로 이동". 줍기가 0 이면 끝에 "줍기 기록 없음" 을 붙인다. 썸네일은 읽지 않는다
  - ⑤ 기록 카드의 ⋯: 카드와 별개 요소로 "기록 삭제"(옛 `cd_delete_record` 그대로)
  - ⑤ 게시물 칸: "게시물, 사진, 나만 보기" / 사진이 없으면 "게시물, 글 앞부분을 읽는다". 자물쇠 이모지는 읽지 않고 "나만 보기" 만 읽는다
  - 빈 상태 캐릭터: 장식이라 읽지 않는다
  - chevron·구분선: 장식이라 읽지 않는다
- 최소 터치 크기 예외: 없음. 기어와 ⋯ 는 48dp(옛 `Gachi.IconButton`·`IconButton.Small` 그대로). 크루 알약은 48dp 이상. 기록 카드는 카드 전체, 게시물 칸은 108dp 칸 전체가 터치 영역이다. 소개 글자는 작아 위아래 여백까지 터치 영역에 넣는다

## 옛 화면과의 차이

- 제목 "프로필" → "내 정보"(하단 탭 라벨과 맞춘다). 기어 버튼은 그대로
- 동네(`area`) → 소개. 동네 개념을 끄고, 이름 아래 한 줄 자리를 `intro` 가 쓴다
- 친구 수 링크(`friendCount`, "친구 N") → 크루 알약. 친구 관계가 없어졌고, 그 자리를 소속 크루가 대신한다. 크루원 목록은 3-11 크루 정보에서 본다
- "다가오는 모임"(`upcomingSection`·`upcomingCard`·"예정 모임 전체 →") → 누적 수치 3분할. 모임이 없어져 통째로 빠졌고, 그 자리에 옛 타인 프로필의 `stats` 한 줄을 3분할 꼴로 키워 넣었다
- 크루장 배지는 새로 생겼다. 옛 앱에는 역할 표시가 없었다
- 탭 라벨 "피드" → "게시물". 3열 그리드와 "🔒 나만 보기" 배지는 그대로
- 기록 카드: 활동 이름(`title`, "성수동 저녁 줍깅")이 없어졌다 — 활동에 유형·메모를 넣지 않기로 했으므로 날짜·시각이 제목 자리를 쓴다. 대신 새싹 이모지 자리에 활동 사진 썸네일(`thumbUrl`)이 들어간다
- 기록 카드의 함께한 사람 묶음(`groupRow`·`memberStack`)은 빠졌다. 활동은 언제나 개인 단위다
- 3분할 요약(개수·시간·거리)과 "줍기 기록 없음" 알약, ⋯ 삭제 버튼, 삭제 확인 문구는 그대로
- 삭제 확인의 "이 기록에 연결된 게시글의 기록 카드도 함께 사라져요."(`profile_delete_rec_linked`) 변형은 없앴다. 게시물은 활동과 독립이고 활동 요약은 첨부된 이미지일 뿐이라, 기록을 지워도 게시물은 남는다
- 빈 상태: 기록 문구·버튼은 그대로. 게시물 문구는 "아직 올린 게시물이 없어요" / "기록을 저장한 뒤 언제든 피드에 공유할 수 있어요…" → "아직 올린 게시물이 없어요" / "올린 게시물이 여기에 모여요. 나만 보기로 올린 것도 나에게는 보여요." 아이콘(`ic_sprout`) 자리에 캐릭터
- 무한 스크롤(커서)과 당겨서 새로고침은 새로 생겼다. 옛 화면은 한 번에 전부 받았다
