# 1-10 위치 권한 안내

**목적** 활동을 시작하려는 시점에 경로·거리 기록에 필요한 위치 권한을 설명하고 요청한다.
**원본** `../legacy/android-res/layout/fragment_location_gate.xml` · **변경** 로그인·홈 진입 게이트를 없애고 활동 시작 전 안내로 옮겼다.
**진입** 4-2 활동 시작에서 정확한 위치 권한이 없을 때만 · **이탈** 허용 → 4-2로 돌아가 시작 흐름 계속 · 나중에/뒤로 → 활동을 시작하지 않고 원래 화면.

로그인·가입·크루 생성·승인 성공은 위치 권한과 무관하게 2-1 홈으로 간다. 홈·피드·모이깅·내 정보와 2-2의 크루원 지도 열람을 위치 허용에 묶지 않는다.

## 배치

기존 배경·제목·설명·권한 버튼을 재사용하고 “나중에”를 추가한다. OS 재요청 가능 여부에 따라 허용 또는 설정 버튼 하나만 보인다. 작은 화면·큰 글씨에서는 장식 여백을 줄인 뒤 전체 스크롤한다.

```
┌──────────────────────────────────────┐
│ ① 위치 권한이 필요해요                │
│ ② 활동 경로와 거리를 기록하는 데 써요. │
│    위치 공유를 켜면 크루원에게 내 위치를│
│    보여 줘요. 다른 탭은 지금도 이용할  │
│    수 있어요.                         │
│ ③ (!) 설정에서 위치 권한을 켜 주세요. │
│ ④ [위치 권한 허용] / [설정으로 이동]  │
│ ⑤ [나중에]                           │
└──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 제목 | 위치 권한이 필요해요 | `Txt` display | — |
| ② | 설명 | 활동 경로·거리 기록, 공유 선택 시 크루원에게 위치 표시. 대략적 위치만 허용 시 정확한 위치 필요 안내 | `Txt` body | — |
| ③ | 설정 안내 | OS에서 권한 재요청 불가일 때만 표시. 거부 횟수를 임의로 단정하지 않는다 | `Banner` warn | — |
| ④ | 권한 버튼 | OS 상태에 따라 위치 권한 허용 / 설정으로 이동 | `Button` primary lg | 앱 사용 중 정확한 위치 요청 또는 OS 앱 설정 |
| ⑤ | 나중에 | 활동 시작을 보류하고 다른 기능 이용 | `Button` ghost lg | 원래 화면 복귀 |

위치 공유는 4-2의 별도 선택이며 권한 허용만으로 켜지지 않는다. 이 화면은 서버를 호출하지 않는다. 백그라운드 추적은 활동 중 포그라운드 서비스를 전제로 하며 플랫폼별 실제 동작 검증이 필요하다. 알림·Health Connect는 이 화면에서 묻지 않는다. 걸음수 권한·설치·데이터가 없거나 걷기가 감지되지 않아도 시작·줍기·종료를 막지 않는다.

## 상태

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | OS 상태를 읽어 ④ 표시. 별도 서버 로딩 없음 | ④·⑤ |
| OS 권한 창 열림 | OS 권한 선택지 | OS 창 선택 |
| 정확한 위치 허용 | 안내 닫고 4-2 계속. 자동으로 활동을 생성하지 않는다 | 4-2의 시작 행동 |
| 이번만 허용 | 현재 허용으로 계속. 다음 활동 시작 시 현재 OS 상태를 다시 검사 | 4-2 |
| 대략적 위치만 허용 | “활동 경로를 기록하려면 정확한 위치가 필요해요.” | 정확한 위치 재요청/설정·⑤ |
| 권한 거부 | 설명 유지. 재요청 불가면 설정 안내·버튼 | ④·⑤ |
| 새로고침 | 앱 복귀 때 OS 상태 재확인. 당겨서 새로고침 없음 | — |
| 빈 | 해당 없음. 고정 안내 | — |
| 오류 | 설정 열기 실패 시 “기기 설정 > 앱 > 가치줍깅 > 권한에서 위치를 켜 주세요.” `Snackbar` | 설정 재시도·⑤ |
| 오프라인 | OS 권한 요청은 가능. 허용 후 네트워크 처리는 4-2 규칙 | ④·⑤ |
| 부분 실패 | 해당 없음. 서버 요청 없음 | — |

## 인터랙션

- 스크롤: 장식 여백을 줄여도 넘치면 안내 전체 스크롤. 글씨·터치를 줄이지 않는다.
- 당겨서 새로고침·길게 누르기·키보드: 없음.
- 시트: 앱 안내 위로 OS 권한 창 또는 OS 설정이 열린다.
- 뒤로 가기: “나중에”와 같이 원래 화면 복귀. OS 권한 창의 뒤로 처리는 OS 결과를 따른다.
- 앱 복귀: OS 권한 재확인. 허용이면 안내를 닫고 4-2로 복귀, 미허용이면 설정·나중에 선택 유지.
- 전환: 4-2의 입력 선택은 보존. 허용되거나 보류하면 이 안내만 닫는다.

## 접근성

- 진입 시 제목에 포커스. 설명 변경·거부 안내는 live region으로 읽는다.
- “설정으로 이동, 기기 설정 앱이 열립니다”, “나중에, 활동 시작을 보류합니다”로 읽는다.
- 기존 의미 색상과 48dp 이상 버튼을 사용한다. 장식 배경은 읽지 않는다.

## 옛 화면과의 차이

- 앱 이용 전체를 막던 위치 게이트를 활동 시작 시점으로 옮겼다. 온보딩·승인 뒤에는 직접 홈으로 간다.
- “나중에”와 뒤로 복귀를 제공한다. 이번만 허용 만료도 다음 활동 시작 때만 안내한다.

## 미결

- Android 대상 버전·기기에서 포그라운드 서비스 추적과 화면 꺼짐·권한 회수·설정 복귀 동작을 구현 시 검증해야 한다.
