# 1-7 크루 만들기

**목적** 크루가 없는 사람이 크루 이름·설명·활동 지역·공개 설정을 정해 새 크루를 만들고 크루장이 된다.
**원본** 신규 — 옛 1-7(이름만 받던 화면, 한때 1-6 바텀시트로 통합)을 입력 넷의 별도 화면으로 되살렸다 · **변경** 바텀시트가 아니라 별도 화면이다(2026-10 회의). 활동 지역은 시·도 목록에서 고르고, 공개/비공개는 기본값 없이 고른다
**진입** 1-6 의 "크루 만들기" · 1-8 빈 결과의 [크루 만들기] · **이탈** 생성 성공 → 2-1 홈 · 뒤로 가기 → 진입 화면

## 배치

헤더 아래에 입력 넷을 세로로 쌓고, 아래에 만들기 버튼을 고정한다. 키보드가 올라오면 입력 영역만 스크롤하고 버튼은 키보드 위에 남는다.

```
┌──────────────────────────────────────┐
│ ① ‹  크루 만들기                       │
├──────────────────────────────────────┤
│ ② 크루 이름 *                          │
│    [ 예: 한강줍깅크루              ]    │
│    이미 사용 중인 크루 이름이에요.        │  ← 평소 숨김
│ ③ 크루 설명 (선택)                      │
│    [ 예: 매주 토요일 아침 여의도     ]    │
│ ④ 활동 지역 *                          │
│    [ 시·도를 골라 주세요          › ]   │
│ ⑤ 가입 방식 *                          │
│    ○ 공개    승인 없이 바로 가입        │
│    ○ 비공개  크루장이 승인해야 가입      │
│    공개·비공개 모두 크루 찾기에 나와요.    │
├──────────────────────────────────────┤
│ ⑥ [          크루 만들기          ]     │
└──────────────────────────────────────┘
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 뒤로 버튼·제목 | "크루 만들기" | `AppHeader` | 진입 화면 |
| ② | 크루 이름 (필수) | 라벨 "크루 이름", 플레이스홀더 "예: 한강줍깅크루". 앞뒤 공백·줄바꿈을 지워 `name` (2~20자). 포커스를 떠날 때 길이 검사 | `Field` | 키보드 |
| ② | 이름 오류 | 2자 미만·20자 초과 "크루 이름은 2~20자로 입력해 주세요." · 409 CREW_NAME_TAKEN "이미 사용 중인 크루 이름이에요." · 422 VALIDATION "크루 이름을 다시 확인해 주세요." 입력값 유지 | `Field` 의 error | — |
| ③ | 크루 설명 (선택) | 라벨 "크루 설명 (선택)", 플레이스홀더 "예: 매주 토요일 아침 여의도". 앞뒤 공백을 지워 `intro` (최대 200자). 비우면 보내지 않는다 | `Field` | 키보드 |
| ④ | 활동 지역 (필수) | 라벨 "활동 지역". 고르기 전에는 "시·도를 골라 주세요", 고른 뒤에는 "서울특별시" 같은 이름. 값은 `region` 코드(`Region` 17개). 자유 입력 없음 | `SelectRow` | 지역 시트 |
| ④ | 지역 시트 | 제목 "활동 지역". 시·도 17개를 계약 `Region` 순서(서울특별시 … 제주특별자치도)로 한 줄씩. 고르면 시트를 닫는다 | `BottomSheet` + `ListRow` | 고른 지역으로 ④ 갱신 |
| ⑤ | 가입 방식 (필수) | 라벨 "가입 방식". "공개 — 승인 없이 바로 가입" / "비공개 — 크루장이 승인해야 가입" → `joinPolicy` OPEN·APPROVAL. **기본값 없음** — 처음에는 둘 다 선택 안 됨. 아래 안내 "공개·비공개 모두 크루 찾기에 나와요." | `SelectRow` | 그 값 선택 |
| ⑥ | 만들기 버튼 | "크루 만들기". 이름이 규칙에 맞고 ④·⑤ 를 골랐을 때만 활성 | `Button` primary lg | `POST /crews` (`name`·`intro`·`region`·`joinPolicy`) |

서버 응답. 오류 봉투의 `code` 로 갈린다. `message` 는 화면에 쓰지 않는다.

| 응답 | 보이는 것 |
|---|---|
| 201 | 온보딩 스택을 지우고 2-1 홈. `Snackbar` "{name} 크루를 만들었어요." |
| 409 CREW_NAME_TAKEN · 422 VALIDATION | ② 아래 이름 오류. 나머지 값 유지 |
| 409 ALREADY_IN_CREW | `Snackbar` "이미 크루에 소속돼 있어요." 뒤 `GET /users/me` 대로 2-1 |
| 409 JOIN_REQUEST_PENDING | `Snackbar` "승인 대기 중인 가입 요청이 있어요. 요청을 취소한 뒤 만들 수 있어요." 뒤 1-9 (다른 기기에서 신청한 경우) |
| 그 외 4xx·5xx·네트워크 실패 | ⑥ 위 `Banner` danger "크루를 만들지 못했어요. 네트워크 상태를 확인하고 다시 시도해 주세요." 입력값 유지 |

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | **해당 없음.** 서버를 부르지 않는다. 지역 목록은 계약의 고정 목록이다. ② 에 포커스·키보드 | 전부(⑥ 은 조건이 맞을 때) |
| 새로고침 | **해당 없음.** 입력 화면이다 | — |
| 빈 | **해당 없음.** 빈 입력은 초기 상태다 | — |
| 오류 | 위 응답 표대로 | 전부. 다시 시도는 ⑥ |
| 오프라인 | 화면은 평소와 같다. ⑥ 을 누르면 네트워크 실패 `Banner` | 전부 |

## 인터랙션

- 스크롤: ②~⑤ 가 세로 스크롤. ⑥ 은 아래 고정이며 키보드 위로 올라간다
- 당겨서 새로고침: 없음
- 길게 누르기: 입력창의 OS 기본 붙여넣기
- 시트: ④ 지역 시트. 시스템 뒤로 가기는 시트를 먼저 닫는다
- 뒤로 가기: 입력이 하나라도 있으면 대화상자 "크루 만들기를 그만둘까요?" / [계속 만들기] [그만두기]. 없으면 바로 팝. 만드는 중에는 무시
- 키보드: ② 다음 키 → ③, ③ 완료 키 → 키보드를 내린다
- 중복 요청: ⑥ 은 첫 탭 뒤 잠근다
- 전환: 1-6·1-8 → 1-7 은 푸시. 2-1·1-9 로 갈 때는 온보딩 스택을 지운다

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - ②: "크루 이름, 필수, 2자에서 20자". 오류는 칸에 붙여 읽는다
  - ③: "크루 설명, 선택, 200자까지"
  - ④: "활동 지역, 필수, 서울특별시" 또는 "활동 지역, 필수, 선택 안 됨"
  - ⑤: "가입 방식, 필수" 묶음 안에서 "공개, 승인 없이 바로 가입" / "비공개, 크루장이 승인해야 가입" 과 선택 상태를 읽는다
  - ⑥: 비활성이면 비활성으로, 만드는 중이면 "만드는 중"
- 최소 터치 크기 예외: 없음. 입력·선택 행·시트 행·버튼 모두 48dp 이상

## 옛 화면과의 차이

- 옛 1-7 은 이름 하나만 받았고 1-6 바텀시트로 합쳤다가, 입력이 넷이 되어 별도 화면으로 되돌렸다(2026-10 회의)
- 크루 설명·활동 지역(시·도)·가입 방식을 새로 받는다. 초대 코드는 만들지 않는다
