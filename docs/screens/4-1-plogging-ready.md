# 4-1 줍깅 대기

**목적** 줍깅 버튼을 **처음 누른 사람에게만** 보이는 온보딩 화면이다. 무엇을 하는 탭인지 한 번 보여 주고 활동 시작 시트로 잇는다.
**온보딩** 이 화면을 한 번 보면 기기에 기록하고, 그 뒤로 하단 가운데 줍깅 버튼은 이 화면을 거치지 않는다 — 진행 중 활동이 있으면 곧장 4-3, 없으면 지금 보고 있는 탭 위에 4-2 시트를 띄운다. 앱을 지웠다 다시 깔면 기록이 지워져 한 번 더 보인다.
**원본** `../legacy/android-res/layout/sheet_start.xml`의 시작 진입점 · **변경** 혼자/근처 사람 선택과 참여 요청을 없애고, 활동을 시작하거나 이어가는 단일 대기 화면으로 바꿨다.
**진입** 하단 줍깅 버튼(처음 한 번만) · 4-7 활동 종료 요약의 "닫기" · 4-2 활동 시작 시트 닫기 · **이탈** 4-2 활동 시작 시트 · 4-3 활동 중 · 4-7 종료 대기 요약 · 1-10 위치 권한 안내

## 배치

옛 시작 시트의 손잡이·제목·주 버튼 리듬을 전체 탭 화면으로 확장한다. 진행 중 활동이 없을 때는 큰 새싹 그림·설명·시작 버튼, 있을 때는 현재 활동 요약 카드·이어가기 버튼을 보인다. 하단 탭은 유지한다.

```
┌──────────────────────────────────────┐
│ ① 줍깅                                │
├──────────────────────────────────────┤
│ ②             🌱                      │
│    지금 주운 것을 기록해 보세요. │
│ ④ [          줍깅 시작          ]      │
├──────────────────────────────────────┤
│ ⑤ 홈  피드  줍깅  모이깅  내 정보       │
└──────────────────────────────────────┘

진행 중 활동이 있으면 ②~④가 다음으로 바뀐다.
│ ② 활동을 이어갈까요?                   │
│ ③ ┌ 1.2km ┊ 42분 ┊ 17개 ┐             │
│    │ 거리   ┊ 시간 ┊ 줍기 │             │
│    └ [일시정지 중] [위치 공유 중] ┘     │
│ ④ [          활동 이어가기      ]      │
종료 대기면: 이전 기록 동기화 대기 · [요약 보기] [다시 시도]
새 활동 시작만 비활성, 하단 탭은 유지한다.
```

## 요소

| 구역 | 요소 | 내용 (계약 필드) | 컴포넌트 | 탭하면 |
|---|---|---|---|---|
| ① | 제목 | "줍깅" | `Txt` display | — |
| ② | 대기 그림·문구 | 새싹 그림과 "지금 주운 것을 기록해 보세요." | `신규` 빈 상태 캐릭터 + `Txt` section | — |
| ② | 진행 중 제목 | `GET /activities/current`의 `data`가 있으면 "활동을 이어갈까요?" | `Txt` section | — |
| ③ | 현재 활동 요약 | 거리·시간·줍기 세 칸. 일시정지 중이면 시간 칸이 흐리고 "일시정지 중" 칩. 위치 공유 칩. `distanceM`·`startedAt`·`pausedSec`·`paused`·`pausedAt`·`itemCount`·`locationShared` (`GET /activities/current`) | `Card` + `MetricSplit` + `Chip` | — (이어가기는 ④ 하나) |
| ④ | 시작 버튼 | "줍깅 시작". 위치 권한이 있으면 4-2를 연다 | `Button` primary lg | 4-2 |
| ④ | 이어가기 버튼 | 진행 중이면 "활동 이어가기" | `Button` primary lg | 4-3 |
| ⑤ | 하단 탭 | 홈 · 피드 · 줍깅 · 모이깅 · 내 정보. 줍깅 선택 | `BottomNav` | 각 탭 |

현재 활동 시간은 `startedAt`부터 현재까지에서 `pausedSec`을 뺀 값으로 "42분" 또는 "1시간 8분"으로 보인다. `distanceM`은 1000 미만이면 "820m", 이상이면 "1.2km". 현재 `paused`가 true이면 `pausedAt`까지만 활동 시간을 계산하고 이후 시간은 누적하지 않는다. 로컬 저장 상태를 먼저 복원하고 서버 응답과 맞춘다. `pausedSec`만으로 현재 정지 여부를 추측하지 않는다.

## 상태

| 상태 | 보이는 것 | 눌리는 것 |
|---|---|---|
| 첫 진입 로딩 | ①·⑤는 보이고 ②~④ 자리에 `Loading` "활동을 확인하고 있어요" | 하단 탭 |
| 종료 동기화 대기 | 계정별 로컬 종료 기록이 있으면 서버가 IN_PROGRESS여도 이어가기 대신 "이전 기록 동기화 대기"·[요약 보기]·[다시 시도]. 새 활동 시작만 비활성 | 4-7·재시도·하단 탭 |
| 대기 | 미동기화 종료가 없고 `data`가 null. ② 대기 그림·④ "줍깅 시작" | 시작 → 위치 권한 확인 |
| 진행 중 | `data`가 있음. ② 진행 중 제목·③ 요약·④ "활동 이어가기" | 이어가기 → 4-3 |
| 새로고침 | 당겨서 새로고침. 기존 대기·진행 중 값을 남기고 상단 스피너 | 평소처럼 |
| 빈 | **해당 없음.** data null은 대기 상태로 표현한다 | 시작 |
| 오류 | `GET /activities/current` 4xx·5xx면 `ErrorState` "활동 상태를 불러오지 못했어요" / [다시 시도] | 다시 시도 |
| 오프라인 | 이전 상태가 있으면 그대로, ① 아래 `Banner` "인터넷 연결을 확인해 주세요.". 값이 없으면 오류 상태 | 이전 이어가기·탭 |
| 권한 거부 | 위치 권한이 없고 시작을 누르면 1-10을 모달로 연다. 허용 뒤 4-2를 다시 연다 | 위치 권한 안내 |
| 부분 실패 | **해당 없음.** 현재 활동 조회 하나다 | — |
| 다른 기기에서 종료됨 | 이어가기 뒤 4-3 진입 시 활동이 없으면 "활동이 이미 끝났어요." `Snackbar` 뒤 이 화면을 재조회한다 | 시작 |

## 인터랙션

- 스크롤: 없음. 작은 화면에서는 ②~④만 세로 스크롤
- 당겨서 새로고침: 있음. `GET /activities/current` 재조회
- 길게 누르기: 없음
- 시트: 대기 상태의 ④가 4-2 활동 시작 시트를 연다
- 온보딩: 이 화면이 보이면(포커스) 온보딩을 본 것으로 기록한다. 이후 하단 줍깅 버튼은 4-3 또는 지금 탭 위의 4-2 로 곧장 간다
- 뒤로 가기: 하단 탭 첫 화면이라 앱을 벗어난다
- 키보드: 없음
- 시작: 로컬 미동기화 종료가 있으면 4-7로 안내하고 새 활동을 만들지 않는다. 위치 권한이 있으면 4-2. 없으면 1-10 허용 후 4-2. 4-2를 닫으면 이 화면으로 돌아온다
- 이어가기: 로컬에서 아직 진행 중인 활동만 4-3으로 푸시. 백그라운드 알림을 누른 경우와 같은 활동 id를 연다

## 접근성

- ② 대기 상태: "줍깅 대기, 지금 주운 것을 기록해 보세요"
- ③ 진행 중 요약: "진행 중인 활동, 1.2킬로미터, 42분, 17개" (일시정지 중이면 ", 일시정지 중")
- ④: "줍깅 시작" 또는 "활동 이어가기"
- 하단 탭·주 버튼은 48dp 이상이다

## 옛 화면과의 차이

- 옛 시작 시트의 혼자/근처 사람 선택과 참여 요청 받기 토글을 없앴다. 활동은 언제나 개인 단위다
- 위치 공유 토글은 4-2 활동 시작 시트가 맡는다
- 진행 중인 활동을 앱 재실행 뒤 이어가는 상태를 새로 추가했다

## 미결

- 활동 없음 새싹 그림은 기존 캐릭터 디자인으로 제작해야 한다.
- `paused`·`pausedAt` 복원과 계정별 내구성 대기열은 계약을 따르는 구현이 필요하다. 앱 재실행·오류·로그아웃·새 시작 시 미동기화 데이터를 삭제하지 않는다.
