# 4-3 활동 중

**목적** 활동하는 동안 거리·시간·줍기 개수를 보며 줍기를 기록하고, 활동 중 위치를 공유하는 크루원을 지도에서 본다.
**원본** `../legacy/android-res/layout/fragment_active.xml` (+ `view_map_frame`, `view_metric_row`) · **변경** 모임 라벨→위치 공유 표시, 멤버 알약→활동 중인 크루원, 그룹 버튼→채팅, 음소거·마이크→일시정지/재개, 지표 3칸→4칸(걸음 추가), GPS 배너를 세 가지로 나눔, 오프라인 문구 변경, 배경 알림창 신설
**진입** 활동 시작 시트(4-2)에서 시작 성공 · 줍깅 대기(4-1)에 들어왔는데 진행 중 활동이 있을 때(`GET /activities/current`) · 배경 알림창 탭 · 활동 중에 하단 탭 줍깅 · AI 분류 확인(4-5)·빠른 줍기 시트(4-6)에서 돌아올 때 · **이탈** 사진 촬영(4-4) · 빠른 줍기 시트(4-6) · 크루 채팅(3-7) · 활동 중인 크루원 목록(2-2) · 활동 종료 요약(4-7). 뒤로 가기는 활동을 끝내지 않는다 — 화면만 접는다

## 배치

옛 XML 의 겹침 순서(전체 지도 → 상단 오버레이[라벨 줄·지표 카드·경고 칩] → 왼쪽 아래 수거 알약 → 하단 바[왼쪽·가운데 촬영·오른쪽])를 그대로 따른다. 지도가 화면 전체를 채우고 나머지는 그 위에 뜬다. 하단 탭은 이 화면에서 숨기고 자체 하단 바가 그 자리를 쓴다(옛 화면과 같다). 지표 카드가 3칸에서 4칸이 됐고, 경고 칩 자리는 상황에 따라 다른 배너 하나가 들어오는 슬롯이다. 작은 화면·큰 글자에서는 지도 높이·장식 여백을 먼저 줄이고 지표·조작 영역을 스크롤한다. 글자나 48dp 터치 영역은 줄이지 않는다.

위치 점 하나가 들어올 때 하는 일(기능범위 "위치 품질"). 여기서 떨어진 점은 지도·거리·소켓 어디에도 쓰지 않는다.

| 순서 | 검사 | 떨어지면 |
|---|---|---|
| 1 | 오차 반경 30m 초과 | 버림. 15초 넘게 이어지면 ④ "GPS 불안정" |
| 2 | 직전 통과 점 대비 초속 5m 초과 이동 | 버림 |
| 3 | 최근 3~5점 평균으로 평활화 | (항상 통과) 평활화된 점을 경로·거리에 쓴다 |
| 4 | 비정지 보행 구간의 유효한 걸음수가 있고 GPS 누적 거리가 걸음×0.7m보다 30% 넘게 큼 | 해당 구간 표시·전송 거리만 보정. 미측정·지연·쓸 수 없는 0 또는 비보행이면 보정하지 않고 필터 통과 GPS 거리를 유지한다. 경로 선은 그대로 |

일시정지 중에도 위치 품질을 통과한 현재 위치는 공유하되 경로·거리·걸음에는 누적하지 않는다. 통과한 점은 5초마다 소켓 `/app/crew/live` 로 보낸다(`activityId`·`location`·`distanceM`·`itemCount`·`elapsedSec`·`paused`). 위치 공유를 끈 활동은 `location` 을 null 로, 나머지는 그대로 보낸다. 앱이 배경에서 소켓을 잃으면 같은 몸을 `POST /activities/{id}/live` 로 보낸다.

지도 열람자는 활동 중일 필요가 없다. 활동 밖에서는 2-2의 읽기 전용 지도를 이용한다. 표시 대상만 진행 중·공유 켬으로 제한한다. 일시정지도 IN_PROGRESS로 공유·줍기 기록은 유지한다.

로컬 저장은 계정별로 활동 상태·경로·거리·걸음·줍기 요청 id·종료 스냅샷을 보존한다. 앱 재실행 시 복구하며 진행 중 또는 미동기화 데이터가 있으면 로그아웃·크루 나가기·탈퇴를 막는다. 종료 대기 상태를 활동 재개로 잘못 열지 않는다.

| 오프라인 | ④ `Chip` warn "오프라인"(스크린리더는 "오프라인, 기록은 계속돼요. 연결되면 보내요"). 지도 타일은 캐시된 것만, 없으면 회색 바탕 위 "지도를 불러오지 못했어요". 경로·거리·시간·걸음은 계속 쌓인다. 크루원 마커는 마지막 위치에 멈추고 흐려진다(muted). 위치 전송은 쌓아 두지 않는다(마지막 값만 의미 있음). 줍기(4-6 빠른 줍기)는 기기에 쌓아 두고 연결되면 `POST /activities/{id}/items` 로 보낸다 — ③ ⑥ 개수는 바로 오른다. 촬영 화면은 오프라인 안내와 빠른 줍기(4-6) 진입을 제공한다. **종료**는 오프라인이어도 로컬 저장 후 즉시 4-7로 이동한다 | 전부. 종료 가능 |
| 권한 거부 | **위치.** 활동 중 위치 권한이 회수되거나 OS 위치가 꺼지면 ④ `Banner` danger "위치가 꺼져 있어요. 거리와 경로를 기록할 수 없어요" + [설정 열기]. 시간·줍기 개수·걸음은 계속. 소켓엔 `location` null 로 보낸다(크루원 지도에서 내 마커가 사라진다). 되면 배너가 걷히고 새 선을 시작한다. **카메라** 거부는 4-4 가 다룬다. **알림** 권한이 없으면 ⑨ 가 안 보일 뿐 추적은 된다(Android 13+). **Health Connect** 거부·미설치면 ③ 걸음 "측정 안 됨" 이고 4단계 보정을 건너뛴다 | 전부 |
| 부분 실패 | `GET /crew/live` 는 왔는데 소켓이 안 붙은 경우: 마커는 초기 위치에 멈춘다. ④ `Chip` info "연결 중…"(재연결 1·2·4·8·최대 30초 간격). 그동안 내 위치는 `POST /activities/{id}/live` 로 보낸다. 붙으면 `GET /crew/live` 를 다시 받아 마커를 맞추고 칩이 걷힌다 | 전부 |
| GPS 검색 중 | 시작·재개 직후, 또는 통과한 점이 10초 넘게 없을 때 ④ `Chip` info "위치를 찾고 있어요". 첫 점이 통과하면 걷힌다 | 전부 |
| GPS 불안정 | 오차 30m 초과로 15초 넘게 점이 버려지면 ④ `Chip` warn "GPS 불안정"(스크린리더는 "GPS 불안정, 경로 정확도가 낮을 수 있어요"). 통과한 점이 다시 들어오면 걷힌다. 유효한 보행 걸음수가 있을 때만 4단계 보정을 쓰고, 없으면 필터 통과 GPS 거리만 유지한다 | 전부 |

## 인터랙션

- 스크롤: 공간 부족 시 지표·조작 영역을 세로 스크롤하며 지도 영역은 분리한다. 지도는 드래그·확대·축소된다. 지도를 옮기면 내 위치 따라가기가 풀리고 ⑤ 가 나타난다
- 당겨서 새로고침: 없음(지도 드래그와 겹친다). 크루원은 복귀 때마다 조용히 다시 받는다
- 길게 누르기: 없음
- 시트: 4-6 빠른 줍기 시트가 이 화면 위에 뜬다. 시트 뒤로 지도·지표가 보이고 시간은 계속 흐른다
- 뒤로 가기: 활동을 끝내지 않는다. 화면을 접고 직전에 있던 하단 탭 화면(없으면 2-1 홈)으로 돌아간다. 하단 탭 줍깅에 배지가 켜지고 누르면 4-3 으로 돌아온다. ⑧ 이 떠 있으면 대화상자만 닫는다(계속 줍기와 같다). 말풍선이 떠 있으면 말풍선만 닫는다. 로컬 종료 저장 중엔 중복 전환을 막는다
- 키보드: 없음
- 화면 꺼짐: 4-3 이 앞에 있는 동안은 화면이 자동으로 꺼지지 않는다. 다른 화면으로 가면 OS 기본으로 돌아간다. 꺼져도 추적은 이어진다(배경 상태)
- 일시정지/재개: 누르는 즉시 로컬 `paused`·`pausedAt`·누적 정지 시간을 보존하고 바뀐다(응답 대기 없음). 시간·거리·걸음 누적을 모두 멈추며 재개 뒤 정지 구간 걸음은 제외한다. 재개하면 "위치를 찾고 있어요" 부터 다시 시작하고, 재개 지점부터 새 경로 선을 그린다
- 종료: [활동 종료] → ⑧ → [종료하기] → 로컬 줍기 대기열·종료 스냅샷 보존 → 추적·실시간 송신·⑨ 끄기 → 즉시 4-7. 온라인·오프라인 동일하다. 4-3은 스택에서 지우고, 대기열의 줍기·되돌리기를 먼저 동기화한 뒤 종료 요청을 보낸다. 새 활동은 종료 동기화 완료 전까지 막는다. 0개·짧은 활동도 저장한다.
- 24시간 자동 종료: 시작 후 24시간이 되면 [종료하기]와 같은 경로로 끝내고 4-7 로 간다(⑧ 이 떠 있으면 닫는다). 종료 시각은 시작 + 24시간이고, 경로·거리·걸음은 그 시점까지만 담는다. 화면이 꺼져 있어도 배경 위치 추적이 그 시각에 끝내고 추적을 끈다. 앱이 꺼져 있었으면 다음 실행·복귀 때 4-3 을 열지 않아도 같은 값으로 끝낸다. 앱이 앞에 있는 동안은 1분마다 검사해, 다른 화면에 있거나 위치가 꺼져 있어도 끝낸다(4-7 로는 4-3 으로 돌아왔을 때 간다). 4-4·4-5 가 위에 떠 있으면 4-3 으로 돌아왔을 때 4-7 로 간다. 기기 저장에 실패하면 ⑧ 이 열려 "기록을 저장하지 못했어요. 다시 시도해 주세요." 와 [종료하기] 재시도를 보인다. 4-3 밖에서 저장에 실패하면 4-3 을 열어 다시 시도한다. 오프라인이어도 같다(`docs/feature-scope.md` "활동 최대 시간")
- 크루원 마커 탭: 말풍선 3초. 다른 마커를 탭하면 바로 옮겨 간다
- 전환: 4-4 · 3-7 · 2-2 푸시(뒤로 가기로 4-3 복귀, 시간은 그동안 흐른다). 4-6 시트. 4-7 은 4-3 을 대체. 배너·칩은 나타나고 사라질 때만 짧게 페이드
- 재실행 때 로컬 경로가 없으면 서버의 마지막 거리와 정지 상태를 복원하고 경로 일부 없음 안내를 보인다

## 접근성

- 스크린리더 라벨이 필요한 요소:
  - 지도: "지도, 내 경로와 활동 중인 크루원". 경로 선·내 위치 점은 읽지 않는다
  - 크루원 마커: "상혁, 1.2km, 9개" · 일시정지면 "상혁, 일시정지 중, 1.2km, 9개". 탭 힌트 "자세히 들으려면 두 번 탭"
  - ② 위치 공유 칩: "위치 공유 중" / "위치 공유 꺼짐" 그대로
  - ② 크루원 알약: "활동 중인 크루원 2명, 목록 보기"
  - ② 활동 종료: "활동 종료"
  - ③ 지표 카드: 한 요소로 묶어 "줍기 17개, 활동 시간 42분, 이동 거리 2.1킬로미터, 3200걸음". 초는 넣지 않는다 — 초점이 카드에 있으면 라벨이 바뀔 때마다 다시 읽힌다(live region 아님) — 걸음 "측정 안 됨" 은 "걸음수 없음"
  - ④ 배너: 나타나는 순간 문구를 읽어 준다(live region). 위치 꺼짐 배너의 버튼은 "위치 설정 열기"
  - ⑤: "내 위치로 이동"
  - ⑥: "줍기 17개, 빠른 줍기 열기"
  - ⑦ 채팅: "크루 채팅, 읽지 않은 메시지 있음" / 점이 없으면 "크루 채팅" · 촬영: "쓰레기 촬영" · 일시정지: "일시정지" / "재개"
  - ⑧: 뜨는 순간 제목과 본문을 읽어 준다. 초점은 [계속 줍기] 에 먼저
  - ⑨: 제목·본문이 알림 그대로 읽힌다
- 최소 터치 크기 예외: ② 칩 세 개는 sm 알약이라 보이는 높이가 48dp 보다 작다 — 위아래 여백까지 터치 영역에 넣는다. ⑦ 채팅·일시정지 원은 48dp, 촬영은 그보다 크다. 크루원 마커는 `Avatar` sm 이라 작다 — 마커 주변 48dp 를 터치 영역으로 잡고, 겹치면 위에 그려진 것이 받는다

## 옛 화면과의 차이

- 모임 라벨(`activityLabel`, "1인 모임"/모임 이름) → 위치 공유 칩. 활동은 항상 개인 단위라 모임 이름이 없다
- 멤버 알약(`memberPill`, "멤버 N") → 활동 중인 크루원 알약("크루원 N"). 수의 출처가 방 인원에서 `GET /crew/live` 로 바뀌고 항상 보인다(옛 화면은 1인이면 숨김)
- 지표(`view_metric_row`) 3칸 "수거 개수 · 활동 시간 · 이동 거리" → 4칸 "줍기 개수 · 활동 시간 · 이동 거리 · 걸음". 용어 수거→줍기
- GPS 칩(`gpsChip`) 하나 → 검색 중 · 불안정 · 위치 꺼짐 세 가지. 불안정 문구는 그대로
- 오프라인 칩 "📴 오프라인 · 촬영과 직접 분류만 가능해요" → "오프라인"(설명 "기록은 계속돼요. 연결되면 보내요" 는 스크린리더 이름으로). 칩에는 상태 한 마디만 둔다. 빠른 줍기가 오프라인에도 기록되기 때문
- 수거 알약(`pickupChip`, "수거 N개" + 미분류 배지) → 줍기 알약 "줍기 N개". 미분류 배지(`unclassBadge`)는 없음 — 4-5 에서 분류를 확인한 뒤 저장하므로 미분류가 생기지 않는다. 누르면 수거 목록 시트(`sheet_pickup`)가 아니라 4-6 빠른 줍기 시트
- 하단 바 왼쪽 그룹(`groupButton`, 참여 요청 점) → 채팅(읽지 않음 점). 오른쪽 마이크·음소거(`voiceButton`) → 일시정지/재개. 가운데 촬영은 그대로
- 참여 요청·멤버 관리(신고·차단) 시트, 음성 통화 안내 문구는 모두 없음(함께줍깅·무전 끔)
- 종료 확인 문구는 1인용 본문(`act_end_body_solo`)만 남기고 모임용(`act_end_body_group`)은 뺐다. 버튼 "계속 줍기"·"종료하기" 그대로
- 내 위치로 버튼(`mapMyLocation`)은 옛 레이아웃에 있었으나 이 화면에서 켰는지 확실치 않다. 새 화면은 따라가기가 풀렸을 때만 보인다
- 배경 알림창·화면 꺼짐 방지·위치 필터 4개·걸음수 보정은 새로 정했다
