# 기능 범위

새 저장소(GitHub)로 옮길 문서다. 백엔드는 지우지 않고 필요한 기능만 살린 뒤 나머지를 끈다.
용어는 `../CONTEXT.md` 를 따른다.

**1차** 는 이번에 만드는 범위, **이후** 는 다음 릴리스로 미룬 것이다.

## 진행 순서

1. API 계약 문서(OpenAPI) 작성
2. 앱 프론트 완성 — 목 데이터 기반
3. 백엔드 정리(필요한 기능 살리고 나머지 끔)·신규 구현
4. 앱과 백엔드 연결, 테스트, 마무리

## 결정된 것

| 영역 | 결정 |
|---|---|
| 저장소 | GitHub 새 저장소. 이 폴더(`next/`)가 그 루트가 된다. 들어가는 것: 이 문서들 · `design-system` · 새 RN 앱 · `backend` 복사본(끌 것을 끈 상태) · `infra` 복사본(컨테이너 4개). `ai` 는 담당자가 정한다. 옮긴 뒤 이 모노레포는 읽기 전용 보존 |
| 제품 | 여러 크루가 각자 쓰는 크루 운영 앱 |
| 무전(LiveKit) | 끔. 앱·서버·인프라에서 제거 |
| 인증 | 이메일+비밀번호, 카카오·구글 소셜 모두 유지. 이메일 계정에 소셜을 연결하는 기존 흐름 유지. iOS 를 넣을 때 Apple 로그인 문제(ADR-0003)를 다시 본다 |
| 관리자 웹 | 새 저장소로 옮기지 않는다. 코드와 `openapi-admin.yaml` 은 이 모노레포에 남고, 이후 크루 웹을 만들 때 참고만 한다 |
| 크루 웹 | 이후. 크루장 운영 도구(가입 승인·공지·활동 내역·CSV 다운로드) + 외부용 크루 소개 페이지 |
| CSV 내보내기 | 1차. 크루장만. 기간(시작일·종료일)을 골라 활동 한 회가 한 행: 날짜 · 크루원 · 거리 · 시간 · 카테고리별 수량 7열. 앱의 내보내기 버튼 → OS 공유 시트. 기존 관리자 Export(줍기 좌표 단위)와 형식이 다르므로 새 API |
| 기록 | 개인 활동으로만 쌓이고 크루 전체 기록에 합산된다. 조(소그룹) 없음. 크루를 나가거나 추방돼도 개인 기록·크루 합산 모두 그대로 남는다(활동에 당시 소속 크루를 기록) |
| 위치 공유 | 방 없음. 활동 시작 때 공유 여부만 선택. 켜면 활동 여부와 무관하게 크루원 모두가 지도에서 실시간 위치를 보고, 끝난 뒤에도 경로가 기록 상세에서 크루원에게 보인다. 꺼도 본인 기록에는 경로가 남고 크루원에게만 안 보인다 |
| 채팅 | 크루마다 단체 채팅방 하나. 크루가 있는 동안 계속 이어지며 모이깅 탭과 줍깅 화면 어디서든 같은 방을 연다. 1:1 없음. 폴링 → 소켓 |
| 백그라운드 | 활동 시작~종료 사이에만 배경 추적. 경로 기록·거리·시간·크루원 위치 전송·알림창 현황(거리·시간·개수)이 화면을 꺼도 유지된다. 포그라운드 서비스 알림으로. 종료하면 즉시 끔. 활동 밖에서는 위치를 올리지 않는다 |
| 위치 품질 | 1차에 필터 4개: 오차 반경 30m 초과 점 버림 · 초속 5m 초과 이동 버림 · 최근 3~5점 평균으로 평활화 · Health Connect/HealthKit 걸음수 거리(걸음 × 0.7m)와 대조해 GPS 거리가 그보다 30% 넘게 크면 걸음수 거리를 쓴다. 인도 위로 선을 붙이는 경로 맞춤(map matching)은 이후 |
| 로고·캐릭터 | 기존 캐릭터를 로고·앱 아이콘·홈 게이미피케이션·빈 상태 화면에 공통으로 쓴다. 필요한 에셋: 홈 단계 5장 · 앱 아이콘(Android adaptive 전경/배경) · 스플래시 1장 · 빈 상태 3장(활동 없음·게시물 없음·알림 없음). `design-system/assets/character/` 에 둔다 |
| DB | Supabase 의 Postgres(PostGIS) 만 쓴다. Spring 이 JDBC 로 접속. Supabase Auth·Storage·Realtime 은 안 쓴다. EC2 Postgres 컨테이너 제거. 리전은 서울로 맞춤 |
| 음성 입력 | 이후. 인터뷰의 음성 요구는 기존 앱의 수동 입력이 불편해서 나온 것이라, 사진 분류와 줍기 UI 가 그 자리를 채운다. 실제 사용에서 여전히 불편하면 다시 검토 |
| 소속 | 한 사람은 크루 하나에만 소속된다. 동네(hood) 개념은 끔 — 온보딩·홈·백엔드에서 제거 |
| 회원 탈퇴 | 크루 합산 숫자는 유지. 게시물·댓글은 "탈퇴한 크루원" 이름으로 보존. 개인 활동 상세(경로 포함)는 삭제. 크루 나가기·추방과 다르다 — 그 경우 계정이 살아 있어 기록이 이름 붙은 채 남는다 |
| 크루장 | 한 명. 만든 사람이 크루장이며 다른 크루원에게 위임할 수 있다. 위임 없이는 탈퇴할 수 없다. 운영진 층 없음 |
| 기존 데이터 | 이관하지 않는다. 새 스키마로 빈 DB 에서 시작. Flyway 도 V1 부터 다시 쓴다 |
| 인프라 | EC2 에 남는 컨테이너 4개: nginx · backend(blue/green) · acme · redis. 끔: postgres · livekit · admin-web · prometheus · grafana · alertmanager · node-exporter · cadvisor. 감시는 Supabase 대시보드 + 외부 헬스체크(`/healthz` 5분 주기)로 대신. AI 서버 위치는 담당자 영역 |
| 플랫폼 | 1차는 **Android 만**, React Native. iOS 는 이후(Apple 개발자 계정·Apple 로그인·HealthKit·Live Activity 가 함께 따라온다). 걸음수·운동 인식은 Health Connect(삼성헬스 데이터 포함) |
| 지도 | 카카오맵 Android SDK 를 RN 네이티브 모듈로 감싼다. 옛 앱의 지도 코드(경로 선·마커·카메라 추적)를 참고. iOS 를 넣을 때 지도 SDK 를 다시 정한다 |

## 화면별 유지 · 변경 · 신규 · 끔

### 온보딩
- 회원가입 → 크루 만들기 또는 크루 가입하기
- 끔: 동네 선택
- 크루 만들기: 이름만 입력. 초대 코드는 자동 생성. 소개·대표 사진·크루 목표는 모이깅 탭의 크루 정보 수정에서 크루장이 채운다. 목표 기본값은 서버가 정한 값으로 시작
- 가입: 초대 코드로 크루를 지정하고 크루장이 승인하면 크루원이 된다. 크루 검색·공개 목록 없음

### 홈
- 유지: 화면 구조(인사 · 상단 선택 · 알림 버튼 · 카드 3장 · 오프라인 카드)
- 변경: 동네 선택 → 크루 이름 표시
- 변경: "이번 주 우리 동네" 카드 → "최근 7일 우리 크루가 주운 쓰레기" (개수 + 7일 스파크라인 유지). 누르면 모이깅 탭의 크루 기록으로
- 변경: "지금 근처에서 함께 줍는 사람" 카드 → "지금 활동 중인 크루원" (수 + 얼굴, 누르면 목록)
- 변경: "이번 주 내가 주운 쓰레기" → "최근 7일 내가 주운 쓰레기"
- 변경: 가운데 지도 → 크루 캐릭터(기존 캐릭터 사용). 최근 14일 크루 줍기 개수를 크루장이 정한 목표와 비교해 5단계로 모습·표정이 바뀐다 — 목표 대비 비율 0~19% 축 처짐 · 20~49% 보통 · 50~79% 신남 · 80~99% 반짝 · 100% 이상 파티. 굴러가는 14일 창이라 절벽 리셋 없이 서서히 변한다. 누르면 "최근 14일 N개, 목표까지 M개". 내 것 보기·다시보기·전체화면 지도는 끔
- 끔: GPS 약함 배너(지도가 빠지므로)

### 피드
- 변경: 게시물은 자유 게시물 하나. 사진 여러 장 + 글. 활동 종료 화면의 "피드에 올리기" 는 요약 이미지를 첨부한 자유 게시물을 만드는 것
- 변경: 인스타 식 SNS. 탭 2개 = 전체(크루) / 나만 보기
- 변경: 검색 버튼 → 달력(날짜로 찾기)
- 유지: 좋아요·댓글

### 모이깅 탭 (크루)
- 신규: 크루 정보(이름·소개·대표 사진·초대 코드·크루원 목록). 크루장은 수정·목표 설정·가입 신청 승인·추방·위임을 여기서 한다
- 신규: 공지사항 — 크루장이 쓰는 글 목록. 최신 공지 하나가 모이깅 탭 상단에 고정. 댓글 가능
- 유지: 채팅 — 크루 단체방 하나 (소켓으로)
- 신규: 일자별·멤버별 활동 내역 달력
- 신규: 크루 기록 — 크루 합산 추이·크루원별 순위. 홈의 크루 지표를 누르면 여기로 온다
- 끔: 모임 만들기·찾기·가입·관리·초대 링크

### 소셜
- 변경: 친구 관계 → 크루원 관계. 친구 요청·수락·친구 목록·사용자 검색 화면은 끄고 크루원 목록이 대신한다
- 신규: 크루장이 크루원을 추방한다
- 변경: 게시물·사용자 신고 유지. 수신자가 운영자 → 크루장. 처리 화면은 "삭제" / "무시" 두 버튼. 삭제되면 작성자에게 알림
- 유지: 사용자 차단(개인 설정). 차단한 사람은 피드·채팅·활동 중인 크루원에서 안 보인다
- 변경: 백엔드의 친구 계열 테이블·컬럼·API 경로 이름을 크루원 관계 이름으로 바꾼다. 실제 이름은 진행 순서 3단계에서 정한다

### 알림
- 변경: 발생원 = 가입 신청(크루장) · 승인(신청자) · 공지 · 게시물 댓글 · 채팅 · 크루원 활동 시작 · 신고 접수(크루장) · 내 게시물이 크루장에 의해 삭제됨(작성자)
- 신규: 활동 시작 알림은 내가 팔로우한 크루원이 시작할 때만 온다
- 유지: 알림 목록 화면(홈 벨 아이콘). 누르면 해당 화면으로 이동, 읽음 처리
- 신규: 크루장에게 온 처리 대기 항목(가입 신청·신고)은 목록 위에 따로 묶어 보여 준다
- 끔: 친구 요청·모임 초대 알림

### 줍깅(활동)
- 변경: 시작할 때 위치 공유 여부만 묻고 바로 시작. 활동 유형·메모 없음
- 유지: 종료 → 요약 화면(거리·시간·줍기 목록·경로 지도) → 피드에 올리기 선택
- 변경: 멤버 → 활동 중인 크루원. 누르면 목록
- 변경: 그룹 버튼 → 채팅 버튼
- 신규: 일시정지 — 거리·시간 누적만 멈춘다. 위치 공유는 계속되고(크루원 지도에 "일시정지 중" 배지) 줍기 기록도 가능
- 신규: 내 위치로 돌아가기
- 끔: 함께줍깅, 음소거
- 신규: 걸음수·운동 인식으로 거리·시간 보정 — Health Connect(삼성헬스 포함)

### 프로필·기록
- 유지: 내 프로필·프로필 수정·활동 기록 상세
- 설정 유지: 프로필 편집 · 비밀번호 재설정 · 차단 관리 · 로그아웃 · 회원 탈퇴
- 설정 신규: 크루 나가기(크루장은 위임 뒤에만) · 활동 시작 알림 켬/끔(팔로우와 별개의 전체 스위치) · 위치 공유 기본값(활동 시작 때 미리 선택된 값)
- 설정 끔: 우리 동네 변경 · 지도에 내 활동 표시
- 변경: 타인 프로필 = 기본 정보 + 탭 2개(기록: 누적 거리·개수·활동 달력·활동 상세 / 게시물: 그 사람이 크루 전체에 올린 것)
- 끔: 모임별 기록

### AI 줍기
- 유지: 카테고리 7종(담배꽁초·캔·플라스틱·종이·유리·비닐·일반). 2줄(4+3) 정렬
- 신규: 사진 없이 카테고리 버튼만 눌러도 줍기가 기록된다(빠른 수동 입력). AI 는 사진을 찍었을 때만
