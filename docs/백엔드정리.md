# 백엔드 정리 지도

옛 `backend` 를 복사한 뒤 진행 순서 3단계에서 도메인별로 무엇을 하는지. 코드는 지우지 않고 **끄는** 것이 원칙이지만, 컴파일 대상에서 빼야 하는 것(끔)과 이름을 바꾸는 것(개명)은 구분한다.
"끔" 은 패키지를 `legacy/` 로 옮기고 소스 세트에서 제외한다. 스키마는 V1 부터 새로 쓰므로(ADR-0002) 옛 마이그레이션 13개는 전부 폐기한다.

| 옛 도메인 | 처리 | 내용 |
|---|---|---|
| `auth` | 유지 | 소셜 검증·토큰 회전·재설정 메일 그대로. Apple 은 ADR-0003 이 바뀔 때 |
| `user` | 유지 + 수정 | `hood_code`·`map_visible`·`role` 제거. `share_location_default`·`notify_activity_start` 추가. 탈퇴 정책(ERD "회원 탈퇴 때") |
| `friend` | 개명 → `follow` | 요청·수락 흐름 제거. 한 방향 `follows` 만. 사용자 검색 끔 |
| `meet` | 끔 | 모임·초대 링크·가입 요청·멤버 전부. 초대 코드 검증 로직만 `crew` 로 옮겨 쓴다 |
| `neighborhood` | 끔 | 동네·수거 지점(`pickup_points`) |
| `chat` | 개명 (meet → crew) | 방 키가 `meet_id` → `crew_id`. 폴링 엔드포인트 제거, STOMP 브로커 추가(`소켓.md`). Redis pub/sub 로 blue/green 두 인스턴스 사이를 잇는다 |
| `live` | 유지 + 확장 | 활동 중 위치. `live_locations` 갱신·`/crew/live`·소켓 `LIVE_*` 발행. 크루 범위로 조회 |
| `activity` | 유지 + 확장 | 시작/일시정지/재개/종료 상태 추가(옛 것은 종료 때 일괄 전송만). `quantity`·사진 없는 줍기·`steps`·`crew_id`. 종료 때 `crew_daily_stats` 적립 |
| `media` | 유지 | `purpose` 추가(ACTIVITY 만 AI 추론). 주소 역지오코딩 제거 |
| `post` | 유지 + 수정 | `visibility` CREW/PRIVATE, `crew_id`, `record_*` 제거, `post_thanks` → `post_likes`, 크루장 삭제(`deleted_by`) |
| `notification` | 유지 + 수정 | type 9종으로 교체. 팔로우 기반 `ACTIVITY_STARTED` 발행. 크루장 처리 대기 집계 |
| `safety` | 유지 + 수정 | `reports` 에 `crew_id`, 수신자 크루장, 결과 DELETE/DISMISS. `blocks` 그대로 |
| `admin` | 끔 | 관리자 API 전부. Export 는 `stats` 에서 크루 단위로 새로 |
| (신규) `crew` | 신규 | 크루·크루원·가입 신청·초대 코드·위임·추방·크루 나가기·0명 자동 삭제 |
| (신규) `notice` | 신규 | 공지·공지 댓글·고정 |
| (신규) `stats` | 신규 | `/crew/home`·`/crew/stats`·`/crew/calendar`·`/crew/export`. 원본은 `crew_daily_stats` + `activities` |

## 횡단 규칙

- `/crew/...` 는 호출자의 소속 크루를 `crew_members` 에서 찾아 주입한다. 없으면 403 `NO_CREW`. 크루장 전용은 `crews.leader_id` 대조 → 403 `FORBIDDEN`
- 차단 필터는 옛 방식 그대로 서버가 목록·상세에서 걸러낸다. 소켓 발행에도 같은 필터
- 계약 테스트(`OpenApiContractTest`)는 `docs/openapi.yaml` 을 읽어 경로·메서드를 컨트롤러와 대조한다. 옛 것을 이식하고 경로만 바꾼다
- `global/` (필터·예외 처리·응답 봉투·커서·멱등)은 그대로 산다
