# 백엔드 정리 지도

옛 백엔드에서 가져온 것은 세 영역이고 나머지는 `ERD.md`·`openapi.yaml` 에서 새로 쓴다(ADR-0004).
순서는 **ERD → Flyway V1 → Entity**. Entity 가 기준이 되는 일은 없다.

## 가져온 것 (이관 커밋)

| 영역 | 내용 | 손볼 것 |
|---|---|---|
| `global/` | JWT 발급·검증·필터, `@CurrentUser`, 응답 봉투·오류 형식·요청 ID, 커서 페이지 | `/crew/...` 소속 크루 주입(`NO_CREW` 403)과 크루장 대조(`FORBIDDEN`)를 여기에 새로 넣는다 |
| `domain/auth` | 카카오·구글 토큰 검증, refresh 회전(가족 폐기·재사용 감지·만료 정리), 비밀번호 재설정 메일 | `user` 를 새로 쓴 뒤 아래 5곳을 잇는다 |
| `domain/media` | 업로드, 서명 URL, AI 호출(타임아웃·`UNAVAILABLE` 폴백) | `purpose` 추가, 주소 역지오코딩 제거, `Category` 를 새로 쓴 뒤 아래 2곳을 잇는다 |

### 이관 직후 끊긴 참조 7곳 — 3단계 첫 작업

| 파일 | 참조 |
|---|---|
| `auth/application/command/AuthCommandService` | `user.domain.service.UserService` |
| `auth/domain/service/AuthService` | `user.domain.service.UserService`, `user.dto.UserAccount` |
| `auth/domain/service/PasswordResetService` | `user.domain.service.UserService` |
| `auth/dto/AuthDtos` | `user.dto.MeResponse` |
| `media/dto/MediaDtos` | `activity.domain.entity.Category` |
| `media/infrastructure/client/AiInferenceClient` | `activity.domain.entity.Category` |

## 새로 쓰는 것

| 도메인 | 내용 | 옛 것에서 달라지는 점(체크리스트) |
|---|---|---|
| `user` | 계정·프로필·설정·탈퇴 | `hood_code`·`map_visible`·`role` 없음. `share_location_default`·`notify_activity_start`. 탈퇴 정책은 ERD "회원 탈퇴 때" |
| `crew` | 크루·크루원·가입 신청·초대 코드·위임·추방·나가기·0명 자동 삭제 | 신규 |
| `activity` | 시작/일시정지/재개/종료 상태, 줍기(`quantity`, 사진 없는 줍기), 사진, 종료 때 `crew_daily_stats` 적립 | 옛 것은 종료 때 일괄 전송만. `crew_id`·`steps` |
| `live` | 활동 중 위치(`live_locations`), `/crew/live`, 소켓 `LIVE_*` | 크루 범위 |
| `post` | 게시물·사진·좋아요·댓글 | `visibility` CREW/PRIVATE, `crew_id`, `post_likes`, 크루장 삭제(`deleted_by`) |
| `notice` | 공지·공지 댓글·고정 | 신규 |
| `chat` | 크루 채팅 이력 + STOMP 브로커 + Redis pub/sub | 방 키 `crew_id`, 폴링 없음(`소켓.md`) |
| `notification` | 알림 9종, 팔로우 기반 활동 시작 발송, 크루장 처리 대기 집계 | 종류 전부 교체 |
| `safety` | 차단·신고(크루장 처리) | `reports.crew_id`, 결과 DELETE/DISMISS |
| `stats` | `/crew/home`·`/crew/stats`·`/crew/calendar`·`/crew/export`(CSV) | 신규. 원본은 `crew_daily_stats` + `activities` |

## 횡단 규칙

- `/crew/...` 는 호출자의 소속 크루를 `crew_members` 에서 찾아 주입한다. 없으면 403 `NO_CREW`. 크루장 전용은 `crews.leader_id` 대조 → 403 `FORBIDDEN`
- 차단 필터는 서버가 목록·상세·소켓 발행에서 걸러낸다
- 계약 테스트(`OpenApiContractTest`)는 `../docs/openapi.yaml` 을 읽어 경로·메서드를 컨트롤러와 대조한다. 가져왔고 경로만 새 계약을 가리킨다
- 멱등("같은 UUID 재전송이면 200")은 별도 모듈이 아니라 각 저장 로직의 패턴이다. `backend/docs/02-컨벤션.md` §8
