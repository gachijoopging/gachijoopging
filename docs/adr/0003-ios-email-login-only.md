# iOS 는 이메일 로그인만 제공한다

App Store 심사 규정 4.8 은 카카오·구글 같은 제3자 로그인을 넣은 앱에 Sign in with Apple 도 함께 요구한다.
Apple 로그인을 붙이려면 Apple 개발자 계정과 서버 검증 경로가 하나 더 필요하다. 지금은 iOS 배포 자체가 미결이라
iOS 에서는 소셜 버튼을 숨기고 이메일+비밀번호만 보인다. Android 는 카카오·구글을 유지한다.
같은 사람이 두 기기를 쓰면 이메일 계정에 소셜을 연결하는 기존 흐름(`PUT /users/me/social`)으로 하나의 계정을 쓴다.

2026-09-07 iOS 가 1차 범위에서 빠졌다(Q40). 이 결정은 iOS 를 넣을 때 다시 살린다. 그때까지 앱은 Android 만이라 소셜 로그인에 제약이 없다.
