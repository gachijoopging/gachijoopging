# 백엔드 구조 — 도메인 지도

> 서버 코드가 **어디에 무엇이 있는지**의 정본이다. HTTP 계약은 `docs/openapi.yaml`, 실시간은
> `docs/realtime.md`, 테이블은 `docs/ERD.md`, 코딩 규약은 `02-conventions.md`.
> 새 경로·새 테이블이 생기면 §3 표에 먼저 적는다.

## 1. 배경

옛 백엔드에서 `global`·`auth`·`media` 만 가져오고 나머지 도메인은 ERD·계약에서 새로 쓴다
(`docs/adr/0004-backend-data-domains-rewritten.md`). 스키마는 V1 부터 다시 썼다(ADR-0002).

## 2. 빌드와 저장소

| 항목 | 값 |
|---|---|
| 언어·빌드 | Java 21 · Gradle Wrapper 8.10 · Spring Boot 3.5.4 · 의존성은 `gradle.lockfile` 로 잠금 |
| 웹 | Spring MVC, 경로 접두사 `/api/v1`. JWT(RS256) 인증은 `global/security` |
| 영속 | Spring Data JPA(Hibernate) · QueryDSL · native `@Query` · `JdbcClient` — 쓰임새는 `AGENTS.md` §backend |
| 스키마 | Flyway 가 만든다. JPA 는 `ddl-auto: validate` 로 대조만 한다 |
| 실시간 | STOMP over WebSocket (`docs/realtime.md`). 아직 구현 전 |

| 저장소 | 무엇을 맡나 |
|---|---|
| Postgres 16 + PostGIS (Supabase, ADR-0001) | 서버 상태 전부. 경로·위치는 PostGIS(`hibernate-spatial`) |
| Redis 7 | 지금은 rate limit(`global/ratelimit`) 하나. STOMP 브로커 릴레이·채팅 pub/sub 이 들어올 예정이다. 활동 중 위치(`live_locations`)는 테이블이고, 부하가 보이면 Redis 로 옮긴다(ERD) |
| 파일 | 미디어 원본·썸네일. `media/client/MediaStorage` 가 `app.media.root` 아래에 쓰고 서명 URL 로 내준다 |

Redis 를 저장소로 쓰는 어댑터는 그 도메인의 `repository/` 에 둔다(`02-conventions.md` §3).

## 3. 도메인과 경로

도메인은 12개다(`ArchitectureTest` 가 이 목록 밖의 도메인을 막는다). 소유 테이블은 V1 의
26개 전부, 경로는 계약의 64개 경로·81개 오퍼레이션 전부다.

⭐ = openapi 태그와 담당 도메인이 다른 경로. 데이터를 가진 쪽이 담당한다.

| 도메인 | 소유 테이블 | 수 | 담당 경로 |
|---|---|---|---|
| auth | refresh_tokens · password_reset_tokens | 9 | `POST /auth/signup` · `POST /auth/login` · `POST /auth/kakao` · `POST /auth/google` · `POST /auth/refresh` · `POST /auth/logout` · `POST /auth/password-reset` · `POST /auth/password-reset/confirm` · ⭐`PUT /users/me/social` |
| user | users · user_agreements · devices | 7 | `GET /users/me` · `PATCH /users/me` · `DELETE /users/me` · ⭐`GET /agreements` · `GET /users/me/agreements` · `PUT /users/me/agreements` · `PUT /users/me/devices` |
| crew | crews · crew_members · crew_join_requests | 15 | `POST /crews` · `GET /crews/preview` · `POST /crews/join-requests` · `GET /crews/join-requests/mine` · `DELETE /crews/join-requests/mine` · `GET /crew` · `PATCH /crew` · `POST /crew/invite-code` · `POST /crew/leave` · `GET /crew/members` · `GET /crew/members/{userId}` · `DELETE /crew/members/{userId}` · `PUT /crew/leader` · `GET /crew/join-requests` · `POST /crew/join-requests/{requestId}` |
| activity | activities · activity_photos · activity_items | 11 | `POST /activities` · `GET /activities/current` · `POST /activities/{id}/pause` · `POST /activities/{id}/resume` · `POST /activities/{id}/items` · `PATCH /activities/{id}/items/{itemId}` · `DELETE /activities/{id}/items/{itemId}` · `POST /activities/{id}/end` · `GET /activities/{id}` · `DELETE /activities/{id}` · `GET /users/me/activities` |
| live | live_locations | 2 | ⭐`POST /activities/{id}/live` · ⭐`GET /crew/live` |
| post | posts · post_media · post_likes · comments | 10 | `GET /crew/posts` · `POST /crew/posts` · `GET /posts/{postId}` · `DELETE /posts/{postId}` · `PUT /posts/{postId}/like` · `DELETE /posts/{postId}/like` · `GET /posts/{postId}/comments` · `POST /posts/{postId}/comments` · `DELETE /comments/{commentId}` · ⭐`GET /crew/members/{userId}/posts` |
| notice | notices · notice_comments | 7 | `GET /crew/notices` · `POST /crew/notices` · `GET /notices/{noticeId}` · `PATCH /notices/{noticeId}` · `DELETE /notices/{noticeId}` · `POST /notices/{noticeId}/comments` · `DELETE /notice-comments/{commentId}` |
| chat | chat_messages · chat_reads | 2 | `GET /crew/chat/messages` · `PUT /crew/chat/read` — 보내기는 STOMP `/app/crew/chat` |
| notification | notifications · follows | 5 | `GET /notifications` · `POST /notifications/read` · `GET /notifications/unread-count` · ⭐`PUT /users/{userId}/follow` · ⭐`DELETE /users/{userId}/follow` |
| safety | blocks · reports | 6 | ⭐`GET /users/me/blocked` · ⭐`PUT /users/{userId}/block` · ⭐`DELETE /users/{userId}/block` · `POST /reports` · `GET /crew/reports` · `POST /crew/reports/{reportId}` |
| stats | crew_daily_stats | 6 | `GET /crew/home` · `GET /crew/stats` · `GET /crew/calendar` · `GET /crew/export` · `GET /users/me/stats` · ⭐`GET /crew/members/{userId}/activities` |
| media | media | 1 | `POST /media` |

검산: 테이블 2+3+3+3+1+4+2+2+2+2+1+1 = **26** = V1 테이블 수. 경로 9+7+15+11+2+10+7+2+5+6+6+1 = **81** = openapi 오퍼레이션 수(경로 64개).

배정 근거:
- `PUT /users/me/social` 이 auth 인 것 — 소셜 토큰 검증이 auth 의 client 에 있다. 이미 그렇게 구현돼 있다
- `GET /agreements` 가 user 인 것 — 태그는 auth 지만 데이터(`user_agreements`)와 버전 설정이 user 에 있다
- follows 가 notification 인 것 — 팔로우는 "크루원 활동 시작" 알림을 받을 대상을 정하는 데만 쓴다(`docs/feature-scope.md` 알림). **확정 필요**
- crew_daily_stats 가 stats 인 것 — 읽는 쪽(홈·통계·달력)이 stats 다. 쓰는 쪽은 activity 종료라 §4 의 결정이 필요하다

## 4. 도메인 간 호출 관계

경계 규칙(남의 repository·client·entity 를 쓰지 않는다)은 `02-conventions.md` §12 R2 다. 남의
데이터를 **읽는** 것은 조회 JOIN 으로 끝나므로 의존이 아니다. 서비스 주입이 필요한 것은 **남의
테이블에 쓰는 것**과 **DB 로 못 하는 일을 위임하는 것** 둘뿐이다.

**지금 코드에 있는 것**

| 호출 | 이유 |
|---|---|
| auth → user (`UserService`) | 가입·로그인·소셜 연결이 users 를 만들고 고친다 |
| media → activity (`Category` enum) | AI 결과를 카테고리 7종으로 돌려준다. enum 공유라 R2 위반이 아니다 |

**계약·ERD 가 요구하지만 방식이 정해지지 않은 것** — 도메인을 세울 때 정하고 이 표를 고친다

| 쓰는 쪽 → 쓰이는 데이터 | 언제 | 정할 것 |
|---|---|---|
| activity → crew_daily_stats | 활동 종료 때 크루별·일별 합산 적립(같은 트랜잭션) | stats 서비스 주입인가, 테이블 소유를 activity 로 옮기나 |
| activity → crew_members | 시작 시점의 소속 크루를 `crew_id` 로 고정 | 조회 JOIN 으로 충분한지 |
| safety → crew_members · posts | 신고 처리에서 추방·게시물 삭제 | crew·post 서비스 주입 |
| user → crew · activity · stats | 회원 탈퇴 때 소속 정리·활동 삭제·합산 보존(ERD "회원 탈퇴 때") | 탈퇴 흐름을 어디서 조립하나 |
| 여러 도메인 → notifications | 가입 신청·승인·공지·댓글·채팅·활동 시작·신고 접수·처리 결과·게시물 삭제 | 서비스 직접 호출인가, `event/` 의 커밋 후 리스너인가 |
| post·notice·chat → blocks | 차단한 상대 숨김 | 조회 JOIN(`query/` 의 조건식) 으로 할 것 |

서비스 주입이 순환하면 기동이 실패한다 — ArchUnit 이 아니라 그쪽이 잡는다(`02-conventions.md` §12).

## 5. 횡단 관심사 — 어디에 무엇이 있나

| 무엇 | 어디 |
|---|---|
| JWT 발급·검증·필터, `@CurrentUser` | `global/security` |
| `/crew/...` 호출자의 소속 크루 주입 — 없으면 403 `NO_CREW` | `global/` 에 새로 넣는다. 크루 id 를 경로에 넣지 않는다 |
| 크루장 전용 — `crews.leader_id` 대조, 아니면 403 `FORBIDDEN` | 위와 같은 자리. 운영진 층은 없다 |
| 차단 필터 — 목록·상세·소켓 발행에서 서버가 걸러낸다 | 각 도메인의 조회 쿼리. 조건식은 safety 의 `query/` |
| 응답 봉투 `ApiResponse` · 커서 `CursorPage`·`Cursors` | `global/response` |
| 오류 `BusinessException`·`ErrorCode` · `GlobalExceptionHandler` | `global/error` |
| 요청 ID(MDC) · 헬스체크 `/health` | `global/web` |
| rate limit (Redis) | `global/ratelimit` |
| 지표 이름 | `global/metrics` |
| `Clock` · 스케줄러 · QueryDSL · OpenAPI 설정 | `global/config` |
| 멱등("같은 UUID 재전송은 200") | 별도 모듈이 아니라 각 저장 로직의 패턴 — `02-conventions.md` §8 |

## 6. 외부 연동

client 는 그것을 쓰는 도메인의 `client/` 에 있고, `facade/` 와 `event/` 리스너만 부른다.

| 외부 | 클라이언트 | 도메인 |
|---|---|---|
| 카카오 로그인 | `KakaoAuthClient` | auth |
| 구글 로그인 | `GoogleAuthClient` (JWKS) | auth |
| 비밀번호 재설정 메일 (SMTP) | `SmtpPasswordResetMailSender` (`prod` 프로필) — 그 밖에는 `LoggingPasswordResetMailSender` 가 로그로만 남긴다 | auth |
| AI 추론 서버 (`ai/`, FastAPI) | `AiInferenceClient` — 실패는 `UNAVAILABLE` 폴백 | media |
| 파일 저장·썸네일 | `MediaStorage` · `Thumbnailer` | media |
| FCM 푸시 | 아직 없다 | notification 예정 |

## 7. 확정된 구조 결정

| 결정 | 이유 |
|---|---|
| 모놀리스 하나, 도메인은 `domain/<도메인>/` 패키지 | 팀·기간이 작다 |
| 도메인 안은 역할 이름(controller·facade·service·repository…)으로 평평하게 | 처음 보는 사람이 바로 읽는다. 의존 방향은 ArchUnit 이 지킨다. 되돌리기 쉬워 ADR 은 쓰지 않았다 |
| 외부 호출은 트랜잭션 밖 — `facade/` 와 커밋 후 `event/` 리스너만 client 를 부른다 | 트랜잭션 안에서 기다리면 커넥션을 물고, 실패해도 롤백할 수 없다 |
| 도메인 간에는 식별자로만 잇는다. JPA 연관은 같은 도메인 안에서만 | 도메인을 따로 고칠 수 있게 |
| 한 사람은 크루 하나. 크루장은 `crews.leader_id` 로만 | `docs/feature-scope.md` |
| 계정 정지·관리자 웹은 없다 | `docs/feature-scope.md` — 제재는 크루장의 신고 처리·추방 |
