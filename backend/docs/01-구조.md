# 백엔드 구조 설계서

> 서버 코드가 **어디에 무엇이 있고 어느 방향으로 의존하는지**의 정본이다. HTTP 계약은
> `docs/openapi.yaml`, 실시간은 `docs/realtime.md`, 테이블은 `docs/ERD.md`. 각 자리에서 코드를
> 어떻게 짜는지(트랜잭션·멱등·네이밍)는 `02-conventions.md`.
> 새 경로·새 테이블이 생기면 §4 표에 먼저 적는다.

## 1. 배경

옛 백엔드에서 `global`·`auth`·`media` 만 가져오고 나머지 도메인은 ERD·계약에서 새로 쓴다
(`docs/adr/0004-backend-data-domains-rewritten.md`). 스키마는 V1 부터 다시 썼다(ADR-0002).

## 2. 빌드 구조

Gradle 단일 모듈이다(`backend/`, `rootProject.name = 'gachijoopging-server'`). 실행 산출물은
`bootJar` 하나이고 일반 `jar` 는 끈다. 이미지는 `backend/Dockerfile` 이 `bootJar` 로 만든다.

```
backend/
├─ build.gradle · settings.gradle · gradle.lockfile · gradlew
├─ Dockerfile
├─ docs/                     01-구조 · 02-conventions
└─ src/
   ├─ main/java/site/gachijoopging/server/
   │  ├─ GachijoopgingApplication.java
   │  ├─ global/             도메인에 안 속한 공통 (§3)
   │  └─ domain/<도메인>/     도메인 12개 (§3·§4)
   ├─ main/resources/
   │  ├─ application.yml     프로필 local · prod
   │  └─ db/migration/       Flyway V{번호}__{설명}.sql
   ├─ test/java/site/gachijoopging/server/
   │  ├─ architecture/       ArchitectureTest + fixture (§5)
   │  ├─ contract/           OpenApiContractTest · 지표 이름 계약
   │  ├─ domain/<도메인>/     도메인별 단위·API 테스트
   │  ├─ global/
   │  └─ support/            IntegrationTest(Testcontainers) · TestAccounts
   └─ test/resources/archunit.properties
```

**태스크**

| 태스크 | 하는 일 |
|---|---|
| `compileJava` | 컴파일. QueryDSL Q클래스도 이때 생긴다(annotation processor) |
| `test` | 단위 테스트. `@Tag("docker")` 는 제외 |
| `dockerTest` | `@Tag("docker")` 통합 테스트. Testcontainers 로 PostGIS·Redis 를 띄운다 — Docker 필요 |
| `jacocoTestReport` | `test`·`dockerTest` 의 exec 를 합쳐 커버리지를 낸다 |
| `spotlessCheck` · `spotlessApply` | googleJavaFormat 검사·적용 |
| `build` | 컴파일 + `test` + jacoco. **`dockerTest` 는 돌지 않는다** |
| `bootJar` | 실행 jar |

의존성은 `gradle.lockfile` 로 잠근다. 바꾸면 `./gradlew dependencies --write-locks` 를 돌려
lockfile 을 같은 커밋에 넣는다(`02-conventions.md` §14).

**기술 스택**

| 항목 | 값 |
|---|---|
| 언어·빌드 | Java 21 · Gradle Wrapper 8.10 · Spring Boot 3.5.4 |
| 웹 | Spring MVC, 경로 접두사 `/api/v1`. JWT(RS256) 인증은 `global/security` |
| 영속 | Spring Data JPA(Hibernate) · QueryDSL · native `@Query` · `JdbcClient` — 쓰임새는 `AGENTS.md` §backend |
| 스키마 | Flyway 가 만든다. JPA 는 `ddl-auto: validate` 로 대조만 한다 |
| 실시간 | STOMP over WebSocket (`docs/realtime.md`). 아직 구현 전 |

**저장소**

| 저장소 | 무엇을 맡나 |
|---|---|
| Postgres 16 + PostGIS (Supabase, ADR-0001) | 서버 상태 전부. 경로·위치는 PostGIS(`hibernate-spatial`) |
| Redis 7 | 지금은 rate limit(`global/ratelimit`) 하나. STOMP 브로커 릴레이·채팅 pub/sub 이 들어올 예정이다. 활동 중 위치(`live_locations`)는 테이블이고, 부하가 보이면 Redis 로 옮긴다(ERD) |
| 파일 | 미디어 원본·썸네일. `media/client/MediaStorage` 가 `app.media.root` 아래에 쓰고 서명 URL 로 내준다 |

## 3. 패키지 구조

```
site.gachijoopging.server
├─ global/
│  ├─ config/        Clock · 스케줄러 · QueryDSL · OpenAPI · 웹 경로 접두사
│  ├─ error/         BusinessException · ErrorCode · GlobalExceptionHandler
│  ├─ metrics/       지표 이름
│  ├─ ratelimit/     Redis rate limit
│  ├─ response/      ApiResponse · CursorPage · Cursors
│  ├─ security/      JWT 필터·발급·검증(jwt/) · @CurrentUser · @CurrentCrew
│  └─ web/           요청 ID · /health
├─ seed/             데모 시드 러너 (DEMO_SEED_ENABLED 일 때만)
└─ domain/<도메인>/
   ├─ controller/    @RestController — 경로·바인딩·검증까지만
   ├─ facade/        (필요한 도메인만) 외부 호출·여러 서비스 조립. @Transactional 없음
   ├─ service/       트랜잭션 경계·비즈니스 규칙·권한. 정책·계산기·XxxCleanupJob 도 여기
   ├─ repository/    Spring Data JPA · QueryDSL · JdbcClient. Redis 같은 저장소 어댑터도 여기
   ├─ entity/        JPA 엔티티. 도메인 밖으로 나가지 않는다
   ├─ dto/           record — 요청·응답·도메인 간 전달
   ├─ event/         (필요한 도메인만) 도메인 이벤트와 AFTER_COMMIT 리스너
   ├─ client/        (필요한 도메인만) 이 도메인 전용 외부 클라이언트
   └─ query/         (필요한 도메인만) 타 도메인이 재사용하는 QueryDSL 조건식
```

- `global` 은 `domain` 을 모른다(§5 R3). 둘 다 쓰는 것은 `global` 에 둔다
- `seed` 는 도메인 밖에서 여러 도메인 테이블에 직접 쓰는 유일한 예외다. 활동·피드·채팅 도메인보다 먼저 데모 데이터가 필요해서다. ArchUnit 이 보지 않으니, 그 도메인이 생기면 불변식(채팅 seq·종료 시 통계 적립)이 시드와 맞는지 확인한다
- 빈 하위 패키지는 만들지 않는다
- 각 자리가 하는 일과 하지 않는 일은 `02-conventions.md` §3

## 4. 도메인과 경로

도메인은 12개다(`ArchitectureTest` 가 이 목록 밖의 도메인을 막는다). 소유 테이블은 V1 의
26개와 이후 추가하는 `crew_expulsions` 전부, 경로는 계약의 63개 경로·81개 오퍼레이션 전부다.

⭐ = openapi 태그와 담당 도메인이 다른 경로. 데이터를 가진 쪽이 담당한다.

| 도메인 | 소유 테이블 | 수 | 담당 경로 |
|---|---|---|---|

| user | users · user_agreements · devices · follows | 9 | `GET /users/me` · `PATCH /users/me` · `DELETE /users/me` · ⭐`GET /agreements` · `GET /users/me/agreements` · `PUT /users/me/agreements` · `PUT /users/me/devices` · `PUT /users/{userId}/follow` · `DELETE /users/{userId}/follow` |

도메인이 하는 일:
- **auth** — 이메일·카카오·구글 로그인, refresh 회전(가족 폐기·재사용 감지·만료 정리), 비밀번호 재설정 메일, 이메일 계정에 소셜 연결
- **user** — 계정·프로필·설정, 약관 동의, 기기 토큰, 팔로우, 탈퇴
- **crew** — 크루·크루 검색·공개 크루 가입·비공개 크루 가입 신청·거절 안내 확인, 정원 50명, 공개 전환 자동 가입, 위임·추방(이력)·나가기, 0명이면 자동 삭제
- **activity** — 시작·일시정지·재개·종료 상태, 줍기(`quantity`, 사진 없는 줍기), 활동 사진
- **live** — 활동 중 위치와 크루원 위치 조회, 소켓 `LIVE_*`
- **post** — 게시물(`visibility` CREW·PRIVATE)·사진·좋아요·댓글, 크루장 삭제(`deleted_by`)
- **notice** — 공지·공지 댓글, 최신 공지 노출
- **chat** — 크루 채팅 이력·읽음 위치, STOMP 로 보내기
- **notification** — 알림 9종(`feature-scope.md` §알림), 크루장 처리 대기 집계, FCM 발송
- **safety** — 차단, 신고와 크루장의 신고 처리(삭제·기각)
- **stats** — 크루 홈·통계·달력·CSV 내보내기·내 통계. 원본은 `crew_daily_stats` 와 `activities`
- **media** — 업로드, 서명 URL, AI 추론(`UNAVAILABLE` 폴백)

배정 근거:
- `PUT /users/me/social` 이 auth 인 것 — 소셜 토큰 검증이 auth 의 client 에 있다. 이미 그렇게 구현돼 있다
- `GET /agreements` 가 user 인 것 — 태그는 auth 지만 데이터(`user_agreements`)와 버전 설정이 user 에 있다
- follows 가 user 인 것 — 사람 사이의 관계라 user 가 갖는다. "크루원 활동 시작" 알림을 보낼 때 notification 은 팔로워를 조회 JOIN 으로 읽기만 한다
- crew_daily_stats 가 stats 인 것 — 읽는 쪽(홈·통계·달력)과 탈퇴 때 보존하는 쪽이 stats 다. 활동 종료의 적립은 activity 가 stats 서비스에 맡긴다(아래)

### 도메인 간 호출 관계

경계 규칙(남의 repository·client·entity 를 쓰지 않는다)은 §5 R2 다. 남의
데이터를 **읽는** 것은 조회 JOIN 으로 끝나므로 의존이 아니다. 서비스 주입이 필요한 것은 **남의
테이블에 쓰는 것**과 **DB 로 못 하는 일을 위임하는 것** 둘뿐이다.

**지금 코드에 있는 것**

| 호출 | 이유 |
|---|---|
| auth → user (`UserService`) | 가입·로그인·소셜 연결이 users 를 만들고 고친다 |
| user · crew → media (`MediaService`·`MediaSignedUrl`) | 프로필·크루 사진의 소유 확인과 서명 URL |
| crew → global (`CrewMembershipLoader` 구현) | `/crew/...` 의 소속 크루 주입. global 은 인터페이스만 알고 crew 를 모른다(R3) |
| media → activity (`Category` enum) | AI 결과를 카테고리 7종으로 돌려준다. enum 공유라 R2 위반이 아니다 |
| auth → activity (`ActivityService`) | 진행 중 활동이 있으면 로그아웃을 막는다 |
| crew · activity → global (`UserLock`) | 사람 단위 불변식(소속·대기 신청·진행 중 활동)을 같은 advisory lock 키로 줄 세운다. 키 계산이 한 곳에만 있어야 어긋나지 않는다 |
| activity → crew_members (조회) | 시작 시점의 소속 크루를 `crew_id` 로 고정. 사용자 잠금 뒤 native 조회로 읽는다 — 나가기가 같은 잠금을 잡아 커밋까지 유효하다 |

**정해졌고 아직 코드가 없는 것**

| 호출 | 이유 |
|---|---|
| activity → stats (`StatsService`) | 활동 종료 때 크루별·일별 합산을 `crew_daily_stats` 에 적립한다. 종료와 같은 트랜잭션 |

**계약·ERD 가 요구하지만 방식이 정해지지 않은 것** — 도메인을 세울 때 정하고 이 표를 고친다

| 쓰는 쪽 → 쓰이는 데이터 | 언제 | 정할 것 |
|---|---|---|
| safety → crew_members · posts | 신고 처리에서 추방·게시물 삭제 | crew·post 서비스 주입 |
| user → crew · activity · stats | 회원 탈퇴 때 소속 정리·활동 삭제·합산 보존(ERD "회원 탈퇴 때") | 탈퇴 흐름을 어디서 조립하나 |
| 여러 도메인 → notifications | 가입 신청·공개 크루 가입·승인·공지·댓글·채팅·활동 시작·신고 접수·처리 결과·게시물 삭제 | 서비스 직접 호출인가, `event/` 의 커밋 후 리스너인가 |
| post·notice·chat → blocks | 차단한 상대 숨김 | 조회 JOIN(`query/` 의 조건식) 으로 할 것 |

서비스 주입이 순환하면 기동이 실패한다 — ArchUnit 이 아니라 그쪽이 잡는다(§5).

## 5. 참조 규칙

레이어(L)는 도메인 **안**의 의존 방향, 경계(R)는 도메인 **사이**와 `global` 이다.
전부 `ArchitectureTest` 가 강제한다. 테스트 코드와 주의점은 `02-conventions.md` §12.

| 규칙 | 내용 | 이유 |
|---|---|---|
| L0 | `repository` 가 있는 도메인은 `controller` 도 있다 | 패키지를 옮겨 규칙이 빈 매칭으로 통과하는 사고를 한 번 더 막는다 |
| L1 | `controller` 는 `repository` 를 직접 부르지 않고, 엔티티를 모른다(enum 예외) | 규칙과 트랜잭션은 서비스에, 응답은 dto 로 |
| L2 | `service`·`entity` 는 `controller`·`facade` 를 모른다 | 안쪽이 바깥을 알면 바깥을 바꿀 때 안쪽이 깨진다 |
| L2b | `facade` 는 엔티티를 모른다(enum 예외) | 서비스가 dto 를 돌려준다 |
| L3 | `client` 는 `facade` 와 `event` 만 부른다 | 외부 호출을 트랜잭션 밖에 둔다 |
| L3b | `entity` 는 `repository`·`client` 를 모른다 | 엔티티는 상태와 규칙만 갖는다 |
| L4 | `repository`·`client` 는 `controller` 를 모른다 | |
| R2 | 다른 도메인의 `repository`·`client`·`entity` 를 쓰지 않는다. Q클래스·enum 은 예외 | 남의 테이블에 쓰지 않는다. 읽기는 조회 JOIN 으로 |
| R3 | `global` 은 `domain` 을 모른다 | 공통이 특정 도메인에 묶이지 않게 |
| R4 | `facade` 는 `facade` 를 주입하지 않고 `@Transactional` 이 없다 | 조립이 조립을 부르면 흐름이 숨고, 트랜잭션을 열면 L3 이 무너진다 |
| — | 도메인은 12개 목록 안에만 | 도메인을 늘리려면 이 문서 §4 부터 고친다 |

## 6. 횡단 관심사 — 어디에 무엇이 있나

| 무엇 | 어디 |
|---|---|
| JWT 발급·검증·필터, `@CurrentUser` | `global/security` |
| `/crew/...` 호출자의 소속 크루 주입 — 없으면 403 `NO_CREW` | 컨트롤러 파라미터 `@CurrentCrew CrewMembership`(`global/security`). 조회는 crew 의 `CrewMembershipLoader` 구현. 크루 id 를 경로에 넣지 않는다 |
| 크루장 전용 — `crews.leader_id` 대조, 아니면 403 `FORBIDDEN` | `CrewMembership.requireLeader()`. 운영진 층은 없다 |
| 미가입자 전용(`GET·POST /crews`, `POST /crews/join-requests`) — 소속이면 409 `ALREADY_IN_CREW`, 승인 대기면 409 `JOIN_REQUEST_PENDING`(같은 크루 재신청은 200) | crew 의 서비스. 신청을 자동 취소하지 않는다 |
| 크루 정원 50명 — 넘으면 409 `CREW_FULL` | crew 의 서비스. 크루원을 넣는 모든 길(공개 가입·승인·공개 전환)이 그 크루 행을 `FOR UPDATE` 로 잠그고 센다(ERD "크루 정원") |
| 차단 필터 — 목록·상세·소켓 발행에서 서버가 걸러낸다 | 각 도메인의 조회 쿼리. 조건식은 safety 의 `query/` |
| 응답 봉투 `ApiResponse` · 커서 `CursorPage`·`Cursors` | `global/response` |
| 오류 `BusinessException`·`ErrorCode` · `GlobalExceptionHandler` | `global/error` |
| 요청 ID(MDC) · 헬스체크 `/health` | `global/web` |
| rate limit (Redis) | `global/ratelimit` |
| 지표 이름 | `global/metrics` |
| `Clock` · 스케줄러 · QueryDSL · OpenAPI 설정 | `global/config` |
| 멱등("같은 UUID 재전송은 200") | 별도 모듈이 아니라 각 저장 로직의 패턴 — `02-conventions.md` §8 |

## 7. 외부 연동

client 는 그것을 쓰는 도메인의 `client/` 에 있고, `facade/` 와 `event/` 리스너만 부른다.

| 외부 | 클라이언트 | 도메인 |
|---|---|---|
| 카카오 로그인 | `KakaoAuthClient` | auth |
| 구글 로그인 | `GoogleAuthClient` (JWKS) | auth |
| 비밀번호 재설정 메일 (SMTP) | `SmtpPasswordResetMailSender` (`prod` 프로필) — 그 밖에는 `LoggingPasswordResetMailSender` 가 로그로만 남긴다 | auth |
| AI 추론 서버 (`ai/`, FastAPI) | `AiInferenceClient` — 실패는 `UNAVAILABLE` 폴백 | media |
| 파일 저장·썸네일 | `MediaStorage` · `Thumbnailer` | media |
| FCM 푸시 | 아직 없다 | notification 예정 |

## 8. 확정된 구조 결정

| 결정 | 이유 |
|---|---|
| 모놀리스 하나, 도메인은 `domain/<도메인>/` 패키지 | 팀·기간이 작다 |
| 도메인 안은 역할 이름(controller·facade·service·repository…)으로 평평하게 | 처음 보는 사람이 바로 읽는다. 의존 방향은 ArchUnit 이 지킨다. 되돌리기 쉬워 ADR 은 쓰지 않았다 |
| 외부 호출은 트랜잭션 밖 — `facade/` 와 커밋 후 `event/` 리스너만 client 를 부른다 | 트랜잭션 안에서 기다리면 커넥션을 물고, 실패해도 롤백할 수 없다 |
| 도메인 간에는 식별자로만 잇는다. JPA 연관은 같은 도메인 안에서만 | 도메인을 따로 고칠 수 있게 |
| 한 사람은 크루 하나. 크루장은 `crews.leader_id` 로만 | `docs/feature-scope.md` |
| 계정 정지·관리자 웹은 없다 | `docs/feature-scope.md` — 제재는 크루장의 신고 처리·추방 |
